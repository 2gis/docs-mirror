# Стили карты

Вы можете изменять внешний вид карты и её объектов с помощью стилей. Стили — это правила, которые определяют в каком порядке и в каком виде отображать данные карты.

## Подключение стиля к карте {#connect-style}

Вы можете подключить стили из [Редактора стилей](https://styles.2gis.com/) к карте, добавленной в мобильное приложение. В Редакторе стилей вы можете детально настраивать отрисовку любых компонентов карты с помощью более 200 стилевых слоёв: см. список [готовых слоёв](/maps/styles/layers/configured/msdk).

Чтобы подключить стиль из Редактора стилей:

1. Создайте стиль карты и настройте стилевые слои с помощью Редактора стилей: см. инструкцию [Создание стилей и настройка стилевых слоёв](/maps/styles/create). Для создания вы можете использовать базовые стили с готовыми слоями.
2. Экспортируйте стиль: см. инструкцию [Подключение стиля для Android SDK](/maps/styles/connect#android-sdk).
3. Переместите скачанный стиль в проект с мобильным приложением.
4. Подключите стиль с помощью метода [File()](/android/sdk/reference/stable/class#ru.dgis.sdk.file) и укажите объект стиля в качестве параметра `styleFile`:

   <Tabs>
   <TabItem value="sdk-14" label="Для версии SDK 14.0.0 и выше" default>

   ```kotlin
   // Установить стиль в настройках карты
   val mapContainer = findViewById<LinearLayout>(R.id.map_container)
   val mapViewModel = DefaultMapControllerViewModel(
      sdkContext,
      MapControllerOptions(
         styleFile = File.fromAsset(sdkContext, "custom-styles.2gis")
      )
   )

   // Создать карту с указанными настройками
   mapView = MapView(this).also { view ->
      view.setMapControllerViewModel(mapViewModel)
   }
   mapContainer.addView(mapView)
   ```

   </TabItem>
   <TabItem value="sdk-13" label="Для версии SDK 13.x">

   ```kotlin
   // Установить стиль в настройках карты
   val mapContainer = findViewById<LinearLayout>(R.id.map_container)
   val mapOptions = MapOptions().apply {
      styleFile = File.fromAsset(sdkContext, "custom-styles.2gis")
   }

   // Создать карту с указанными настройками
   mapView = MapView(this, mapOptions)
   mapContainer.addView(mapView)
   ```

   </TabItem>
   </Tabs>

   Вы можете указать [File()](/android/sdk/reference/stable/class#ru.dgis.sdk.file) с помощью различных конструкторов:

   ```kotlin
   styleFile = File("custom-styles.2gis")

   styleFile = File.fromAsset(sdkContext, "custom-styles.2gis")

   styleFile = File.fromString("custom-styles.2gis")
   ```

5. Если ранее у вас был подключён другой стиль, выпустите новую версию приложения.

## Изменение стиля карты {#change-style}

Чтобы изменить стиль карты, которая уже добавлена в приложение:

1. Экспортируйте обновлённый стиль из Редактора стилей: см. инструкцию [Подключение стиля для Android SDK](/maps/styles/connect#android-sdk).
2. Загрузите новый стиль с помощью [StyleBuilder](/android/sdk/reference/stable/class#ru.dgis.sdk.map.style-builder):

    ```kotlin
    // Загрузить новый стиль карты
    val newStyle = StyleBuilder(sdkContext).loadStyle(File.fromAsset(sdkContext, "custom-styles.2gis"))

    // Изменить стиль карты после загрузки
    newStyle.onResult { map.style = it }
    ```

3. Выпустите новую версию приложения.

## Переключение темы {#switch-theme}

Стили карты могут содержать несколько тем (например, дневную и ночную), между которыми можно переключаться «на лету» без необходимости загрузки дополнительного стиля.

### При создании карты {#switch-theme-on-map-creation}

Вы можете указать тему при создании карты:

<Tabs>
<TabItem value="sdk-14" label="Для версии SDK 14.0.0 и выше" default>

```kotlin
// Установить тему в настройках карты
val mapContainer = findViewById<LinearLayout>(R.id.map_container)
val mapViewModel = DefaultMapControllerViewModel(
    sdkContext,
    MapControllerOptions(
        mapAppearance = MapAppearance(
            Fixed(MapTheme("day", Color(0xFFFF0000.toInt())))
        )
    )
)

// Создать карту с указанными настройками
mapView = MapView(this).also { view ->
    view.setMapControllerViewModel(mapViewModel)
}
mapContainer.addView(mapView)
```

</TabItem>
<TabItem value="sdk-13" label="Для версии SDK 13.x">

```kotlin
// Установить тему в настройках карты
val mapContainer = findViewById<LinearLayout>(R.id.map_container)
val mapOptions = MapOptions().apply {
    // Переключиться между темами
    setTheme(theme = MapTheme("day", Color(255,0,0)))
}

// Создать карту с указанными настройками
mapView = MapView(this, mapOptions)
mapContainer.addView(mapView)
```

</TabItem>
</Tabs>

### После создания карты {#switch-theme-after-map-creation}

Вы можете изменить тему после создания карты:

<Tabs>
<TabItem value="sdk-14" label="Для версии SDK 14.0.0 и выше" default>

```kotlin
map.appearance = MapAppearance(Fixed(MapTheme.defaultDarkTheme))
```

</TabItem>
<TabItem value="sdk-13" label="Для версии SDK 13.x">

```kotlin
mapView.setTheme(MapTheme.defaultDarkTheme)
```

</TabItem>
</Tabs>

## Управление стилевыми слоями {#manage-style-layers}

Вы можете динамически включать и выключать отображение стилевого слоя на карте. Чтобы включить слой (например, слой с парковками):

1. Инициализируйте глобальную переменную:

   1. Откройте [Редактор стилей](https://styles.2gis.com/).
   2. В блоке **Мои стили** откройте карточку нужного стиля.
   3. В разделе **Слои** выберите слой, который нужно включить.
   4. В блоке **Данные (JSON)** отредактируйте JSON-файл и добавьте нужную глобальную переменную (`global`). Например, для слоя с парковками — это переменная `parkingOn`:

      <img src="/img/mobile-sdk/add-attribute.png" alt="Добавление глобальной переменной" width="650"  />

      Глобальная переменная может использоваться в нескольких слоях, но только внутри одного стиля.

2. Экспортируйте и подключите стиль: см. инструкцию [Подключение стиля для Android SDK](/maps/styles/connect#android-sdk).

3. Установите значение `true` для атрибута с помощью метода [setAttributeValue()](/android/sdk/reference/stable/class#ru.dgis.sdk.map.attributes/set-attribute-value). Например, чтобы включить отображение слоя парковок:

   ```kotlin
   map.attributes.setAttributeValue("parkingOn", AttributeValue(true))
   ```

4. Выпустите новую версию приложения.
