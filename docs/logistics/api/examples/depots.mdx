# Склады

**Склады** — это точки, в которых агенты могут забирать заказы или груз. Склады используются при создании задач в маршрутных планах. Агенты могут начинать или заканчивать работу на складе, также склад может быть промежуточной точкой. Подробнее о складах см. в разделе [Склады](/logistics/administrator/managing/depots) Руководства администратора.

## Получение списка складов {#getting-depots-list}

Вы можете получить список складов с данными о них: ID, названием, адресом, графиком работы, датой и временем создания и обновления.

Чтобы получить список складов, отправьте GET-запрос к [/v1/depots](/logistics/api/reference/depots#tag/depots/operation/listDepots) с параметром `limit` — максимальным количеством складов в ответе от 1 до 100.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/depots?limit=2' \
   --header 'Authorization: Bearer <token>'
```
