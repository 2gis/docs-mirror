# Агенты

**Агенты** выполняют рабочие задачи и используются при создании маршрутных планов. Агентами могут быть мобильные сотрудники (например, операторы и курьеры), спецтехника и т. д. Подробнее об агентах см. в разделе [Агенты](/logistics/administrator/managing/agents) Руководства администратора.

## Получение списка агентов {#getting-agents-list}

Вы можете получить список агентов с данными о них: ID агента, ID шаблона, датой и временем создания и обновления, источниками данных о местоположении агента и атрибутами.

Чтобы получить список агентов, отправьте GET-запрос к [/v1/agents](/logistics/api/reference/agents#tag/agents/operation/listAgents) с параметром `limit` — максимальным количеством агентов в ответе от 1 до 500.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/agents?limit=2' \
   --header 'Authorization: Bearer <token>'
```

## Получение агента по ID {#getting-agent}

Вы можете получить данные агента по его идентификатору: ID шаблона, дату и время создания и обновления, источники данных о местоположении агента и атрибуты.

Чтобы получить данные агента, отправьте GET-запрос к [`/v1/agents/{id}`](/logistics/api/reference/agents#tag/agents/operation/getAgent), где `{id}` — идентификатор агента.

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/agents/56ca1414-3d9b-4167-9fa1-646576fe9227' \
   --header 'Authorization: Bearer <token>'
```

## Создание агента {#creating-agent}

Чтобы создать агента, отправьте POST-запрос к [/v1/agents](/logistics/api/reference/agents#tag/agents/operation/createAgent) со следующими параметрами:

* `template_id` (обязательный параметр) — ID [шаблона агента](/logistics/api/examples/templates).
* `attributes` — список атрибутов агента. Каждый объект `data` должен содержать:

   * `attribute_id` (обязательный параметр) — ID атрибута, указанный в [шаблоне агента](/logistics/api/examples/templates#getting-agent-template).
   * `type` (обязательный параметр) — тип атрибута, указанный в [шаблоне агента](/logistics/api/examples/templates#getting-agent-template).
   * `value` — значение атрибута.

* `data_sources` — список источников данных о местоположении агента. Каждый объект `value` должен содержать:

   * `type` (обязательный параметр) — тип источника данных: `mobile` (мобильное приложение) или `device` (устройство трекинга). Чтобы привязать к агенту устройство, используйте решение [2ГИС ГеоПоток: Мониторинг](/monitoring/overview) вместе с 2ГИС ГеоПоток: Логистикой.
   * `user_id` или `device_id` (обязательный параметр) — в зависимости от типа источника данных: ID пользователя в мобильном приложении или ID устройства трекинга.

**Пример запроса:**

```bash
curl --request POST \
   --url 'https://geoflow.2gis.ru/public/api/v1/agents' \
   --header 'Authorization: Bearer <token>' \
   --header 'Content-Type: application/json' \
   --data '{
      "template_id": "af5e5d63-10f0-4ea0-b520-ddb36af1a59c",
      "attributes": [
         {
            "data": {
               "attribute_id": "6653466e-1f20-485c-928e-c18b4bffedbc",
               "type": "text",
               "value": "Иван Иванов"
            }
         },
         {
            "data": {
               "attribute_id": "1efd0fb1-7216-4d69-8baf-4470570de40b",
               "type": "transport_type",
               "value": "walking"
            }
         }
      ],
      "data_sources": [
         {
            "type": "mobile",
            "value": {
               "type": "mobile",
               "user_id": "590cef82-d71f-48a1-8f81-3118db444b92"
            }
         }
      ]
   }'
```

## Обновление агента {#updating-agent}

Чтобы обновить данные агента, отправьте PUT-запрос к [`/v1/agents/{id}`](/logistics/api/reference/agents#tag/agents/operation/updateAgent), где `{id}` — идентификатор агента, и передайте в теле запроса новые данные.

**Пример запроса:**

```bash
curl --request PUT \
   --url 'https://geoflow.2gis.ru/public/api/v1/agents/b70ebe82-6af7-4731-a4c7-7f2f5acc3387' \
   --header 'Authorization: Bearer <token>' \
   --header 'Content-Type: application/json' \
   --data '{
      "template_id": "af5e5d63-10f0-4ea0-b520-ddb36af1a59c",
      "attributes": [
         {
            "data": {
               "attribute_id": "6653466e-1f20-485c-928e-c18b4bffedbc",
               "type": "text",
               "value": "Иван Петров"
            }
         }
      ]
   }'
```

## Удаление агента {#deleting-agent}

:::warning

Агент будет исключён из маршрутных планов и задач. Восстановить агента после удаления невозможно.

:::

Чтобы удалить агента, отправьте DELETE-запрос к [`/v1/agents/{id}`](/logistics/api/reference/agents#tag/agents/operation/deleteAgent), где `{id}` — идентификатор агента.

**Пример запроса:**

```bash
curl --request DELETE \
   --url 'https://geoflow.2gis.ru/public/api/v1/agents/b70ebe82-6af7-4731-a4c7-7f2f5acc3387' \
   --header 'Authorization: Bearer <token>'
```

При успешном удалении вернётся ответ со статусом `204 No Content`.
