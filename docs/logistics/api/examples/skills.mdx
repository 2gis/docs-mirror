# Навыки

**Навыки** определяют, какие задачи может выполнять агент. Назначить задачу агенту в маршрутном плане можно, если он обладает всеми навыками, которые требуются для её выполнения. Подробнее о навыках см. в разделе [Навыки](/logistics/administrator/managing/skills) Руководства администратора.

## Получение списка навыков {#getting-skills-list}

Вы можете получить список навыков с данными о них: ID, названием, датой и временем создания и обновления.

Чтобы получить список навыков, отправьте GET-запрос к [/v1/skills](/logistics/api/reference/skills#tag/skills/operation/listSkills) с параметром `limit` — максимальным количеством навыков в ответе от 1 до 100.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/skills?limit=3' \
   --header 'Authorization: Bearer <token>'
```
