# Задачи

На вкладке **Задачи** мобильного приложения отображается список задач для агента в маршрутном плане.

Задачи отображаются в том порядке, в котором их нужно выполнить. В карточках задач отображаются данные, которые указал администратор при создании задачи (например, время выполнения, необходимые навыки и т. д.), и расчётное время выполнения задачи. Подробнее о задачах см. в [Руководстве администратора](/logistics/administrator/routes).

## Начало работы {#getting-started}

Чтобы начать работать с задачей:

1. Перейдите на вкладку **Задачи** и выберите текущую дату.
2. Нажмите **Начать маршрут**.
3. Чтобы включить режим навигации для проезда к первой точке посещения, нажмите **Навигатор**. Включать навигатор необязательно, но он поможет вам совершить объезд по оптимальному маршруту.

   Когда вы доберётесь до точки посещения, нажмите **Я на месте**.

   <img src="/img/logistics/operator-tasks-card-698.png" alt="Карточка задачи" width="300"/>&nbsp;&nbsp;<img src="/img/logistics/operator-tasks-navigation-698.png" alt="Кнопка Я на месте" width="300"/>

4. Чтобы завершить работу над задачей, откройте её карточку и нажмите **Завершить задачу**.
5. Выберите статус результата задачи: **Выполнена** или **Не выполнена**.

   <img src="/img/logistics/operator-tasks-finish-698.png" alt="Завершить задачу" width="300"/>

6. Чтобы перейти к следующей задаче в маршрутном плане, нажмите **К следующей точке**.

   <img src="/img/logistics/operator-tasks-next-point-698.png" alt="Перейти к следующей точке" width="300"/>

Завершённые задачи отобразятся на вкладке **Завершённые**. Оставшиеся активные задачи — на вкладке **Активные**.
