# Обзор мобильного приложения

Мобильное приложение 2ГИС Логистика позволяет сотрудникам просматривать карту, список своих задач и использовать навигатор для построения маршрутов при работе над задачами маршрутного плана.

:::tip[2ГИС ГеоПоток]

Если 2ГИС Логистика используется вместе с [2ГИС ГеоПотоком](/geoflow/overview), то мобильное приложение записывает данные о перемещениях агента (сотрудника или транспорта). Эти данные позволяют администраторам отслеживать агентов в реальном времени и анализировать историю перемещений в веб-панели: см. [Руководство администратора 2ГИС ГеоПоток](/geoflow/administrator/monitoring).

:::

## Интерфейс приложения {#application-interface}

В роли **Сотрудник** вы можете работать со следующими вкладками в мобильном приложении:

* **Карта**: для просмотра карты и точек посещения в рамках маршрутных планов.
* **[Задачи](/logistics/operator/tasks)**: для просмотра задач внутри маршрутного плана и работы с ними. Задачи и маршрутные планы создают пользователи с ролями **Главный администратор**, **Администратор компании** и **Диспетчер** в веб-панели: подробнее см. в [Руководстве администратора](/logistics/administrator/routes).
* **[Профиль](/logistics/operator/settings)**: для просмотра уведомлений и управления настройками.
