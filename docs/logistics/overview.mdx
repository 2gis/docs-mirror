# Обзор

2ГИС Логистика — решение для планирования маршрутов на основе [TSP API](/api/navigation/tsp/overview). Автоматически рассчитывает оптимальный порядок посещения точек и распределяет задачи между агентами (например, мобильными сотрудниками или транспортом) так, чтобы минимизировать количество агентов, общее время и расстояние. Подробнее об алгоритме расчёта маршрутов см. в разделе [Алгоритм расчёта маршрута](/logistics/administrator/routes#route-calculation).

Сервис можно использовать в различных отраслях: доставка еды, курьерская служба, такси и другие.

## Основные особенности {#main-features}

* **Снижение затрат на логистику**

   Помогает сократить время на планирование маршрутов, автоматизировать работу логистов и вносить изменения в маршрутный план во время работы.

* **Обработка большого количества данных**

   Для расчёта одного маршрутного плана можно задавать до 350 задач и 200 агентов. После расчёта каждый сотрудник получает оптимальный маршрут.

* **Дополнительные параметры**

    Для расчёта маршрутных планов можно задавать дополнительные параметры: временные окна для посещения точек, навыки агентов, тип транспорта, способ оптимизации маршрута и другие.

## Варианты решения {#solution-options}

Решение поставляется в нескольких вариантах в зависимости от потребностей бизнеса:

* Только алгоритм маршрутизации на основе [TSP API](/api/navigation/tsp/overview) для построения маршрутов обхода точек, кратчайших по времени или расстоянию. Вы можете интегрировать API в свою систему планирования маршрутов и распределения задач.
* Полноценное решение с интерфейсом, содержащее:

   * Веб-панель для администраторов, которая позволяет указывать точки маршрута, задачи и агентов. Маршрутные планы рассчитываются автоматически на основе алгоритма TSP API.
   * Мобильное приложение для сотрудников, которое помогает им ориентироваться на карте, просматривать список задач и использовать навигатор для проезда по маршруту.

:::tip[2ГИС ГеоПоток]

Чтобы отслеживать местоположение сотрудников и транспорта в реальном времени, используйте решение [2ГИС ГеоПоток](/geoflow/overview) вместе с 2ГИС Логистикой. В общей веб-панели администраторы смогут [отслеживать агентов](/geoflow/administrator/monitoring) и [планировать смены](/geoflow/administrator/shifts).

:::

## Технические требования {#technical-requirements}

Для эффективной работы системы, устройства, на которых используются инструменты 2ГИС Логистики, должны удовлетворять следующим требованиям:

* **Веб-панель администратора**. Рекомендуемые требования к устройству для работы с веб-панелью:

   * Процессор: минимум 4 ядра с частотой 2 ГГц.
   * Оперативная память: минимум 8 ГБ.
   * Операционная система: Windows 11, macOS 13 Ventura или Linux последней версии.
   * Браузер: Google Chrome, Mozilla Firefox, Microsoft Edge или Safari.
   * Разрешение экрана: FullHD (1920×1080 пикселей).
   * Стабильное интернет-соединение.

* **Мобильное приложение сотрудника**. Для установки мобильного приложения требуется мобильное устройство на базе операционной системы Android версии 10 (API level 29) и выше.
* **Трекер сотрудника** (при использовании 2ГИС ГеоПотока). Трекер должен содержать ГЛОНАСС/GPS-приёмник с протоколом передачи данных EGTS.
