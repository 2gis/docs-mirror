# Маршрутные планы

**Маршрутный план** — это оптимальная последовательность точек, которые [агенты](/logistics/administrator/managing/agents) должны посетить для выполнения [задач](/logistics/administrator/tasks). Агенты могут посмотреть список своих задач для текущего маршрутного плана в [мобильном приложении](/logistics/operator/tasks).

Для каждого маршрутного плана рассчитываются общее расстояние, примерное время выполнения и необходимое количество агентов.

В роли **Главный администратор**, **Администратор компании** и **Диспетчер** вы можете работать с маршрутными планами на вкладке **Маршруты**:

* [создавать планы](#creating-plan),
* [перепланировать маршруты](#replanning-route),
* [редактировать планы](#editing-plan),
* [просматривать информацию о планах](#viewing-plan),
* [скачивать планы](#downloading-plan),
* [удалять планы](#deleting-plan).

## Алгоритм расчёта маршрута {#route-calculation}

Цель расчёта — распределить максимальное количество задач между агентами, минимизируя количество задействованных агентов, общее время выполнения плана и суммарное расстояние.

Алгоритм итеративно строит маршруты и выбирает лучший вариант по заданным критериям. Порядок выбора варианта маршрута:

1. Выбирается маршрут с наибольшим количеством распределённых задач.
2. Если количество распределённых задач одинаковое, выбирается маршрут с наименьшим количеством агентов.
3. Если количество агентов одинаковое, выбирается вариант с наименьшим общим временем.
4. Если общее время одинаковое, выбирается вариант с наименьшим суммарным расстоянием.

При расчёте учитывается расположение точек и ограничения:

* вместимость агентов;
* данные о грузе в задачах;
* ограничения во времени: временные окна складов и точек, время обслуживания, рабочее время агентов, время перемещения между точками;
* навыки задач и агентов (задача с навыком назначается только агенту с таким же навыком);
* тип транспорта, используемого в задачах и у агентов;
* дорожная ситуация (данные о текущих и статистических пробках) в зависимости от выбранного параметра для оптимизации маршрута.

Алгоритм не делит задачи по районам и не распределяет нагрузку агентов равномерно: он выбирает оптимальный вариант с минимальными общими затратами и учётом всех ограничений.

В некоторых случаях алгоритм может распределить не все задачи по маршруту, если это невозможно сделать с учётом ограничений. Такие задачи будут отображаться в панели **Не назначены**. Некоторые агенты могут быть исключены, если использование меньшего числа агентов будет оптимальнее.

## Создание плана {#creating-plan}

Для создания плана необходим минимум один [склад](/logistics/administrator/managing/depots), две [задачи](/logistics/administrator/tasks) и один [агент](/logistics/administrator/managing/agents). Вы можете создать склады, задачи и агентов в процессе создания плана или до этого.

В план нельзя добавить задачи и агентов, которые используются в других маршрутных планах на эту дату (кроме планов со статусом `Черновик`) и сменах (если вы используете решение [2ГИС ГеоПоток: Мониторинг](/monitoring/overview)).

Чтобы создать план:

1. Перейдите на вкладку **Маршруты**.
2. Нажмите **Добавить маршрут**.
3. Укажите обязательные параметры плана:

   * **Название**: название плана.
   * **Дата**: дата выполнения плана. Вы можете выбрать дату не ранее текущей и не позднее чем через 365 дней. Должна совпадать с датой, указанной в задачах.
   * **Часовой пояс**: часовой пояс, в котором указывается время выполнения плана. Должен совпадать с часовым поясом, указанным в задачах.
   * **Транспорт**: тип транспорта, используемый в задачах плана: `Легковой`, `Велосипед`, `Пешком`, `Самокат`, `Грузовой`. Должен совпадать с типом транспорта, указанным у агентов в поле **Транспорт** (поле может иметь другое название в зависимости от шаблона агента).
   * **Оптимизация маршрута**: параметр для оптимизации маршрута обхода точек:

      * `Самый быстрый по статистике пробок`: кратчайший по времени с учётом статистической информации по пробкам.
      * `Самый быстрый по текущим пробкам`: кратчайший по времени с учётом текущих пробок.
      * `Самый короткий по расстоянию`: кратчайший по расстоянию без учёта пробок.

      Подробнее об алгоритме расчёта см. в разделе [Алгоритм расчёта маршрута](#route-calculation).

   ![Создание плана](/img/logistics/creating-plan-743.png)

4. Добавьте задачи в план одним из способов ниже. Можно добавить от 2 до 350 задач.

   <Tabs>
   <TabItem value="create-tasks" label="Создать задачи" default>

      Чтобы создать задачи в форме создания маршрутного плана:

      1. В панели **Задачи** нажмите значок ![Плюс](/img/logistics/plus-icon.svg).
      2. Выберите или создайте шаблон задачи. Чтобы создать шаблон, нажмите **Добавить шаблон задачи**: подробнее см. в разделе [Создание шаблона задачи](/logistics/administrator/managing/templates#creating-task-template).

         Если шаблон не подходит для создания плана (не хватает обязательных атрибутов), нажмите **Изменить шаблон задачи**. Добавьте атрибуты и нажмите **Сохранить**. Подробнее об атрибутах см. в разделе [Создание шаблона задачи](/logistics/administrator/managing/templates#creating-task-template).

      3. В правом верхнем углу нажмите **+ Задача**.
      4. Укажите параметры задачи:

         ![Создание задач](/img/logistics/creating-tasks-743.png)

         * **Название**: уникальный идентификатор задачи. Поле может иметь другое название в зависимости от [шаблона задачи](/logistics/administrator/managing/templates#creating-task-template), например `Идентификатор`.
         * **Местоположение** (обязательный параметр): укажите адрес точки одним из способов:

            * Отметьте точку на карте. Вы можете переместить значок маркера в любое место на карте.
            * Введите адрес точки в поле и выберите вариант из выпадающего списка.
            * Введите координаты точки в формате `долгота, широта` (например, `37.607132,55.7680412`).

            При необходимости укажите подъезд, этаж, квартиру или офис и комментарий к адресу.

         * **Дата и время**: дата и время выполнения задачи:

            * **Дата** (обязательный параметр): дата, в которую нужно выполнить задачу. Должна совпадать с датой, указанной в плане.
            * **Время** (обязательный параметр): временной интервал, в который нужно выполнить задачу.
            * **Время на задачу в минутах**: время, необходимое для выполнения задачи.
            * **Часовой пояс**: часовой пояс, в котором указывается время выполнения задачи.
            * **Жёсткое окно**: отметьте чекбокс, если задачу нужно выполнить только в указанное время. Если параметр указан, агент не сможет выполнить задачу раньше или позже.

         * **Склад** (обязательный параметр): [склад](/logistics/administrator/managing/depots), с которого агент должен забрать груз:

            * **Склад**: выберите склад из списка или добавьте новый. Чтобы добавить склад, нажмите **Добавить склад** и укажите его параметры:

               ![Создание склада](/img/logistics/creating-tasks-depot-743.png)

               * **Название** (обязательный параметр): название склада.
               * **Описание**: описание склада.
               * **Адрес** (обязательный параметр): укажите адрес склада одним из способов:
               
                  * Отметьте точку на карте. Вы можете переместить значок ![Склад](/img/logistics/depot-icon.svg) в любое место на карте.
                  * Введите адрес склада в поле и выберите вариант из выпадающего списка.
                  * Введите координаты склада в формате `долгота, широта` (например, `37.607132,55.7680412`).

                  При необходимости укажите подъезд, этаж, офис и комментарий к адресу.

               * **График работы**: рабочее время склада:
               
                  * **Часовой пояс**: часовой пояс, в котором указывается время работы склада.
                  * **Дни недели**: дни недели, в которые работает склад.
                  * **Рабочее время**: временной интервал, в который работает склад. Чтобы добавить интервал работы, нажмите **Добавить интервал** и введите время. Чтобы удалить интервал, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с ним.
                  * **Жёсткое окно**: отметьте чекбокс, если склад можно посещать только в указанное время. Если агент не сможет попасть на склад в указанный временной отрезок, склад исключится из расчёта маршрута.

               * **Время сборки заказа в минутах**: время, необходимое для сборки заказа на складе.

            * **Время на погрузку в минутах**: время, необходимое для погрузки заказа на складе.

      5. Укажите другие атрибуты, которые зависят от шаблона задачи.
      6. Нажмите **Сохранить**.
      7. Отметьте чекбоксы рядом с задачами.

         Вы можете искать задачи по названию, фильтровать их по типу (шаблону) задачи, по дате и времени выполнения, складу, навыкам и дате обновления. Чтобы скрыть задачи, которые нельзя добавить в план, включите опцию **Скрыть недоступные**.

         Задачи должны содержать обязательные атрибуты: дату и время выполнения задачи в часовом поясе, указанном в шаблоне, местоположение и склад, с которого агент должен забрать груз. Подробнее об атрибутах см. в разделе [Создание шаблона задачи](/logistics/administrator/managing/templates#creating-task-template).

         ![Выбор задач](/img/logistics/selecting-plan-tasks-743.png)

      8. Нажмите **Добавить**.

         После подтверждения плана вы можете [перепланировать маршрут](#replanning-route), например, исключить задачи или добавить агентов.

   </TabItem>
   <TabItem value="save-draft" label="Сохранить черновик">

      Чтобы сохранить план в виде черновика, нажмите **Сохранить черновик**. План перейдёт в статус `Черновик`. Позже вы сможете рассчитать маршрут или [отредактировать план](#editing-plan).

   </TabItem>
   </Tabs>

## Перепланирование маршрута {#replanning-route}

Вы можете перепланировать маршруты в планах со статусами `Рассчитан`, `Запланирован` и `В работе`:

* добавить или удалить задачи из плана;
* добавить или удалить агентов из плана;
* снять задачи с агентов;
* выбрать другой способ оптимизации маршрута.

Вы можете удалить задачи из плана или снять их с агента только если рейс ещё не начался. Если рейс связан с другим рейсом (например, груз для одной из точек второго рейса забирается в первом), после начала выполнения маршрутного плана нельзя редактировать оба рейса.

Вы можете как отредактировать текущую версию плана, так и создать новую. После подтверждения версии остальные будут удалены. После перепланирования маршрута агенты получат уведомления в мобильном приложении о том, что маршрут изменён, и список новых задач.

:::note[Одновременное перепланирование]

Несколько пользователей не могут одновременно перепланировать один маршрут. Если другой пользователь редактирует маршрут, вы увидите уведомление о том, что изменение недоступно. Редактирование блокируется на 10 минут. Срок блокировки продлевается автоматически при любом действии в плане (например, при добавлении или удалении задачи) или вручную.

:::

Чтобы перепланировать маршрут:

1. Перейдите на вкладку **Маршруты**.
2. Откройте страницу плана.
3. Нажмите **Изменить маршрутный план**.
4. Внесите изменения в план:

   ![Перепланирование маршрута](/img/logistics/editing-plan-771.png)

   * Чтобы добавить агентов, нажмите **+ Агент** и отметьте чекбоксы рядом с агентами или группами. Вы можете искать агентов по идентификатору, фильтровать их по типу (шаблону) агента и навыкам. Чтобы скрыть агентов, которых нельзя добавить в план, включите опцию **Скрыть недоступных**. Нажмите **Добавить**.
   * Чтобы добавить задачи, нажмите **+ Задача** и отметьте чекбоксы рядом с задачами. Вы можете искать задачи по названию, фильтровать их по типу (шаблону) задачи, по дате и времени выполнения, складу, навыкам и дате обновления. Чтобы скрыть задачи, которые нельзя добавить в план, включите опцию **Скрыть недоступные**. Нажмите **Добавить**.
   * Чтобы снять назначение задачи с агента, в списке задач нажмите значок ![Меню задачи](/img/menu-dots-horizontal.svg) у задачи и выберите **Снять назначение**. Задача перенесётся в список задач в панели **Не назначены** и будет назначена другому или этому же агенту при пересчёте маршрута.
   * Чтобы удалить задачу из плана, в списке задач нажмите значок ![Меню задачи](/img/menu-dots-horizontal.svg) у задачи и выберите **Исключить из маршрута**. Задача будет удалена из плана.
   * Чтобы удалить агента из плана, в списке агентов нажмите значок ![Меню агента](/img/menu-dots-horizontal.svg) у агента и выберите **Снять агента с маршрута**. Агент будет удалён из плана. Невыполненные задачи агента перенесутся в список задач в панели **Не назначены** и будут назначены другим агентам при пересчёте маршрута.

5. Чтобы пересчитать маршрут, нажмите **Пересчитать план**. Если вы хотите сбросить внесённые изменения и вернуться к предыдущей версии плана, нажмите **Сбросить изменения**.
6. Если план в статусе `Рассчитан` или `Запланирован`, в диалоговом окне:

   1. Выберите способ оптимизации маршрута:

      * `Самый быстрый по статистике пробок`: кратчайший по времени с учётом статистической информации по пробкам.
      * `Самый быстрый по текущим пробкам`: кратчайший по времени с учётом текущих пробок.
      * `Самый короткий по расстоянию`: кратчайший по расстоянию без учёта пробок.

   2. Укажите, нужно ли создать новую версию плана.

      Версии создаются автоматически для планов со статусом `В работе`, а также для планов со статусом `Запланирован`, для которых создана только одна версия.

7. Нажмите **Рассчитать маршрут**.
8. Чтобы подтвердить версию плана, выберите её и нажмите **Подтвердить выбранный маршрут**. Агенты увидят новые маршруты и задачи в мобильном приложении.

## Перепланирование маршрута агентом {#replanning-route-agent}

В [мобильном приложении](/logistics/operator/tasks) агент может изменить маршрутный план: отменить задачу или перенести её на другое время или другой день. В этом случае на странице маршрутного плана в веб-панели администратора появится вкладка **История изменений**. Подробнее см. в разделе [Просмотр информации о плане](#viewing-plan).

Доступные действия зависят от статуса рейса, которому принадлежит задача:

* Если рейс не начат, агент может отменить задачу и перенести её на другое время или другой день. При внесении изменений маршрутный план пересчитывается. Если при пересчёте возникает ошибка, агент может повторить попытку или исключить задачу из плана без пересчёта.
* Если рейс уже начат, агент не может перенести задачу на другое время этого же дня, но может отменить задачу или перенести её на другой день. В этом случае маршрутный план не пересчитывается.

## Редактирование плана {#editing-plan}

Вы можете отредактировать планы со статусами `Черновик` и `Не рассчитан`:

* изменить транспорт и способ оптимизации маршрута;
* добавить или удалить задачи из плана;
* добавить или удалить агентов из плана.

Для планов со статусом `Черновик` вы можете изменить название и дату.

Чтобы отредактировать план:

1. Перейдите на вкладку **Маршруты**.
2. Откройте страницу плана.
3. Внесите изменения в план.

   ![Редактирование плана](/img/logistics/editing-plan-draft-743.png)

4. Завершите планирование.

   <Tabs>
   <TabItem value="calculate-route-editing" label="Рассчитать маршрут" default>

      Чтобы рассчитать маршрут:

      1. Нажмите **Рассчитать маршрут**. План перейдёт в статус `Рассчитан`.
      2. Проверьте маршрутный план.
      3. Чтобы подтвердить план, нажмите **Подтвердить маршрут**. План перейдёт в статус `Запланирован`. Агенты увидят свои маршруты и задачи в мобильном приложении.

         После подтверждения плана вы можете [перепланировать маршрут](#replanning-route), например, исключить задачи или добавить агентов.

   </TabItem>
   <TabItem value="save-draft-editing" label="Сохранить черновик">

      Чтобы сохранить план в виде черновика, нажмите **Сохранить черновик**. Позже вы сможете рассчитать маршрут или снова отредактировать план.

   </TabItem>
   </Tabs>

## Просмотр информации о плане {#viewing-plan}

![Просмотр плана](/img/logistics/viewing-plan-771.png)

1. Перейдите на вкладку **Маршруты**. В списке отображаются планы с возможными статусами:

   * **Черновик**: план создан, но не рассчитан.
   * **Идёт расчёт**: план рассчитывается.
   * **Рассчитан**: план рассчитан, но не подтверждён администратором. Чтобы задачи появились в мобильном приложении у агентов, подтвердите план.
   * **Запланирован**: план подтверждён администратором, но агенты ещё не начали работу.
   * **В работе**: хотя бы одна задача плана находится в работе у агента.
   * **Выполнен**: все задачи плана выполнены агентами.
   * **Не рассчитан**: план не удалось рассчитать. Чтобы повторить расчёт, нажмите **Повторить** или **Изменить параметры**.
   * **Ошибка**: при расчёте плана произошла ошибка.

2. Откройте страницу плана. Вы можете искать планы по названию и фильтровать их по дате и статусу: активным и завершённым.

### Страница плана {#plan-page}

На странице планов со статусами `Рассчитан`, `Запланирован`, `В работе` и `Выполнен` отображается:

* Название плана.
* Дата выполнения плана.
* Статус плана.
* Дата, когда план был подтверждён (для статусов `Запланирован` и `В работе`).
* Имя пользователя, который подтвердил план (для статусов `Запланирован` и `В работе`).
* Способ оптимизации маршрута (для статусов `Рассчитан`, `Запланирован` и `В работе`).
* **Задачи**:

   * **Всего**: общее количество задач в плане.
   * **Не назначены**: количество задач, которые не были назначены агентам (для статусов `Рассчитан` и `Запланирован`).
   * **Выполнено**: количество задач, выполненных агентами (для статусов `В работе` и `Выполнен`).
   * **Отменено**: количество задач, отменённых администратором или агентами (для статусов `В работе` и `Выполнен`).

* **Ресурсы**:

   * **Агенты**: количество агентов, назначенных на задачи плана.
   * **Рейсы**: количество рейсов в плане. Рейс — часть маршрута агента от склада до конечной точки или до следующего посещения склада (в зависимости от того, что наступит раньше).

* **Время**:

   * **Общее**: расчётное общее время выполнения плана.
   * **Среднее**: расчётное среднее время выполнения плана для всех агентов.

* **Пробег**:

   * **Общий**: расчётное общее расстояние для всех агентов.
   * **Средний**: расчётное среднее расстояние для одного агента.

* Список агентов, назначенных на задачи плана. Для каждого агента отображаются:

   * Расчётное время выполнения задач.
   * Расчётное расстояние.
   * Процент загрузки. Если у агента два рейса и более, отображается диапазон: минимальный и максимальный процент загрузки по рейсам. Подробнее о расчёте процента загрузки см. в разделе [Создание шаблона агента](/logistics/administrator/managing/templates#creating-agent-template).
   * Индикаторы задач:

      * **X**: общее количество задач агента в плане (для статусов `Рассчитан` и `Запланирован`).
      * **X из Y**: количество выполненных задач из общего количества задач агента в плане (для статусов `В работе` и `Выполнен`).
      * Значок ![Крестик](/img/logistics/cross-icon.svg): количество задач, отменённых администратором или агентом.
      * Значок ![Восклицательный знак](/img/logistics/exclamation-icon.svg): количество задач, исключённых из маршрутного плана при пересчёте маршрута агентом.
      * Значок ![Календарь](/img/logistics/calendar-icon.svg): количество задач, перенесённых агентом на другой день.

   * Список рейсов, если у агента два рейса и более. Для каждого рейса отображаются:

      * Индикатор цвета рейса на карте.
      * Количество задач в рейсе.
      * Расчётное время выполнения задач.
      * Расчётное расстояние.

   * Список задач. Для каждой задачи отображаются:

      * Расчётное время прибытия на склад или точку.
      * Название задачи. Для складов отображается название **Погрузка**.
      * Адрес склада или точки.
      * Временное окно выполнения задачи. Если выбрано жёсткое окно, отображается значок **!**.
      * Данные о грузе и навыки (если указаны в шаблоне задачи).

* **История изменений**: список запросов агента на [перепланирование маршрута](#replanning-route-agent) (для статуса `В работе`).

### На карте {#on-map}

Для планов со статусами `Рассчитан`, `Запланирован`, `В работе` и `Выполнен` на карте отображаются:

* Иконки складов с названием и планируемым временем прибытия агентов (началом обслуживания).
* Маршруты рейсов для каждого агента с порядком посещения точек, названиями задач и планируемым временем прибытия. Если у агента несколько рейсов, они отображаются разными цветами.
* Индикаторы задач:

   * Значок ![Крестик](/img/logistics/cross-icon.svg): задача отменена администратором или агентом.
   * Значок ![Восклицательный знак](/img/logistics/exclamation-icon.svg): задача исключена из маршрутного плана при пересчёте маршрута агентом.
   * Значок ![Календарь](/img/logistics/calendar-icon.svg): задача перенесена агентом на другой день.

## Скачивание плана {#downloading-plan}

Вы можете скачать план в форматах XLSX и JSON.

1. Перейдите на вкладку **Маршруты**.
2. Откройте страницу плана.
3. Нажмите значок ![Меню плана](/img/menu-dots-horizontal.svg) и выберите **Скачать в XLSX** или **Скачать в JSON**.

## Удаление плана {#deleting-plan}

:::warning

Восстановить план после удаления невозможно.

:::

Вы можете удалить план с любым статусом, кроме `В работе`.

1. Перейдите на вкладку **Маршруты**.
2. В строке плана нажмите значок ![Меню плана](/img/menu-dots-horizontal.svg) и выберите **Удалить**.
3. Подтвердите удаление.
