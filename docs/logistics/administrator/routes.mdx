# Маршрутные планы

**Маршрутный план** — это оптимальная последовательность точек, которые [агенты](/logistics/administrator/managing/agents) должны посетить для выполнения [задач](/logistics/administrator/tasks). Агенты могут посмотреть список своих задач для текущего маршрутного плана в [мобильном приложении](/logistics/operator/tasks).

Для каждого плана рассчитываются общая длина дорог, примерное время выполнения и необходимое количество агентов.

В роли **Главный администратор**, **Администратор компании** и **Диспетчер** вы можете работать с маршрутными планами на вкладке **Маршруты**:

* [создавать планы](#creating-plan),
* [добавлять версии плана](#adding-plan-version),
* [редактировать планы](#editing-plan),
* [просматривать информацию о планах](#viewing-plan),
* [удалять планы](#deleting-plan).

![Работа с маршрутными планами](/img/logistics/route-plan-698.png)

## Алгоритм расчёта маршрута {#route-calculation}

Цель расчёта — распределить максимальное количество задач между агентами, минимизируя количество задействованных агентов, общее время выполнения плана и суммарное расстояние.

Алгоритм итеративно строит маршруты и выбирает лучший вариант по заданным критериям. Порядок выбора варианта маршрута:

1. Выбирается маршрут с наибольшим количеством распределённых задач.
2. Если количество распределённых задач одинаковое, выбирается маршрут с наименьшим количеством агентов.
3. Если количество агентов одинаковое, выбирается вариант с наименьшим общим временем.
4. Если общее время одинаковое, выбирается вариант с наименьшим суммарным расстоянием.

При расчёте учитывается расположение точек и ограничения:

* вместимость агентов;
* данные о грузе в задачах;
* ограничения во времени: временные окна складов и точек, время обслуживания, рабочее время агентов, время перемещения между точками;
* навыки задач и агентов (задача с навыком назначается только агенту с таким же навыком);
* тип транспорта, используемого в задачах и у агентов;
* дорожная ситуация (данные о текущих и статистических пробках) в зависимости от выбранного параметра для оптимизации маршрута.

Алгоритм не делит задачи по районам и не распределяет нагрузку агентов равномерно: он выбирает оптимальный вариант с минимальными общими затратами и учётом всех ограничений.

В некоторых случаях алгоритм может распределить не все задачи по маршруту, если это невозможно сделать с учётом ограничений. Такие задачи будут отображаться в панели **Не назначено**. Некоторые агенты могут быть исключены, если использование меньшего числа агентов будет оптимальнее.

## Создание плана {#creating-plan}

Для создания плана необходим минимум один [склад](/logistics/administrator/managing/depots), две [задачи](/logistics/administrator/tasks) и один [агент](/logistics/administrator/managing/agents). Вы можете создать склады, задачи и агентов в процессе создания плана или до этого.

В план нельзя добавить задачи и агентов, которые используются в других маршрутных планах на эту дату (кроме планов со статусом `Черновик`) и сменах (если вы используете решение [2ГИС ГеоПоток](/geoflow/overview)).

Чтобы создать план:

1. Перейдите на вкладку **Маршруты**.
2. Нажмите **Добавить маршрут**.
3. Укажите обязательные настройки плана:

   * **Название**: название плана.
   * **Дата**: дата выполнения плана. Вы можете выбрать дату не ранее текущей и не позднее чем через 365 дней. Должна совпадать с датой, указанной в задачах.
   * **Транспорт**: тип транспорта, используемый в задачах плана: `Легковой`, `Грузовой`, `Самокат`, `Велосипед`, `Пешком`. Тип должен совпадать с типом транспорта, указанным у агентов.
   * **Оптимизация маршрута**: параметр для оптимизации маршрута обхода точек:
   
      * `Самый быстрый по статистике пробок`: кратчайший по времени с учётом статистической информации по пробкам.
      * `Самый быстрый по текущим пробкам`: кратчайший по времени с учётом текущих пробок.
      * `Самый короткий по расстоянию`: кратчайший по расстоянию без учёта пробок.

      Подробнее об алгоритме расчёта см. в разделе [Алгоритм расчёта маршрута](#route-calculation).

   ![Создание плана](/img/logistics/creating-plan-698.png)

               * **Время сборки заказа в минутах**: время, необходимое для сборки заказа на складе.

            * **Время на погрузку в минутах**: время, необходимое для погрузки заказа на складе.

## Добавление версии плана {#adding-plan-version}

Для планов со статусом `Рассчитан` вы можете создать другую версию плана: изменить настройки, добавить или удалить задачи и агентов. Будет создана версия плана с новым маршрутом. После подтверждения одной версии остальные будут удалены.

Максимальное количество версий плана — 5.

Чтобы добавить версию плана:

1. Перейдите на вкладку **Маршруты**.
2. Откройте страницу плана.
3. Нажмите **Добавить версию**.
4. Внесите изменения в план.
5. Нажмите **Рассчитать маршрут**.

Чтобы подтвердить новую версию плана, нажмите **Подтвердить маршрут**.

## Редактирование плана {#editing-plan}

Вы можете редактировать план со статусами `Черновик` и `Не рассчитан`.

1. Перейдите на вкладку **Маршруты**.
2. В меню плана нажмите значок ![Меню плана](/img/menu-dots-horizontal.svg) и выберите **Редактировать**.
3. Внесите изменения в план.
4. Нажмите **Рассчитать маршрут**.

## Просмотр информации о плане {#viewing-plan}

1. Перейдите на вкладку **Маршруты**.
2. Откройте страницу плана. Вы можете искать планы по названию и фильтровать их по дате и статусу: активным и завершённым.

На странице плана отображается карта с маршрутом и следующие данные:

* **Название**: название плана.
* **Дата**: дата выполнения плана.
* **Статус**: статус плана:

   * **Черновик**: план создан, но не подтверждён администратором. Вы можете [отредактировать план](#editing-plan). Чтобы задачи и маршруты плана появились в мобильном приложении у агентов, подтвердите план.
   * **Идёт расчёт**: выполняется расчёт маршрута.
   * **Рассчитан**: маршрут рассчитан, задачи распределены по маршруту.
   * **Запланирован**: план подтверждён администратором, но агенты не начали работу.
   * **В работе**: хотя бы одна из задач плана находится в работе у агента (агент взял задачу в работу в мобильном приложении).
   * **Не рассчитан**: не удалось рассчитать маршрут. В этом случае вы можете [отредактировать план](#editing-plan) и изменить параметры маршрута.
   * **Ошибка**: произошла ошибка при создании плана.
   * **Выполнен**: все задачи в плане выполнены агентами.

* **Задачи**:

   * **Всего**: общее количество задач в плане.
   * **Не назначено**: количество задач, которые не удалось распределить по маршруту.

* **Ресурсы**:

   * **Агенты**: количество агентов, распределённых на задачи плана.
   * **Рейсы**: количество рейсов в плане.

* **Время**:

   * **Общее**: общее время выполнения плана.
   * **Среднее**: среднее время выполнения плана для всех агентов.

* **Пробег**:

   * **Общий**: общий пробег всех агентов в плане.
   * **Средний**: средний пробег одного агента в плане.

* **Агенты**: список агентов, назначенных на задачи плана. Для каждого агента отображается:
   
   * Время выполнения.
   * Пробег.
   * Процент загрузки. Если у агента в маршрутном плане два рейса и более, отображается диапазон загрузки: минимальный и максимальный процент загрузки в рейсах. Подробнее о расчёте процента загрузки см. в разделе [Создание шаблона агента](/logistics/administrator/managing/templates#creating-agent-template).
   * Склад.
   * Список задач, которые агент должен выполнить в рамках плана. Для каждой задачи отображается:

      * Расчётное время прибытия.
      * Адрес точки.
      * Временное окно, в которое нужно выполнить задачу.

      Чтобы посмотреть подробную информацию о задаче, нажмите на неё на карте.

## Удаление плана {#deleting-plan}

:::warning

Восстановить план после удаления невозможно.

:::

Вы можете удалить план только со статусом `Черновик`.

1. Перейдите на вкладку **Маршруты**.
2. В меню плана нажмите значок ![Меню плана](/img/menu-dots-horizontal.svg) и выберите **Удалить**.
3. Подтвердите удаление.
