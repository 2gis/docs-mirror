# Начало работы

Чтобы начать работу с 2ГИС ГеоПоток: Логистикой, выполните подготовительные шаги в зависимости от вашей роли в веб-панели администратора:

<Tabs>
<TabItem value="main-administrator" label="Главный администратор" default>

1. Зарегистрируйтесь в веб-панели администратора 2ГИС ГеоПоток: Логистики. Подробнее о регистрации см. в разделе [Демо-доступ](/logistics/demo).
2. [Добавьте администраторов](/logistics/administrator/managing/users#adding-user) в компанию и назначьте им роль **Администратор компании**.

</TabItem>
<TabItem value="company-administrator" label="Администратор компании">

1. Зарегистрируйтесь в веб-панели администратора 2ГИС ГеоПоток: Логистики по приглашению от главного администратора.

   <CtaButton href="https://geoflow.2gis.ru/" target="_blank">
      Открыть 2ГИС ГеоПоток: Логистика
   </CtaButton>

2. [Добавьте пользователей](/logistics/administrator/managing/users#adding-user) в компанию и назначьте им роли **Диспетчер** или **Сотрудник** в зависимости от уровня доступа.
3. [Добавьте справочники](/logistics/administrator/managing/directories#creating-directory) для классификации задач и агентов.
4. [Добавьте склады](/logistics/administrator/managing/depots#creating-depot).
5. [Создайте шаблоны агентов](/logistics/administrator/managing/templates#creating-agent-template).
6. [Создайте агентов](/logistics/administrator/managing/agents#creating-agent).
7. [Создайте шаблоны задач](/logistics/administrator/managing/templates#creating-task-template).

</TabItem>
<TabItem value="dispatcher" label="Диспетчер">

1. Зарегистрируйтесь в веб-панели администратора 2ГИС ГеоПоток: Логистики по приглашению от администратора компании.

   <CtaButton href="https://geoflow.2gis.ru/" target="_blank">
      Открыть 2ГИС ГеоПоток: Логистика
   </CtaButton>

2. [Добавьте навыки](/logistics/administrator/managing/skills#creating-skill) для классификации задач и агентов.
3. [Создайте или импортируйте задачи](/logistics/administrator/tasks) для агентов. Вы можете создать задачи в процессе [создания маршрутного плана](/logistics/administrator/routes#creating-plan).
4. [Создайте маршрутные планы](/logistics/administrator/routes#creating-plan) и добавьте в них задачи и агентов.

</TabItem>
</Tabs>
