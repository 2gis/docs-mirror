# Шаблоны

**Шаблоны** — это подготовленные наборы атрибутов для создания [агентов](/logistics/administrator/managing/agents) и [задач](/logistics/administrator/tasks). Шаблоны позволяют:

* создавать типовых агентов (например, курьеров) и типовые задачи (например, задачи по доставке);
* фильтровать агентов и задачи по типу при создании [маршрутных планов](/logistics/administrator/routes).

В роли **Главный администратор** и **Администратор компании** вы можете работать с шаблонами на вкладке **Управление → Шаблоны**:

* [создавать шаблоны агентов](#creating-agent-template),
* [создавать шаблоны задач](#creating-task-template),
* [редактировать шаблоны](#editing-template),
* [дублировать шаблоны](#duplicating-template).

В роли **Диспетчер** вы можете просматривать список шаблонов и информацию о них.

![Работа с шаблонами](/img/logistics/managing-templates-698.png)

## Создание шаблона агента {#creating-agent-template}

![Создание шаблона агента](/img/logistics/creating-agent-template-698.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. В выпадающем списке выберите **Агент**.
4. Чтобы создать собственный шаблон агента, оставьте поле **Предзаполнить из набора** пустым. Чтобы использовать предзаполненный шаблон, выберите в этом поле один из готовых типов агентов:

   * **Оператор**: сотрудник, выполняющий задачи.
   * **Курьер**: сотрудник, доставляющий документы или посылки.
   * **Спецтехника**: транспортные средства или машины, выполняющие работы. Например, курьерский автомобиль, бензовоз, экскаватор и т. д.

   Параметры ниже заполнятся автоматически для выбранного типа. При необходимости вы можете отредактировать их.

5. В поле **Метрика агента** выберите **Отключена**. Чтобы рассчитывать эффективность агентов, используйте решение [2ГИС ГеоПоток: Мониторинг](/monitoring/overview) вместе с 2ГИС ГеоПоток: Логистикой. В общей веб-панели администраторы смогут [отслеживать эффективность агентов](/monitoring/administrator/monitoring).
6. В поле **Название** введите общее название для типа агентов.
7. (Опционально) В блоке **Вид на карте** укажите отображение иконки агентов на карте. Нажмите на превью карты и укажите параметры:

   * **Иконка**: иконка агента.
   * **Цвет**: цвет иконки.

   Нажмите **Сохранить**.

8. В блоке **Атрибуты** укажите список полей для создания агентов этого типа. Некоторые атрибуты обязательны и добавляются в шаблон автоматически. Для всех атрибутов вы можете отметить чекбокс **Обязательное поле**, чтобы сделать их обязательными для создания агента.

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

   | **Тип данных** | **Обязательный атрибут** | **Описание** |
   | --- | --- | --- |
   | `Текстовое поле` | Необходим один атрибут для обозначения уникального идентификатора агента (например, табельный номер или ФИО). | Однострочный текст. |
   | `Транспорт` | Да. | Транспортное средство агента: велосипед, легковой автомобиль, самокат, пешком или грузовой автомобиль. |
   | `Многострочный текст` | Нет. | Многострочный текст. |
   | `Числовое поле` | Нет. | Числовое значение. |
   | `Чекбокс` | Нет. | Логическое значение. |
   | `Телефон` | Нет. | Номер телефона. |
   | `Email` | Нет. | Адрес электронной почты. |
   | `Справочник` | Нет. | Используется для выбора объектов [справочника](/logistics/administrator/managing/directories) при создании агента. Значения атрибута:<ul><li>Справочник.</li><li>**Разрешить множественный выбор**: чтобы разрешить выбирать несколько значений из справочника при создании агента, отметьте чекбокс.</li></ul> |
   | `Навыки` | Нет. | Используется для выбора [навыков](/logistics/administrator/managing/skills) при создании агента. |
   | `Вместимость` | Нет. | Груз, который может перевозить агент. Значения атрибута:<ul><li>**Количество мест**: количество мест под груз.</li><li>**Вес в кг**: максимальный вес груза в килограммах.</li><li>**Объём в м³**: максимальный объём груза в кубических метрах.</li><li>**Габариты в метрах**: максимальные габариты груза в метрах.</li></ul><br />На основе значений этих параметров рассчитывается загрузка агента в процентах в [маршрутных планах](/logistics/administrator/routes#viewing-plan), если в задачах указаны значения для параметров с типом **Груз**. Суммарная загрузка агента по всем задачам в маршрутном плане делится на значение параметра:<ul><li>Если указан один параметр, загрузка рассчитывается по нему. Например, значение параметра **Вес в кг** агента — 100 кг, а суммарная загрузка агента по всем задачам в маршрутном плане — 30 кг. Значение загрузки — 30%.</li><li>Если указано два и более параметра, загрузка рассчитывается по каждому из них, и берётся максимальное значение. Например, для агента указаны значения: **Количество мест** — 20, **Вес в кг** — 100 кг. Суммарная загрузка агента по всем задачам в маршрутном плане — 3 места и 98 кг. Значение загрузки — 98%.</li><li>Если ни один из параметров не указан, загрузка не рассчитывается.</li></ul> |
   | `Точка старта` | Нет. | Местоположение, в котором агент начинает выполнять задачи. |
   
9. Нажмите **Сохранить**.

## Создание шаблона задачи {#creating-task-template}

![Создание шаблона задачи](/img/logistics/creating-task-template.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. В выпадающем списке выберите **Задача**.
4. Чтобы создать собственный шаблон задачи, оставьте поле **Предзаполнить из набора** пустым. Чтобы использовать предзаполненный шаблон, выберите в этом поле готовый тип задачи **Логистический**.

   Параметры ниже заполнятся автоматически для выбранного типа. При необходимости вы можете отредактировать их.

5. В поле **Название** введите общее название для типа задач.
6. В блоке **Атрибуты** укажите список полей для создания задач этого типа. Некоторые атрибуты обязательны и добавляются в шаблон автоматически. Для всех атрибутов вы можете отметить чекбокс **Обязательное поле**, чтобы сделать их обязательными для создания задачи.

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

   | **Тип данных** | **Обязательный атрибут** | **Описание** |
   | --- | --- | --- |
   | `Дата и время` | Да. | Дата и время выполнения задачи. Чтобы ограничить время выполнения задачи, включите **Время на задачу в минутах**. |
   | `Местоположение` | Да. | Пункт назначения (местоположение): координаты или адрес. |
   | `Склад` | Да. | Склад, с которого агент должен забрать груз. Значения атрибута:<ul><li>**Склад**: указывает, что точка является складом.</li><li>**Время готовности груза**: время, необходимое для подготовки груза на складе.</li><li>**Время на погрузку в минутах**: время, необходимое для погрузки груза на складе, в минутах.</li></ul> |
   | `Текстовое поле` | Нет. | Однострочный текст. |
   | `Многострочный текст` | Нет. | Многострочный текст. |
   | `Телефон` | Нет. | Номер телефона. |
   | `Числовое поле` | Нет. | Числовое значение. |
   | `Email` | Нет. | Адрес электронной почты. |
   | `Чекбокс` | Нет. | Логическое значение. |
   | `Справочник` | Нет. | Используется для выбора объектов [справочника](/logistics/administrator/managing/directories) при создании задачи. Значения атрибута:<ul><li>Справочник.</li><li>**Разрешить множественный выбор**: чтобы разрешить выбирать несколько значений из справочника при создании задачи, отметьте чекбокс.</li></ul> |
   | `Название` | Нет. | Имя или наименование задачи. |
   | `Описание` | Нет. | Текстовое описание задачи. |
   | `Груз` | Нет. | Груз, который нужно перевезти. Значения атрибута:<ul><li>**Количество мест**: количество мест под груз.</li><li>**Вес в кг**: вес груза в килограммах.</li><li>**Объём в м³**: объём груза в кубических метрах.</li><li>**Габариты в метрах**: габариты груза в метрах.</li></ul><br />На основе значений этих параметров рассчитывается загрузка агента в процентах в [маршрутных планах](/logistics/administrator/routes#viewing-plan), если для агентов указаны значения для параметров с типом **Вместимость**. Подробнее о расчёте загрузки см. в разделе [Создание шаблона агента](#creating-agent-template). |
   | `Навыки` | Нет. | Используется для выбора [навыков](/logistics/administrator/managing/skills) при создании задачи. |
   | `Контактное лицо` | Нет. | Значения атрибута:<ul><li>**Имя**: имя контактного лица.</li><li>**Телефон**: номер телефона контактного лица.</li><li>**Email**: адрес электронной почты контактного лица.</li></ul> |
   | `Отчёт при завершении работы` | Нет. | Используется для отправки отчёта агентом в мобильном приложении. Файлы будут доступны для просмотра в веб-панели администратора. Значения атрибута:<ul><li>**Вложения**: поля, которые агент должен заполнить при завершении задачи в мобильном приложении:<ul><li>**Только фото с камеры**: отправка фото, сделанного камерой устройства.</li><li>**Файлы**: отправка фото с камеры, выбор фото из галереи или прикрепление файлов в форматах PDF, DOC, DOCX, XLS и XLSX.</li></ul></li><li>**Обязательное для закрытия**: чтобы агент не мог завершить задачу без отправки отчёта, отметьте чекбокс.</li></ul> |
   | `Файлы` | Нет. | Используется для прикрепления файлов (фото и документов) в форматах JPG, JPEG, PNG, PDF, DOC, DOCX, XLS и XLSX к задаче. Вы можете прикрепить до 10 файлов общим объёмом до 10 МБ. Файлы будут доступны для просмотра в веб-панели администратора и в мобильном приложении. |

7. Нажмите **Сохранить**.

## Редактирование шаблона {#editing-template}

:::warning

Редактирование шаблона (например, его атрибутов) изменяет настройки всех агентов или задач, созданных по этому шаблону.

:::

Вы можете:

* переименовать шаблон;
* изменить список атрибутов, их названия, тип и обязательность для заполнения;
* дополнительно для шаблонов агентов: изменить вид иконки агента на карте.

<br />

Чтобы отредактировать шаблон:

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в шаблон.
4. Нажмите **Сохранить**.

## Дублирование шаблона {#duplicating-template}

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Дублировать**.
3. (Опционально) Внесите изменения в шаблон.
4. Нажмите **Сохранить**.
