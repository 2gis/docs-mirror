# Агенты

**Агенты** выполняют рабочие задачи и используются при создании маршрутных планов. Агентами могут быть мобильные сотрудники (например, операторы и курьеры), спецтехника и т. д.

Перед созданием агентов [создайте шаблон агента](/logistics/administrator/managing/templates#creating-agent-template) или выберите тип агента из предзаполненных шаблонов. Шаблон содержит набор атрибутов, которые указываются при создании агента. Вы можете создать агентов в процессе [создания плана](/logistics/administrator/routes#creating-plan).

В роли **Главный администратор** и **Администратор компании** вы можете работать с агентами на вкладке **Управление → Агенты**:

* [создавать агентов](#creating-agent),
* [просматривать информацию об агентах](#viewing-agent),
* [редактировать информацию об агентах](#editing-agent),
* [дублировать агентов](#duplicating-agent),
* [удалять агентов](#deleting-agent).

В роли **Диспетчер** вы можете просматривать список агентов и информацию о них.

![Работа с агентами](/img/geoflow/managing-agents-698.png)

## Создание агента {#creating-agent}

1. Перейдите на вкладку **Управление → Агенты**.
2. Нажмите **Добавить агента**.
3. Выберите [шаблон агента](/logistics/administrator/managing/templates#creating-agent-template).
4. Укажите основные данные агента, которые зависят от выбранного шаблона:

   ![Создание агента](/img/geoflow/creating-agent-data-698.png)

   * **Наименование**: уникальный идентификатор агента. Поле может иметь другое название в зависимости от [шаблона агента](/logistics/administrator/managing/templates#creating-agent-template), например `Идентификатор`.
   * **Транспорт**: тип транспорта агента. Поле может иметь другое название в зависимости от шаблона агента.
   * **Источник локации**: нажмите **Добавить источник** и выберите один из типов источников локации:

      * **Приложение**: выберите пользователя, который использует мобильное приложение и будет привязан к агенту.
      * **EGTS-трекер**: чтобы привязать к агенту устройство, используйте решение [2ГИС ГеоПоток](/geoflow/overview) вместе с 2ГИС Логистикой. В общей веб-панели администраторы смогут [отслеживать местоположение агентов](/geoflow/administrator/monitoring).

      Вы можете выбрать несколько источников локации для одного агента, но каждый источник может быть одновременно привязан только к одному агенту.

      Чтобы добавить источник, нажмите **Добавить источник**. Чтобы удалить источник, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с ним.

5. Укажите другие атрибуты, которые зависят от шаблона агента.
6. Укажите график работы агента:

   ![Создание агента](/img/geoflow/creating-agent-schedule-698.png)

   * **Часовой пояс**: часовой пояс, в котором указывается время работы агента.
   * **Дни работы**: дни недели, в которые работает агент.
   * **Рабочее время**: временной интервал, в который работает агент. Чтобы добавить интервал работы, нажмите **Добавить интервал** и введите время. Чтобы удалить интервал, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с ним.
   * **Жёсткое временное окно**: отметьте чекбокс, если агент может работать только в указанное время. Если параметр указан, агенту нельзя назначать задачу раньше или позже.

7. Нажмите **Сохранить**.

## Просмотр информации об агенте {#viewing-agent}

1. Перейдите на вкладку **Управление → Агенты**.
2. Откройте карточку агента. Вы можете искать агентов по идентификатору и фильтровать их по типу (шаблону) агента.

В карточке агента отображается:

* **Основные данные**:

   * **Наименование**: уникальный идентификатор, указанный при создании агента. Поле может иметь другое название в зависимости от шаблона агента, например `Идентификатор`.
   * **Транспорт**: тип транспорта, указанный при создании агента. Поле может иметь другое название в зависимости от шаблона агента.
   * **Источник локации**: источники, с помощью которых собираются данные о местоположении агента (мобильное приложение или трекер).

      * **Приложение**: имя пользователя, который использует мобильное приложение и привязан к агенту.
      * **EGTS-трекер**: название и уникальный идентификатор устройства. Отображается, если вы используете решение [2ГИС ГеоПоток](/geoflow/overview).
      * **Сигнал**: текущий статус GPS-сигнала на источнике локации агента.
      * **Последняя активность**: время последней активности агента. Для агентов, использующих мобильное приложение, это время последнего входа в мобильное приложение. Для агентов, использующих трекер, это время последнего получения данных о местоположении.
      * **Посмотреть историю перемещений**: нажмите, чтобы открыть на карте текущую геопозицию агента и историю его перемещений.

   * **Дата создания**: дата и время создания агента.
   * **Последнее изменение**: дата и время последнего обновления информации об агенте.

      Здесь могут отображаться другие атрибуты, если они были указаны в [шаблоне агента](/logistics/administrator/managing/templates#creating-agent-template).

* **График работы**:

   * **Жёсткое временное окно**: отображается, если было указано при создании агента.
   * **Дни недели**: дни недели, в которые работает агент.
   * **Рабочее время**: время, в которое работает агент.

## Редактирование информации об агенте {#editing-agent}

Вы можете редактировать основные данные, график работы агентов и другие атрибуты, которые зависят от [шаблона агента](/logistics/administrator/managing/templates#creating-agent-template).

1. Перейдите на вкладку **Управление → Агенты**.
2. В строке агента нажмите значок ![Меню агента](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в информацию об агенте.
4. Нажмите **Сохранить**.

## Дублирование агента {#duplicating-agent}

1. Перейдите на вкладку **Управление → Агенты**.
2. В строке агента нажмите значок ![Меню агента](/img/menu-dots-horizontal.svg) и выберите **Дублировать**.
3. (Опционально) Укажите новые параметры агента.
4. Нажмите **Сохранить**.

## Удаление агента {#deleting-agent}

:::warning

Агент будет исключён из маршрутных планов и задач. Восстановить агента после удаления невозможно.

:::

1. Перейдите на вкладку **Управление → Агенты**.
2. В строке агента нажмите значок ![Меню агента](/img/menu-dots-horizontal.svg) и выберите **Удалить**.
3. Подтвердите удаление.
