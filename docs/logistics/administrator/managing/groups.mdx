# Группы агентов

Вы можете объединять [агентов](/logistics/administrator/managing/agents) одного или разных типов (например, операторов и курьеров) в группы.

В роли **Главный администратор**, **Администратор компании** и **Диспетчер** вы можете работать с группами на вкладке **Управление → Группы агентов**:

* [создавать группы](#creating-group),
* [редактировать группы](#editing-group),
* [удалять группы](#deleting-group).

![Работа с группами](/img/geoflow/managing-agent-groups-620.png)

## Создание группы {#creating-group}

![Создание группы агентов](/img/geoflow/creating-agent-group-620.png)

1. Перейдите на вкладку **Управление → Группы агентов**.
2. Нажмите **Добавить группу**.
3. Укажите параметры группы:

   * **Название группы** (обязательный параметр).
   * **Цвет агентов на карте**: цвет иконок агентов из группы на карте. Если агент состоит в нескольких группах, иконка агента будет разноцветной.
   * **Руководитель**: пользователь, который будет руководить группой.
   * **Агенты**: агенты, которые входят в группу.
   
      Чтобы добавить агента, нажмите **Добавить агента** и выберите его. Вы можете добавлять агентов, созданных из разных шаблонов. Чтобы удалить агента из группы, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с ним и подтвердите удаление.

4. Нажмите **Сохранить**.

## Редактирование группы {#editing-group}

Вы можете редактировать группы:

* переименовать группу;
* изменить цвет иконки агентов на карте;
* изменить руководителя группы;
* добавить или удалить агентов из группы.

<br />

Чтобы отредактировать группу:

1. Перейдите на вкладку **Управление → Группы агентов**.
2. В строке группы нажмите значок ![Меню группы](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в группу.
4. Нажмите **Сохранить изменения**.

## Удаление группы {#deleting-group}

При удалении группы её агенты не удаляются из системы. Вы можете добавить этих агентов в другую группу.

1. Перейдите на вкладку **Управление → Группы агентов**.
2. В строке группы нажмите значок ![Меню группы](/img/menu-dots-horizontal.svg) и выберите **Удалить**.
3. Подтвердите удаление.
