# Обзор веб-панели администратора

В веб-панели администратора 2ГИС Логистики пользователи могут управлять агентами (сотрудниками и транспортом) и создавать маршрутные планы.

![Веб-панель администратора](/img/logistics/route-plan-698.png)

Вы можете управлять доступом к веб-панели с помощью ролей пользователей.

## Роли пользователей {#role-model}

* **Сотрудник** — имеет доступ только к [мобильному приложению](/logistics/operator/start) для выполнения задач.
* **Диспетчер** — имеет доступ к информации обо всех группах агентов, может управлять навыками, группами, задачами и маршрутными планами.
* **Администратор компании** — имеет полный доступ к системе, кроме настроек компании.
* **Главный администратор** — выполняет те же функции, что администратор компании, но может быть только один в компании. Роль главного администратора присваивается пользователю, который создал компанию.

## Интерфейс веб-панели {#web-panel-interface}

Работайте со следующими вкладками в веб-панели администратора в зависимости от вашей роли:

* **Маршруты**: для создания и управления маршрутными планами, которые оптимизируют выполнение задач.
* **Задачи**: для создания и управления задачами, которые выполняют агенты.
* **Управление**: для работы с пользователями, справочниками, складами, навыками, шаблонами, агентами и группами агентов.
* **Уведомления**: для просмотра уведомлений о событиях.

Все пользователи веб-панели могут управлять настройками [стиля карты](/logistics/administrator/styles).
