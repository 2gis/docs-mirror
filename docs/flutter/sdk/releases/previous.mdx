# Предыдущие релизы

:::warning

Прекращена поддержка версий SDK, описанных ниже. Используйте [версию 13.0.0 и выше](/flutter/sdk/releases/latest). Cм. инструкции по [миграции с предыдущих версий](/flutter/sdk/releases/migration).

:::

## 12.10.0 (2025-12-19)

### 🌟 Новые возможности

* [Marker.suppressOnOverlap](https://pub.dev/documentation/dgis_mobile_sdk_full/12.10.0/dgis_mobile_sdk/Marker/suppressOnOverlap.html) и [MarkerOptions.suppressOnOverlap](https://pub.dev/documentation/dgis_mobile_sdk_full/12.10.0/dgis_mobile_sdk/MarkerOptions/suppressOnOverlap.html) — свойство для управления видимостью иконки маркера при наложении объектов на карте.
* [SimpleClusterObject.suppressOnOverlap](https://pub.dev/documentation/dgis_mobile_sdk_full/12.10.0/dgis_mobile_sdk/SimpleClusterObject/suppressOnOverlap.html) и [SimpleClusterOptions.suppressOnOverlap](https://pub.dev/documentation/dgis_mobile_sdk_full/12.10.0/dgis_mobile_sdk/SimpleClusterOptions/suppressOnOverlap.html) — свойство для управления видимостью иконки кластерного объекта при наложении объектов на карте.
* [Package.pause()](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/Package/pause.html) — метод для постановки на паузу установки или обновления пакета.

### 🛠 Исправления

* Исправлена ошибка построения офлайн-маршрутов между регионами.
* Из iOS-сборки удалена библиотека `CallKit`, которая использовалась для отслеживания телефонных вызовов при воспроизведении голосовых инструкций в навигаторе.

## 12.8.0 (2025-08-14)

### 🌟 Новые возможности

* Добавлена поддержка армянского языка на карте, в справочнике и при построении маршрутов. Также добавлены голосовые пакеты уведомлений на армянском языке.
* В [TrafficRouter](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficRouter/TrafficRouter.html) добавлена возможность задавать тип поисковика маршрутов (онлайн, офлайн или гибрид) с помощью [RouterType](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/RouterType.html).
* В [NavigationManager](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/NavigationManager/NavigationManager.html) и [RouteEditor](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/RouteEditor/RouteEditor.html) добавлена возможность указывать поисковик маршрутов ([TrafficRouter](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficRouter/TrafficRouter.html)).

### 🛠 Исправления

* Данные о пробках через источник [TrafficSource](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficSource-class.html) теперь не запрашиваются и не обновляются в фоновом режиме приложения.
* Добавлена опция линковщика для установки размера страницы памяти 16 КБ при сборке Android-библиотеки.
* Исправлены визуальные артефакты в [MapWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/MapWidget-class.html), которые возникали при смене конфигурации устройства.
* Исправлены анимации в [SpeedLimitWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SpeedLimitWidget-class.html).
* Исправлено отображение [TrafficLineWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficLineWidget-class.html).

## 12.7.2 (2025-07-07)

### 🌟 Новые возможности

* [DirectoryObject.routeInfos](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DirectoryObject/routeInfos.html) — информация о маршрутах общественного транспорта в объекте справочника.
* [DirectoryObject.publicTransportScheduleInfo](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DirectoryObject/publicTransportScheduleInfo.html) — метод для получения информации о расписаниях платформ общественного транспорта и направлений маршрутов.
* [DirectoryObject.platformIds](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DirectoryObject/platformIds.html) — информация об идентификаторах платформ общественного транспорта в объекте справочника.
* [EntranceInfo.entranceNumber](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/EntranceInfo/entranceNumber.html) — номер входа на станцию общественного транспорта.
* [ItemMarkerInfo.tradeLicense](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/ItemMarkerInfo/tradeLicense.html) — информация о торговой лицензии организации в маркере.
* [SearchQueryBuilder.setSearchNearby](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SearchQueryBuilder/setSearchNearby.html) — метод, который указывает поисковому движку искать объекты рядом с пользователем.
* [SuggestQueryBuilder.setSearchNearby](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SuggestQueryBuilder/setSearchNearby.html) — метод, который указывает поисковому движку искать объекты рядом с пользователем.
* [SearchResult.nearbyRequested](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SearchResult/nearbyRequested.html) — признак в результатах поиска, что при поиске были запрошены объекты поблизости.
* [SearchWidgetColorScheme](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SearchWidgetColorScheme-class.html) — класс для указания цветовой схемы для класса [DgisSearchWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DgisSearchWidget-class.html).
* Добавлена возможность указать сборщики для создания [SearchQuery](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SearchQuery-class.html) и [SuggestQuery](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SuggestQuery-class.html) в классе [DgisSearchWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DgisSearchWidget-class.html).
* [TrafficRoute.routeTollPaymentInfos](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficRoute/routeTollPaymentInfos.html) — информация о стоимости проезда по платным участкам маршрута.
* [RoadMacroGraph](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/RoadMacroGraph-class.html) — пакет глобального дорожного графа будет удалён в следующих версиях. Вы можете строить маршруты между регионами на основе скачанных [офлайн-данных](/flutter/sdk/start#offline-mode).

### 🛠 Исправления

* Улучшена производительность карты для Android и iOS: карта может работать с кадровой частотой 120 FPS.

### 🗺 Изменения в стилях карты

* Заново выгрузите стили: в навигаторе исправлено отображение иммерсивных дорог и тумана.

## 12.6.3 (2025-05-15)

### 🌟 Новые возможности

* Добавлена возможность использовать Flutter SDK на устройствах с операционной системой Аврора. Подробнее см. в разделе [Установка](/flutter/sdk/start#aurora-os).

### 🛠 Исправления

* Оптимизирована работа [TrafficSource](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficSource-class.html):

  * Тайлы с пробками запрашиваются при изменении масштаба карты и по таймеру.
  * Уровень пробок в баллах обновляется при смене региона и по таймеру.

* Улучшена производительность карты при добавлении полигонов с большим количеством вершин через [MapObjectManager](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/MapObjectManager-class.html).

## 12.6.1 (2025-04-21)

### 🌟 Новые возможности

* В источник геопозиции по умолчанию для Android добавлена возможность настроить использование сервиса [Radar API](/api/navigation/radar/overview) для геопозиционирования устройства по точкам доступа Wi-Fi и сотовым вышкам. Настроить использование Radar API можно через [RadarApiSettings](/android/sdk/reference/stable/class#ru.dgis.sdk.positioning.radar.radar-api-settings) и `ru.dgis.sdk.positioning.RadarSettingsProvider` при регистрации Android-плагина. Подробнее см. в разделе [Использование Radar API](/flutter/sdk/examples/navigation#radar-api).
* [File.fromAsset](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/File/fromAsset.html) — метод для загрузки файла из asset-директории приложения.
* [TextStyle.suppressOnOverlap](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TextStyle/suppressOnOverlap.html) — опция для скрытия текста подписи маркера при пересечении с другими объектами.

### 🛠 Исправления

* Исправлено обновление генерализации при изменении атрибутов объектов, добавленных через метод [MapObjectManager.withGeneralization()](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/MapObjectManager/withGeneralization.html).
* Исправлена ошибка, при которой приложение падало при логировании сетевых запросов.

## 12.5.0 (2025-03-25)

### 🌟 Новые возможности

* Исправлена ошибка, при которой маркер местоположения, добавленный через [MyLocationMapObjectSource](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/MyLocationMapObjectSource-class.html), исчезает при первом перелёте камеры.
* Исправлено отображение информации о маршруте на карте при направлении текста справа налево (RTL) для источника данных [RouteEditorSource](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/RouteEditorSource-class.html).
* Изменены настройки кеширования данных из источника на маршруте. Теперь данные кешируются на расстоянии 4000 метров впереди от текущей позиции на маршруте вместо 20000.

### 🗺 Изменения в стилях карты

* Повторно выгрузите стили: исправлено отображение информации о маршруте на карте при направлении текста справа налево.

* Исправлена работа атрибута для управления видимостью объекта на карте [SimpleMapObject.isVisible](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/SimpleMapObject/isVisible.html) при генерализации и кластеризации объектов.
* Доработано отображение [NavigationLayoutWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/NavigationLayoutWidget-class.html) в альбомной ориентации.

### 🗺 Изменения в стилях карты

* Исправлен приоритет обработки нажатий между маркером геопозиции и зданиями на карте.

## 12.3.0 (2024-12-20)

### 🌟 Новые возможности

* [ModelMapObject](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/ModelMapObject-class.html) и [ModelMapObjectOptions](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/ModelMapObjectOptions-class.html) — классы для создания и настройки динамических объектов с 3D-моделями. * Теперь при добавлении [TrafficSource](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficSource-class.html) на карту тайлы с пробками запрашиваются на основе области видимости экрана независимо от обновления конфигурационного файла SDK.
* [DirectoryObject.rubricIds](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/DirectoryObject-class.html) — идентификаторы рубрик в объекте справочника.
* [FreeRoamSelector](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/FreeRoamSelector-class.html) и [NavigationManager.freeRoamSelector](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/NavigationManager-class.html) — возможность включения и выключения перевода навигатора в режим `FreeRoam` при слишком долгом перестроении маршрута.

* [TrafficRouter.requestRoute](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/TrafficRouter-class.html) — возможность поиска маршрута по ранее сериализованным параметрам.
* [NavigationLayoutWidget](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/NavigationLayoutWidget-class.html) — общий UI-элемент для отображения интерфейса навигатора.

### 🛠 Исправления

* Оптимизировано отображение карты на iOS и удалено мигание при слежении за текущим местоположением в навигаторе.
* Исправлено дублирование числа филиалов для категорий организаций в [Suggest.subtitle](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/Suggest-class.html).
* Исправлена ошибка получения координат объекта при обработке клика на [Marker](https://pub.dev/documentation/dgis_mobile_sdk_full/latest/dgis_mobile_sdk/Marker-class.html), добавленный на карту перед первичной загрузкой карты.
* Исправлено отображение 3D-модели маркера геопозиции навигатора для всех типов маршрута, кроме пешеходного. Для пешеходного маршрута отображается обычная модель маркера геопозиции.
* Обновлена конфигурация навигатора для улучшения работы при плохом сигнале GPS.

### 🗺 Изменения в стилях карты

* Добавлен слой для отображения динамических 3D-моделей.
