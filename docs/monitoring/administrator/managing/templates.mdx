# Шаблоны

**Шаблоны** — это подготовленные наборы атрибутов для создания [агентов](/monitoring/administrator/managing/agents), [задач](/monitoring/administrator/tasks) и [объектов](/monitoring/administrator/managing/objects). Шаблоны позволяют:

* создавать типовых агентов (например, курьеров), типовые задачи (например, задачи по доставке) и типовые объекты (например, здания);
* фильтровать агентов и задачи по типу при планировании [смен](/monitoring/administrator/shifts);
* фильтровать агентов по типу и просматривать метрики эффективности агентов на дашборде [мониторинга](/monitoring/administrator/monitoring);
* фильтровать объекты по типу на дашборде [мониторинга](/monitoring/administrator/monitoring) и в [мобильном приложении](/monitoring/operator/overview) с помощью слоёв.

В роли **Главный администратор** и **Администратор компании** вы можете работать с шаблонами на вкладке **Управление → Шаблоны**:

* создавать шаблоны [агентов](#creating-agent-template), [задач](#creating-task-template) и [объектов](#creating-object-template);
* [редактировать шаблоны](#editing-template);
* [дублировать шаблоны](#duplicating-template).

В роли **Диспетчер** и **Руководитель группы агентов** вы можете просматривать список шаблонов и информацию о них.

## Создание шаблона агента {#creating-agent-template}

![Создание шаблона агента](/img/monitoring/creating-agent-template-744.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. В выпадающем списке выберите **Агент**.
4. Чтобы создать собственный шаблон агента, оставьте поле **Предзаполнить из набора** пустым. Чтобы использовать предзаполненный шаблон, выберите в этом поле один из готовых типов агентов:

   * **Оператор**: сотрудник, выполняющий задачи.
   * **Курьер**: сотрудник, доставляющий документы или посылки.
   * **Спецтехника**: транспортные средства или машины, выполняющие работы. Например, курьерский автомобиль, бензовоз, экскаватор и т. д.

   Параметры ниже заполнятся автоматически для выбранного типа. При необходимости вы можете отредактировать их.

5. В поле **Метрика агента** выберите метрику, которая будет использоваться для расчёта эффективности агента и отображаться при [мониторинге](/monitoring/administrator/monitoring) смены в карточке агента на вкладке **Метрики**:

   * **Отключена**: данные об эффективности агента отображаться не будут.
   * **Эффективность выполнения задач**: отношение количества задач, выполненных за смену, к количеству задач, назначенных в смене.
   * **Эффективность работы**: отношение времени, когда агент находился в геозонах, к времени, которое прошло от начала смены.

6. В поле **Название** введите общее название для типа агентов.
7. (Опционально) В блоке **Вид на карте** укажите отображение иконки агентов на карте. Нажмите на превью карты и укажите параметры:

   * **Иконка**: иконка агента.
   * **Цвет**: цвет иконки.

   Нажмите **Сохранить**.

8. В блоке **Атрибуты** укажите список полей для создания агентов этого типа. Некоторые атрибуты обязательны и добавляются в шаблон автоматически. Для всех атрибутов вы можете отметить чекбокс **Обязательное поле**, чтобы сделать их обязательными для создания агента.

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

   | **Тип данных** | **Обязательный атрибут** | **Описание** |
   | --- | --- | --- |
   | `Текстовое поле` | Необходим один атрибут для обозначения уникального идентификатора агента (например, табельный номер или ФИО). | Однострочный текст. |
   | `Транспорт` | Да. | Транспортное средство агента: велосипед, легковой автомобиль, самокат, пешком или грузовой автомобиль. |
   | `Многострочный текст` | Нет. | Многострочный текст. |
   | `Числовое поле` | Нет. | Числовое значение. |
   | `Чекбокс` | Нет. | Логическое значение. |
   | `Телефон` | Нет. | Номер телефона. |
   | `Email` | Нет. | Адрес электронной почты. |
   | `Справочник` | Нет. | Используется для выбора объектов [справочника](/monitoring/administrator/managing/directories) при создании агента. Значения атрибута:<ul><li>Справочник.</li><li>**Разрешить множественный выбор**: чтобы разрешить выбирать несколько значений из справочника при создании агента, отметьте чекбокс.</li></ul> |
   | `Навыки` | Нет. | Используется для выбора [навыков](/monitoring/administrator/managing/skills) при создании агента. |

9. Нажмите **Сохранить**.

## Создание шаблона задачи {#creating-task-template}

![Создание шаблона задачи](/img/monitoring/creating-task-template-744.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. В выпадающем списке выберите **Задача**.
4. Чтобы создать собственный шаблон задачи, оставьте поле **Предзаполнить из набора** пустым. Чтобы использовать предзаполненный шаблон, выберите в этом поле готовый тип задачи **Стандартный**.

   Параметры ниже заполнятся автоматически для выбранного типа. При необходимости вы можете отредактировать их.

5. В поле **Название** введите общее название для типа задач.
6. В блоке **Атрибуты** укажите список полей для создания задач этого типа. Некоторые атрибуты обязательны и добавляются в шаблон автоматически. Для всех атрибутов вы можете отметить чекбокс **Обязательное поле**, чтобы сделать их обязательными для создания задачи.

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

   | **Тип данных** | **Обязательный атрибут** | **Описание** |
   | --- | --- | --- |
   | `Дата и время` | Да. | Дата и время выполнения задачи. Чтобы ограничить время выполнения задачи, включите **Время на задачу в минутах**. |
   | `Текстовое поле` | Нет. | Однострочный текст. |
   | `Многострочный текст` | Нет. | Многострочный текст. |
   | `Телефон` | Нет. | Номер телефона. |
   | `Числовое поле` | Нет. | Числовое значение. |
   | `Email` | Нет. | Адрес электронной почты. |
   | `Чекбокс` | Нет. | Логическое значение. |
   | `Справочник` | Нет. | Используется для выбора объектов [справочника](/monitoring/administrator/managing/directories) при создании задачи. Значения атрибута:<ul><li>Справочник.</li><li>**Разрешить множественный выбор**: чтобы разрешить выбирать несколько значений из справочника при создании задачи, отметьте чекбокс.</li></ul> |
   | `Название` | Нет. | Имя или наименование задачи. |
   | `Описание` | Нет. | Текстовое описание задачи. |
   | `Местоположение` | Нет. | Пункт назначения (местоположение): геозона, координаты или адрес. |
   | `Навыки` | Нет. | Используется для выбора [навыков](/monitoring/administrator/managing/skills) при создании задачи. |
   | `Контактное лицо` | Нет. | Значения атрибута:<ul><li>**Имя**: имя контактного лица.</li><li>**Телефон**: номер телефона контактного лица.</li><li>**Email**: адрес электронной почты контактного лица.</li></ul> |
   | `Отчёт при завершении работы` | Нет. | Используется для отправки отчёта агентом в мобильном приложении. Файлы будут доступны для просмотра в веб-панели администратора. Значения атрибута:<ul><li>**Вложения**: поля, которые агент должен заполнить при завершении задачи в мобильном приложении:<ul><li>**Только фото с камеры**: отправка фото, сделанного камерой устройства.</li><li>**Файлы**: отправка фото с камеры, выбор фото из галереи или прикрепление файлов в форматах PDF, DOC, DOCX, XLS и XLSX.</li></ul></li><li>**Обязательное для закрытия**: чтобы агент не мог завершить задачу без отправки отчёта, отметьте чекбокс.</li></ul> |
   | `Файлы` | Нет. | Используется для прикрепления файлов (фото и документов) в форматах JPG, JPEG, PNG, PDF, DOC, DOCX, XLS и XLSX к задаче. Вы можете прикрепить до 10 файлов общим объёмом до 10 МБ. Файлы будут доступны для просмотра в веб-панели администратора и в мобильном приложении. |

7. Нажмите **Сохранить**.

## Редактирование шаблона {#editing-template}

:::warning

Редактирование шаблона (например, его атрибутов) изменяет настройки всех агентов, задач или объектов, созданных по этому шаблону.

:::

Вы можете:

* Переименовать шаблон.
* Изменить список атрибутов, их названия, тип и обязательность для заполнения.
* Дополнительно для шаблонов агентов: изменить метрику агента. Показатели эффективности по новой метрике будут рассчитываться с начала следующей смены.
* Дополнительно для шаблонов агентов и объектов: изменить вид иконки на карте.

<br />

Чтобы отредактировать шаблон:

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в шаблон.
4. Нажмите **Сохранить**.

## Дублирование шаблона {#duplicating-template}

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Дублировать**.
3. (Опционально) Внесите изменения в шаблон.
4. Нажмите **Сохранить**.
