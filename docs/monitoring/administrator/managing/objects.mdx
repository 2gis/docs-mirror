# Объекты

**Объекты** — это реальные объекты инфраструктуры, которые вы можете отмечать на карте и отображать в виде слоёв. Объектами могут быть здания, сооружения, скважины и т. д.

Перед созданием объектов [создайте шаблон объекта](/monitoring/administrator/managing/templates#creating-object-template). Шаблон содержит набор атрибутов, которые указываются при создании объекта.

В роли **Главный администратор** и **Администратор компании** вы можете работать с объектами на вкладке **Управление → Объекты**:

* [создавать объекты](#creating-object),
* [просматривать информацию об объектах](#viewing-object),
* [редактировать объекты](#editing-object),
* [дублировать объекты](#duplicating-object),
* [удалять объекты](#deleting-object).

В роли **Диспетчер** и **Руководитель группы агентов** вы можете просматривать список объектов и информацию о них.

## Создание объекта {#creating-object}

![Создание объекта](/img/monitoring/creating-object-744.png)

1. Перейдите на вкладку **Управление → Объекты**.
2. Нажмите **Добавить объект**.
3. Выберите или создайте шаблон объекта. Чтобы создать шаблон, нажмите **Добавить шаблон объекта**: подробнее см. в разделе [Создание шаблона объекта](/monitoring/administrator/managing/templates#creating-object-template).
4. Укажите обязательные параметры объекта:

   * **Наименование**: уникальный идентификатор объекта. Поле может иметь другое название в зависимости от [шаблона объекта](/monitoring/administrator/managing/templates#creating-object-template), например `Идентификатор`.
   * **Местоположение**: укажите адрес объекта одним из способов:

      * Отметьте точку на карте. Вы можете переместить значок маркера в любое место на карте.
      * Введите адрес объекта в поле и выберите вариант из выпадающего списка.
      * Введите координаты объекта в формате `долгота, широта` (например, `37.607132,55.7680412`).
   
5. Укажите другие атрибуты, которые зависят от шаблона объекта.
6. Нажмите **Сохранить**.

## Просмотр информации об объекте {#viewing-object}

1. Перейдите на вкладку **Управление → Объекты**.
2. Откройте карточку объекта. Вы можете фильтровать объекты по типу (шаблону) объекта.

В карточке объекта отображается:

* **Наименование**: уникальный идентификатор, указанный при создании объекта. Поле может иметь другое название в зависимости от шаблона объекта, например `Идентификатор`.
* **Местоположение**:
   * **Координаты**: координаты объекта.
   * **Адрес**: адрес объекта.
* **Дополнительно**: здесь могут отображаться другие атрибуты, если они были указаны в [шаблоне объекта](/monitoring/administrator/managing/templates#creating-object-template).

## Редактирование объекта {#editing-object}

Вы можете редактировать наименование, местоположение и другие атрибуты, которые зависят от [шаблона объекта](/monitoring/administrator/managing/templates#creating-object-template).

1. Перейдите на вкладку **Управление → Объекты**.
2. В строке объекта нажмите значок ![Меню объекта](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в информацию об объекте.
4. Нажмите **Сохранить**.

## Дублирование объекта {#duplicating-object}

1. Перейдите на вкладку **Управление → Объекты**.
2. В строке объекта нажмите значок ![Меню объекта](/img/menu-dots-horizontal.svg) и выберите **Дублировать**.
3. (Опционально) Внесите изменения в информацию об объекте.
4. Нажмите **Сохранить**.

## Удаление объекта {#deleting-object}

:::warning

Восстановить объект после удаления невозможно.

:::

1. Перейдите на вкладку **Управление → Объекты**.
2. В строке объекта нажмите значок ![Меню объекта](/img/menu-dots-horizontal.svg) и выберите **Удалить**.
3. Подтвердите удаление.
