# Обзор мобильного приложения

Мобильное приложение 2ГИС ГеоПоток: Мониторинг позволяет сотрудникам просматривать карту и список своих задач.

Мобильное приложение записывает данные о перемещениях агента (сотрудника или транспорта) в течение смены. Эти данные позволяют администраторам отслеживать перемещения агентов в реальном времени и анализировать их историю в веб-панели: см. [Руководство администратора](/monitoring/administrator/overview).

:::tip[2ГИС ГеоПоток: Логистика]

Если 2ГИС ГеоПоток: Мониторинг используется вместе с [2ГИС ГеоПоток: Логистикой](/logistics/overview), то в мобильном приложении сотрудники могут использовать навигатор для построения маршрута: см. [Руководство сотрудника 2ГИС ГеоПоток: Логистика](/logistics/operator/overview).

:::

## Интерфейс приложения {#application-interface}

В роли **Сотрудник** вы можете работать со следующими вкладками в мобильном приложении:

* **[Карта](/monitoring/operator/map)**: для просмотра карты и информации об агентах, сменах и объектах инфраструктуры.
* **[Задачи](/monitoring/operator/tasks)**: для просмотра задач на сменах и работы с ними. Задачи и смены создают пользователи с ролями **Главный администратор**, **Администратор компании** и **Диспетчер** в веб-панели: подробнее см. в [Руководстве администратора](/monitoring/administrator/tasks).
* **[Профиль](/monitoring/operator/settings)**: для просмотра уведомлений и управления настройками.
