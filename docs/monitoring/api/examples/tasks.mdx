# Задачи

Вы можете создавать **задачи** для агентов, например: доставить груз, провести инспекцию и т. д. Подробнее о задачах см. в разделе [Задачи](/monitoring/administrator/tasks) Руководства администратора.

## Получение списка задач {#getting-tasks-list}

Вы можете получить список задач с данными о них: ID задачи, ID шаблона, статусом, датой и временем создания и обновления и списком атрибутов.

Чтобы получить список задач, отправьте GET-запрос к [/v1/tasks](/monitoring/api/reference/tasks#tag/tasks/operation/listTasks) с параметром `limit` — максимальным количеством задач в ответе от 1 до 100.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/tasks?limit=2' \
   --header 'Authorization: Bearer <token>'
```

## Получение задачи по ID {#getting-task}

Вы можете получить данные задачи по её идентификатору: ID шаблона, статус, дату и время создания и обновления и список атрибутов.

Чтобы получить данные задачи, отправьте GET-запрос к [`/v1/tasks/{id}`](/monitoring/api/reference/tasks#tag/tasks/operation/getTask), где `{id}` — идентификатор задачи.

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/tasks/402ed0c2-e7a5-404e-bee2-e1695ec65bb2' \
   --header 'Authorization: Bearer <token>'
```

## Создание задачи {#creating-task}

Чтобы создать задачу, отправьте POST-запрос к [/v1/tasks](/monitoring/api/reference/tasks#tag/tasks/operation/createTask) со следующими параметрами:

* `template_id` (обязательный параметр) — ID [шаблона задачи](/monitoring/api/examples/templates).
* `attributes` (обязательный параметр) — список атрибутов задачи. Каждый объект `data` должен содержать:

   * `attribute_id` (обязательный параметр) — ID атрибута, указанный в [шаблоне задачи](/monitoring/api/examples/templates#getting-task-template).
   * `type` (обязательный параметр) — тип атрибута, указанный в [шаблоне задачи](/monitoring/api/examples/templates#getting-task-template).
   * `value` — значение атрибута.

**Пример запроса:**

```bash
curl --request POST \
   --url 'https://geoflow.2gis.ru/public/api/v1/tasks' \
   --header 'Authorization: Bearer <token>' \
   --header 'Content-Type: application/json' \
   --data '{
      "template_id": "eaacda1f-251e-40a5-9d2d-b4cba2d462c3",
      "attributes": [
         {
            "data": {
               "attribute_id": "d227f3d3-0c17-409e-9820-8e4f713be6e6",
               "type": "name",
               "value": "Задача"
            }
         },
         {
            "data": {
               "attribute_id": "bc53e352-f052-4a40-bea6-8c5267541430",
               "type": "time_windows_settings",
               "value": {
                  "timezone": "Europe/Moscow",
                  "time_windows": [
                     {
                        "from": "2026-09-20T09:00:00Z",
                        "to": "2026-09-20T12:00:00Z"
                     }
                  ]
               }
            }
         }
      ]
   }'
```

## Обновление задачи {#updating-task}

Чтобы обновить данные задачи, отправьте PUT-запрос к [`/v1/tasks/{id}`](/monitoring/api/reference/tasks#tag/tasks/operation/updateTask), где `{id}` — идентификатор задачи, и передайте в теле запроса новые данные.

**Пример запроса:**

```bash
curl --request PUT \
   --url 'https://geoflow.2gis.ru/public/api/v1/tasks/da6e2e9b-3152-4425-a330-abb1fca5956b' \
   --header 'Authorization: Bearer <token>' \
   --header 'Content-Type: application/json' \
   --data '{
      "id": "da6e2e9b-3152-4425-a330-abb1fca5956b",
      "attributes": [
         {
            "data": {
               "attribute_id": "d227f3d3-0c17-409e-9820-8e4f713be6e6",
               "type": "name",
               "value": "Задача 1"
            }
         }
      ]
   }'
```

**Пример ответа:**

## Изменение статуса задачи {#updating-task-status}

Чтобы изменить статус задачи, отправьте PUT-запрос к [`/v1/tasks/{id}/status`](/monitoring/api/reference/tasks#tag/tasks/operation/setTaskStatus), где `{id}` — идентификатор задачи, с параметром `status_alias` — новым статусом задачи.

Возможные статусы задач:

* `created` — создана,
* `ready` — готова к выполнению,
* `in_progress` — выполняется,
* `completed` — выполнена,
* `cancelled` — отменена.

**Пример запроса:**

```bash
curl --request PUT \
   --url 'https://geoflow.2gis.ru/public/api/v1/tasks/d510b69a-ce4b-4c6f-bd8b-76c1da962a84/status' \
   --header 'Authorization: Bearer <token>' \
   --header 'Content-Type: application/json' \
   --data '{
    "status_alias": "completed"
  }'
```
