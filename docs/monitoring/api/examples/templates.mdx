# Шаблоны

**Шаблоны** — это подготовленные наборы атрибутов для создания агентов, задач и объектов. Подробнее о шаблонах см. в разделе [Шаблоны](/monitoring/administrator/managing/templates) Руководства администратора.

С помощью Публичного API вы можете получить список шаблонов. Чтобы создать или изменить шаблон, используйте веб-панель администратора 2ГИС ГеоПоток: Мониторинг.

## Получение списка шаблонов агентов {#getting-agent-templates-list}

Вы можете получить список шаблонов агентов с данными о шаблонах: ID, названием, иконкой агентов на карте, датой и временем создания и обновления и списком атрибутов.

Чтобы получить список шаблонов агентов, отправьте GET-запрос к [/v1/agent-templates](/monitoring/api/reference/agent-templates#tag/agent-templates/operation/listAgentTemplates) с параметром `limit` — максимальным количеством шаблонов в ответе от 1 до 100.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/agent-templates?limit=2' \
   --header 'Authorization: Bearer <token>'
```
