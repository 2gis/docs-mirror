# Мониторинг

Вы можете получать актуальное местоположение агентов и историю их перемещений с событиями входа в геозоны и потери сигнала. Подробнее о мониторинге агентов см. в разделе [Мониторинг](/monitoring/administrator/monitoring) Руководства администратора.

## Получение последних местоположений агентов {#last-locations}

Вы можете получить последние известные координаты местоположения агентов и статус GPS-сигнала на источнике данных о местоположении.

Метод предназначен для поллинга данных: чтобы проверить наличие новых данных, отправьте запрос. Вы можете запрашивать местоположения агентов только за последние 24 часа.

Статусы сигнала могут быть следующими:

* `online` — сигнал и данные о местоположении доступны.
* `signal_lost` — сигнал потерян, данные о местоположении недоступны.

Чтобы получить последние местоположения агентов, отправьте GET-запрос к [/v1/monitoring/agents/last-locations](/monitoring/api/reference/monitoring#tag/monitoring/operation/listAgentLastLocations) с параметром `last_update_at` — датой и временем в формате RFC 3339. В ответе вернутся местоположения, обновлённые после этого момента.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/monitoring/agents/last-locations?last_update_at=2026-09-16T12:00:00Z' \
   --header 'Authorization: Bearer <token>'
```

## Получение истории перемещений агента {#agent-timeline}

Чтобы получить историю перемещений агента в заданном интервале, отправьте GET-запрос к [`/v1/monitoring/agents/{id}/timeline`](/monitoring/api/reference/monitoring#tag/monitoring/operation/getAgentTimeline), где `{id}` — идентификатор агента, со следующими параметрами:

* `from` (обязательный параметр) — дата и время начала интервала в формате RFC 3339.
* `to` (обязательный параметр) — дата и время окончания интервала в формате RFC 3339.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/monitoring/agents/018f2e6b-1c2a-7b3e-9c4d-5e6f7a8b9c0d/timeline?from=2026-09-17T00%3A00%3A00Z&to=2026-09-17T23%3A59%3A59Z' \
   --header 'Authorization: Bearer <token>'
```

**Пример ответа:**
