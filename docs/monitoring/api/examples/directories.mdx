# Справочники

**Справочники** — это группы признаков, которые содержат дополнительную справочную информацию об агентах или задачах. Подробнее о справочниках см. в разделе [Справочники](/monitoring/administrator/managing/directories) Руководства администратора.

## Получение списка справочников {#getting-directories-list}

Вы можете получить список справочников с данными о них: ID, названием, датой и временем создания и обновления, а также списком объектов справочника.

Чтобы получить список справочников и их объектов, отправьте GET-запрос к [/v1/dictionaries](/monitoring/api/reference/directories#tag/dictionaries/operation/listDictionaries) с параметром `limit` — максимальным количеством справочников в ответе от 1 до 100.

**Пример запроса:**

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/dictionaries?limit=2' \
   --header 'Authorization: Bearer <token>'
```
