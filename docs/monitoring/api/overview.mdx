# Обзор

Публичный API помогает автоматизировать работу с 2ГИС ГеоПоток: Мониторинг и получать данные мониторинга.

## Основные возможности {#main-features}

С помощью Публичного API вы можете:

* Создавать пользователей мобильного приложения и отправлять им приглашения, а также синхронизировать агентов и учётные записи пользователей мобильного приложения.
* Просматривать справочники, навыки и их данные.
* Просматривать шаблоны агентов и задач. Создание и изменение шаблонов агентов и задач через Публичный API недоступно, для этого используйте [веб-панель администратора](/monitoring/administrator/managing/templates).
* Создавать и удалять агентов, просматривать и обновлять их данные.
* Создавать задачи, просматривать и обновлять их данные, изменять статус.
* Планировать и удалять смены, просматривать и обновлять их данные, добавлять задачи и назначать агентов.
* Получать последние местоположения агентов и историю их перемещений.

Подробнее см. в [примерах](/monitoring/api/examples/users) и в [Справочнике API](/monitoring/api/reference/token).

## Начало работы {#getting-started}

### Получение токена доступа {#getting-access-token}

Вы можете отправлять запросы к [/v1/healthcheck](/monitoring/api/reference/healthcheck#tag/health/operation/healthcheck) и [/oauth/token](/monitoring/api/reference/token#tag/oauth/operation/exchangeToken) без токена. Для работы с остальными endpoint-ами получите Bearer-токен доступа. Для получения токена нужно создать учётные данные (Client ID и Client Secret), так как запросы к API выполняются не от имени пользователя, а от имени организации.

1. Чтобы активировать возможность создания учётных данных, обратитесь к менеджеру <Brand />.
2. Откройте веб-панель администратора 2ГИС ГеоПоток: Мониторинг.

   <CtaButton href="https://geoflow.2gis.ru/" target="_blank">
      Открыть 2ГИС ГеоПоток: Мониторинг
   </CtaButton>

3. Перейдите на вкладку **Компания**.
4. Нажмите **Добавить учётные данные**.
5. Укажите параметры учётных данных:

   * **Название** (обязательный параметр).
   * **Окончание действия**: дата и время, когда пара Client ID и Client Secret перестанет действовать. Доступ к ним закроется автоматически. Чтобы сделать срок действия неограниченным, оставьте поле пустым.

   ![Создание учётных данных](/img/monitoring/issuing-credentials.png)

6. Нажмите **Добавить**.
7. Чтобы скопировать значение Client Secret, нажмите **Скопировать**. Скопировать его повторно нельзя. При потере Client Secret создайте новые учётные данные.

   Пример учётных данных:

   ```bash
   {
      "client_id": "7e1*****2f1",
      "client_secret": "Rd5*****Lxc"
   }
   ```

8. Чтобы выпустить токен доступа, отправьте POST-запрос к [/oauth/token](/monitoring/api/reference/token#tag/oauth/operation/exchangeToken):

   ```bash
   curl --request POST \
      --url 'https://geoflow.2gis.ru/public/api/oauth/token' \
      --header 'Content-Type: application/x-www-form-urlencoded' \
      --data 'grant_type=client_credentials' \
      --data 'client_id=<client_id>' \
      --data 'client_secret=<client_secret>'
   ```

   Где:

   * `grant_type=client_credentials` — тип авторизации.
   * `client_id` и `client_secret` — значения, полученные при создании учётных данных.

<br />

Передавайте полученный токен в заголовках запросов:

```http
Authorization: Bearer <token>
```

:::warning

Токен доступа имеет ограниченное время жизни. Срок действия в секундах возвращается в поле `expires_in` ответа при POST-запросе к `/oauth/token`. В настоящее время он составляет пять минут. После истечения срока или при ответе `401` на защищённый метод получите новый токен.

:::

### Пример запроса {#request-example}

Например, чтобы получить список навыков, отправьте GET-запрос к `/v1/skills`:

```bash
curl --request GET \
   --url 'https://geoflow.2gis.ru/public/api/v1/skills?limit=3' \
   --header 'Authorization: Bearer <token>'
```

В запросе укажите `token` — значение токена доступа.

## Управление учётными данными {#managing-credentials}

![Работа с учётными данными](/img/monitoring/managing-credentials.png)

### Изменение учётных данных {#editing-credentials}

Вы можете изменить название и срок действия пары Client ID и Client Secret. Изменить сами значения нельзя, поэтому при необходимости создайте новые учётные данные.

1. Перейдите на вкладку **Компания**.
2. В строке учётных данных нажмите значок ![Меню данных](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения.
4. Нажмите **Сохранить**.

### Отзыв учётных данных {#revoking-credentials}

При отзыве учётных данных вы не сможете использовать их для получения токена доступа.

1. Перейдите на вкладку **Компания**.
2. В строке учётных данных нажмите значок ![Меню данных](/img/menu-dots-horizontal.svg) и выберите **Отозвать**.
3. Подтвердите отзыв учётных данных.
