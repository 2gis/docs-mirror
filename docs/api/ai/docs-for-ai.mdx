# Документация для AI

Документация API-платформы 2ГИС доступна не только на сайте [docs.2gis.com](https://docs.2gis.com/), но и в проекте [2GIS Platform Documentation](https://context7.com/2gis/docs-mirror) в Context7. Проект позволяет AI-агентам получать сведения об API и SDK 2ГИС непосредственно во время работы над задачей.

[Context7](https://context7.com/docs/overview) — сервис, который добавляет в контекст AI-агента релевантные фрагменты документации и примеры кода из проиндексированных источников. Агент может обращаться к документации при подготовке кода или ответа, а вам не нужно вручную переносить в запрос содержимое отдельных страниц.

:::note[Внешний сервис]

Context7 является внешним сервисом. Порядок подключения и условия его использования могут меняться, проверяйте их в [официальной документации Context7](https://context7.com/docs/overview).

Актуальная и достоверная информация о продуктах 2ГИС содержится в официальной документации на [docs.2gis.com](https://docs.2gis.com/). Рекомендуется сверять ответы AI-агента с этим источником.

:::

## Подключение {#connect}

1. Подключите Context7 к вашему AI-агенту по [инструкции](https://context7.com/docs/resources/all-clients).
2. При формулировке задачи укажите агенту проект документации 2ГИС: `/2gis/docs-mirror`. Примеры:

    ```text
    Напиши запрос к Places API для поиска всех кафе в Москве в радиусе 3км от Курского вокзала, которые открыты сегодня в 21:00. Используй context7 и проект /2gis/docs-mirror.
    ```

    ```text
    Используй context7 и проект /2gis/docs-mirror: какой API мне нужен, чтобы построить маршрут для грузовика с учетом его габаритов?
    ```

## Context7 и MCP-сервер 2ГИС {#context7-and-mcp-server}

Context7 предоставляет AI-агенту документацию, но не выполняет запросы к API 2ГИС и не возвращает геоданные. Для поиска организаций, построения маршрутов и работы с картами через AI-агента используйте [MCP-сервер 2ГИС](/api/ai/mcp-server).

Эти инструменты можно применять вместе: Context7 помогает агенту разобраться в документации и подготовить интеграцию, а MCP-сервер 2ГИС предоставляет инструменты для обращения к API.
