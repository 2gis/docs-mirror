# MCP-сервер API-платформы 2ГИС

MCP-сервер API-платформы 2ГИС предоставляет ИИ-агентам доступ к геоданным 2ГИС: картам, адресам, маршрутам и данным об организациях. Он использует открытый протокол [Model Context Protocol](https://modelcontextprotocol.io/), направляет запросы от ИИ-агентов к API 2ГИС и возвращает результаты в подходящем для обработки формате. ИИ-ассистенты используют эти данные, чтобы отвечать на вопросы пользователей о местах, адресах, организациях и маршрутах, а также анализировать и визуализировать данные.

Схема работы:

1. Пользователь отправляет запрос ИИ-агенту (например, `Найти все круглосуточные аптеки`).
2. Агент определяет, какие геоданные и сервисы нужны (карты, поиск объектов по критерию и т. д.), и обращается к MCP-серверу.
3. MCP-сервер отправляет запросы к соответствующим API 2ГИС (например, Static API для получения изображения карты, Places API для поиска объектов и получения данных о них).
4. Агент получает результат и формирует ответ для пользователя.

## Начало работы {#getting-started}

Для работы с MCP-сервером 2ГИС необходимо получить ключ доступа к API: оформить бесплатный [демо-ключ](/platform-manager/subscription/keys#demo) (действует 30 дней, есть [ограничения по количеству запросов](/platform-manager/subscription/pricing#demo-limits)) или купить [подписку](/platform-manager/subscription/purchase).

MCP-сервер API-платформы 2ГИС доступен как в облаке, так и в виде дистрибутива для локальной установки. Следуйте инструкциям для нужного варианта:

* [Облачный MCP-сервер](/api/ai/mcp-server/cloud) — чтобы быстро подключить агента к MCP-серверу без установки сервера локально.
* [Дистрибутив MCP-сервера](/api/ai/mcp-server/downloadable) — чтобы развернуть сервер в своей инфраструктуре.

## Рекомендации по формулировке промптов {#prompt-recommendations}

* Указывайте логичную последовательность решения задачи, например `сначала получи координаты по адресу, затем проложи маршрут`. Это поможет избежать частой ошибки — построения маршрута на вымышленных координатах.
* Разбивайте сложные задачи на несколько небольших. Например, вместо расчёта одной матрицы расстояний 25×25 используйте несколько матриц меньшего размера.
* Для построения маршрутов указывайте тип транспорта и ограничения, если они есть. Например, `маршрут пешком` или `маршрут на автомобиле без платных дорог`.
* Для поиска точек интереса указывайте желаемое количество результатов. Например, `три ближайшие` или `топ пять по рейтингу`.
* Указывайте язык ответа явно: `ответ на английском`.
