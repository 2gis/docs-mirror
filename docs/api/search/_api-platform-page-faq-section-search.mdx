<AccordionItem title="Как начать работать с API поиска?">

Чтобы работать с API, получите ключ доступа:

1. Зарегистрируйтесь в личном кабинете Менеджер Платформы.

   <CtaButton href="https://platform.2gis.ru/ru/?utm_source=docs&utm_medium=referral&utm_campaign=api_search_faq" target="_blank">
      В кабинет
   </CtaButton>

2. Создайте [демо-ключ](/platform-manager/subscription/keys#demo) или купите [подписку](/platform-manager/subscription/purchase) для доступа к API.
3. Изучите примеры запросов и ответов в документации к нужному API.

</AccordionItem>

<AccordionItem title="Как рассчитывается стоимость использования API?">

Стоимость использования API поиска рассчитывается исходя из количества запросов. При этом часть информации об объектах (например, ИНН компании) доступна только по отдельному запросу и за дополнительную плату. См. список методов и полей с отдельной тарификацией в документации к [Places API](/api/search/places/overview#info-on-demand), [Geocoder API](/api/search/geocoder/overview#info-on-demand) и [Suggest API](/api/search/suggest/overview#info-on-demand).

</AccordionItem>

<AccordionItem title="Можно ли использовать API поиска бесплатно?">

Вы можете [оформить демо-ключ доступа](/platform-manager/subscription/keys#demo) для тестирования API поиска на один месяц. При использовании демо-ключа вы можете получить максимум 5 страниц с результатами ответов по 10 объектов на каждой странице.

</AccordionItem>

<AccordionItem title="Как контролировать использование API-ресурсов?">

Отслеживайте расходование лимитов по сервисам и статистику распределения запросов в личном кабинете [Менеджер Платформы](https://platform.2gis.ru/ru/?utm_source=docs&utm_medium=referral&utm_campaign=api_search_faq). Чтобы не исчерпать лимиты раньше времени, в личном кабинете вы можете:

* Установить лимиты на запросы к конкретным сервисам по всем API-ключам в подписке или по отдельным ключам. При превышении лимитов запросы к API вернут ошибку.
* Настроить отправку уведомлений при приближении к лимитам.

Подробнее см. в разделах [Управление ключами доступа](/platform-manager/subscription/managing-keys) и [Статистика](/platform-manager/subscription/statistics).

</AccordionItem>

<AccordionItem title="По каким критериям можно искать объекты в справочнике?">

С помощью Places API вы можете найти конкретный объект или список объектов по произвольному текстовому запросу, координатам, адресу, телефону, рубрикам и другим параметрам объекта (например, по наличию Wi-Fi). См. основные сценарии в разделе [Примеры](/api/search/places/examples/objects).

</AccordionItem>

<AccordionItem title="Как я могу ограничить область поиска?">

При поиске вы можете указать административную единицу (область, город, район и т. д.), конкретный адрес или задать свою область поиска по координатам (например, радиус вокруг точки на карте, прямоугольник или произвольную область). Подробнее см. в разделе [Примеры](/api/search/places/examples/objects).

</AccordionItem>

<AccordionItem title="Какие данные о компании можно получить?">

С помощью поисковых API вы можете получить основную информацию об организации: название, адрес, режим работы, координаты на карте, статистику отзывов, и другое. Некоторые данные доступны за дополнительную плату и недоступны для демо-ключа: ИНН, контактная информация, численность сотрудников, торговая лицензия и т. д. См. полный список доступных данных и условия их получения в документации к нужному API.

</AccordionItem>

<AccordionItem title="Можно ли получить список отзывов клиентов о компании?">

С помощью Places API вы можете получить только статистические данные по отзывам: общее количество отзывов и среднюю оценку. Дополнительно вы можете отфильтровать результаты поиска, чтобы включить в них только компании с отзывами.

Текстовые отзывы нельзя получить с помощью API.

</AccordionItem>

<AccordionItem title="Можно ли получить фотографии организаций?">

Нет. При работе с API поиска вы можете отфильтровать организации по наличию фотографий в их карточках, но получить сами фотографии не получится.

</AccordionItem>

<AccordionItem title="Как часто обновляются данные в справочнике?">

Данные в справочнике <Brand /> обновляются каждый месяц и становятся доступными в ваших проектах одновременно с продуктами <Brand />.

</AccordionItem>

<AccordionItem title="Можно ли добавлять собственные объекты или адреса в справочник?">

Редактирование справочника <Brand /> возможно только через внутренние процессы компании <Brand />. Чтобы добавить информацию о своём бизнесе в справочник <Brand />, используйте сервис [2ГИС для бизнеса](https://account.2gis.com/).

</AccordionItem>

<AccordionItem title="Можно ли установить сервисы поиска в собственной инфраструктуре?">

Да, вы можете установить API-платформу <Brand /> в закрытом контуре. Подробнее см. в разделе [On-Premise](/on-premise-api-platform/overview/summary).

</AccordionItem>
