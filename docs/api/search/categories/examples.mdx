# Примеры

Перед началом работы с категориями необходимо получить ID нужного региона — он передаётся в параметре `region_id` во всех последующих запросах.

## Получите ID региона {#get-region-id}

:::note[Доступ]

Для использования метода [/2.0/region/search](/api/search/regions/reference/2.0/region/search) нужен доступ к Regions API.

:::

Отправьте GET-запрос к [/2.0/region/search](/api/search/regions/reference/2.0/region/search):

* `q` — название города или региона, например `q=Москва`.
* `locale` (необязательный) — язык поиска и ответа, например `locale=ru_RU`. По умолчанию используется язык региона.
* `key` — ваш ключ API.

**Пример запроса:**

```http
https://catalog.api.2gis.com/2.0/region/search?q=Москва&locale=ru_RU&key=API_KEY
```

**Пример ответа:**

<details>
<summary><code>response.json</code></summary>

```json
{
    "meta": {
        "api_version": "2.0.21656",
        "code": 200,
        "issue_date": "20260925"
    },
    "result": {
        "items": [
            {
                "id": "32",
                "name": "Москва",
                "type": "region"
            }
        ],
        "total": 1
    }
}
```

</details>

Скопируйте ID региона из поля `result.items.id`.

## Поиск категории по названию {#search-category-by-name}

Чтобы найти категорию по ключевому слову, отправьте GET-запрос к [/2.0/catalog/rubric/search](/api/search/categories/reference/2.0/catalog/rubric/search):

* `q` — название категории, например `q=кафе`.
* `region_id` — [ID региона](#get-region-id), например `region_id=32`.
* `page` (необязательный) — номер страницы результатов, по умолчанию `1`.
* `page_size` (необязательный) — количество результатов на странице: от 1 до 50 (по умолчанию `20`).
* `locale` (необязательный) — язык поиска и ответа, например `locale=ru_RU`. По умолчанию используется язык региона.
* `key` — ваш ключ API.

**Пример запроса:**

```http
https://catalog.api.2gis.com/2.0/catalog/rubric/search?q=кафе&region_id=32&locale=ru_RU&key=API_KEY
```

**Пример ответа:**

<details>
<summary><code>response.json</code></summary>

```json
{
    "meta": {
        "api_version": "2.0.21656",
        "code": 200,
        "issue_date": "20260927"
    },
    "result": {
        "items": [
            {
                "alias": "kafe",
                "branch_count": 6539,
                "caption": "Кафе",
                "id": "161",
                "keyword": "Кафе",
                "name": "Кафе",
                "org_count": 5262,
                "parent_id": "2",
                "title": "Кафе",
                "type": "rubric"
            },
           ...
        ],
        "total": 9
    }
}
```

</details>

Параметры ответа:

* `result.items` — список найденных категорий:
   * `alias` — псевдоним категории.
   * `branch_count` — количество филиалов в категории.
   * `id` — ID категории. 
   * `keyword` — ключевые слова категории.
   * `name`, `caption`, `title` — название категории.
   * `org_count` — количество организаций в категории.
   * `parent_id` — ID объединяющей категории.
   * `type` — тип категории: `rubric` (обычная) или `general_rubric` (объединяющая).
* `result.total` — общее количество найденных категорий.

Подробнее о параметрах см. в [Справочнике API](/api/search/categories/reference/2.0/catalog/rubric/search).

## Получение списка категорий {#category-list-in-region}

Чтобы получить полный каталог категорий в выбранном регионе, отправьте GET-запрос к [/2.0/catalog/rubric/list](/api/search/categories/reference/2.0/catalog/rubric/list):

* `region_id` — [ID региона](#get-region-id), например `region_id=32`.
* `sort` (необязательный) — сортировка: `name` (по алфавиту, по умолчанию) или `popularity` (по популярности).
* `page_size` (необязательный)— количество результатов на странице: от 1 до 10000 (по умолчанию `10000`).
* `locale` (необязательный) — язык поиска и ответа, например `locale=ru_RU`. По умолчанию используется язык региона.
* `key` — ваш ключ API.

**Пример запроса:**

```http
https://catalog.api.2gis.com/2.0/catalog/rubric/list?region_id=32&locale=ru_RU&key=API_KEY
```

**Пример ответа:**

Параметры ответа:

* `result.items` — список категорий:

   * `id` — ID категории.
   * `name` — название категории.
   * `org_count` — количество организаций в категории.
   * `type` — тип категории: `rubric` (обычная) или `general_rubric` (объединяющая).
* `result.total` — общее количество категорий.

Подробнее о параметрах см. в [Справочнике API](/api/search/categories/reference/2.0/catalog/rubric/list).

## Получение списка дочерних категорий {#child-categories}

Возвращает список дочерних категорий внутри объединяющей категории.

### Через ID родительской категории {#via-parent-id}

Получите [ID объединяющей категории](#category-list-in-region) и отправьте GET-запрос к [/2.0/catalog/rubric/list](/api/search/categories/reference/2.0/catalog/rubric/list):

* `parent_id` — ID объединяющей категории, например `parent_id=2`.
* `region_id` — [ID региона](#get-region-id), например `region_id=32`.
* `locale` (необязательный) — язык поиска и ответа, например `locale=ru_RU`. По умолчанию используется язык региона.
* `key` — ваш ключ API.

**Пример запроса:**

```http
https://catalog.api.2gis.com/2.0/catalog/rubric/list?parent_id=2&region_id=32&locale=ru_RU&key=API_KEY
```

**Пример ответа:**

        "code": 200,
        "issue_date": "20260927"
    },

            {
                "alias": "ehkskursii",

Параметры ответа:

* `result.items` — массив объединяющих категорий:
   * `alias` — псевдоним дочерней категории.
   * `branch_count` — количество филиалов в категории.
   * `id` — ID дочерней категории.
   * `name`, `caption`, `title` — название дочерней категории.
   * `org_count` — количество организаций в категории.
   * `parent_id` — ID объединяющей категории.

* `result.total` — общее количество категорий.

Подробнее о параметрах см. в [Справочнике API](/api/search/categories/reference/2.0/catalog/rubric/list).

### Через параметр `fields` {#via-fields-parameter}

Список объединяющих и дочерних категорий также можно получить с помощью параметра `fields`. Для этого отправьте GET-запрос к [/2.0/catalog/rubric/list](/api/search/categories/reference/2.0/catalog/rubric/list):

* `region_id` — [ID региона](#get-region-id), например `region_id=32`.
* `fields` (необязательный)— дополнительные поля. Для получения дочерних категорий передайте `fields=items.rubrics`.
* `locale` (необязательный) — язык поиска и ответа, например `locale=ru_RU`. По умолчанию используется язык региона.
* `key` — ваш ключ API.

**Пример запроса:**

```http
https://catalog.api.2gis.com/2.0/catalog/rubric/list?region_id=32&fields=items.rubrics&locale=ru_RU&key=API_KEY
```
