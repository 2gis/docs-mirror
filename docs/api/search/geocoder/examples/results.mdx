# Обработка результатов поиска

Вы можете обрабатывать результаты поиска:

* [сортировать их](#sort) по параметрам;
* [получать определённую страницу результатов поиска](#page);
* [ограничивать количество результатов на странице](#page-size).

## Сортировка результатов {#sort}

С помощью параметра `sort` вы можете сортировать результаты поиска по удалённости от пользователя и другим параметрам. По умолчанию результаты сортируются по убыванию релевантности. Полный список параметров сортировки см. в [справочнике API](/api/search/geocoder/reference/3.0/items/geocode).

Чтобы сортировать результаты поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — [текстовый запрос с адресом](/api/search/geocoder/examples/direct#text), например «Москва, Садовая улица».
* `sort` — параметр сортировки, например `sort=name` для сортировки по названию объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=Москва, Садовая улица&sort=name&key=API_KEY
```

## Получение результатов по страницам {#page}

В ответе на запрос к API результаты поиска выводятся постранично. По умолчанию каждая страница содержит 20 результатов для основного [ключа в подписке](/platform-manager/subscription/keys#production) и 10 результатов для [демо-ключа](/platform-manager/subscription/keys#demo).

По умолчанию выводится первая страница. С помощью параметра `page` вы можете получить определённую страницу результатов поиска.

Чтобы получить определённую страницу результатов поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — [текстовый запрос с адресом](/api/search/geocoder/examples/direct#text), например «Москва, Садовая улица».
* `page` — номер страницы с результатами, например `page=5` для получения пятой страницы. Если вы используете [демо-ключ](/platform-manager/subscription/keys#demo) для доступа к API, максимальное значение — 5.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=Москва, Садовая улица&page=5&key=API_KEY
```

## Ограничение количества результатов на странице {#page-size}

В ответе на запрос к API результаты поиска выводятся постранично. По умолчанию каждая страница содержит 20 результатов для основного [ключа в подписке](/platform-manager/subscription/keys#production) и 10 результатов для [демо-ключа](/platform-manager/subscription/keys#demo).

С помощью параметра `page_size` вы можете изменить количество результатов на странице — от 1 до 50. Например, вы можете:

* сократить количество результатов при поиске на карте, чтобы показать ближайшие места без перегрузки интерфейса;
* увеличить количество результатов, чтобы отправить меньшее количество запросов.

Чтобы ограничить количество результатов поиска на странице, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — [текстовый запрос с адресом](/api/search/geocoder/examples/direct#text), например «Москва, Садовая улица».
* `page_size` — количество результатов на странице, например `page_size=3` для получения трёх результатов на странице. Если вы используете [демо-ключ](/platform-manager/subscription/keys#demo) для доступа к API, максимальное значение — 10.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=Москва, Садовая улица&page_size=3&key=API_KEY
```
