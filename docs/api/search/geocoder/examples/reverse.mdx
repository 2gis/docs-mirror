# Поиск по координатам (обратное геокодирование)

Для поиска объекта по координатам укажите координаты точки в параметрах `lon` и `lat` в GET-запросе к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode): см. подробнее в разделе [Поиск по координатам точки](#lon-lat). Чтобы получить в ответе адрес объекта и административные единицы, которым он принадлежит, укажите в запросе параметр `fields=items.adm_div,items.address`.

Также вы можете искать по координатам:

* объекты, находящиеся в [радиусе вокруг точки](#radius);
* [входы в здание](#entrance);
* определённые [типы объектов](#type).

## Поиск по координатам точки {#lon-lat}

При поиске по координатам точки радиус поиска равен нулю: возвращается адрес только той точки, которую вы указали. Если указанные координаты принадлежат зданию, в ответе будет адрес этого здания. Если координаты не попадают в границы здания, в ответе будут только административные единицы (например, район), к которым относится точка.

Чтобы получить адрес здания, указывайте точные координаты, находящиеся внутри его границ. Если вы не знаете точные координаты и хотите найти ближайшее здание к точке, используйте [поиск в радиусе вокруг точки](#radius).

Чтобы получить адрес точки, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `lon` — долгота точки поиска, например `lon=37.609256`.
* `lat` — широта точки поиска, например `lat=55.770784`.
* `fields=items.adm_div,items.address` — включает в ответ поля с административными единицами и адресом объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?lon=37.609256&lat=55.770784&fields=items.adm_div,items.address&key=API_KEY
```

## Поиск в радиусе вокруг точки {#radius}

С помощью параметра `radius` вы можете найти все объекты в радиусе вокруг точки. Точку можно задать с помощью параметра `point` или пары параметров `lon` и `lat`.

Максимальный радиус — 2 000 м. Если в запросе указан адрес в виде текстового запроса (параметр `q`), максимальный радиус — 50 000 м: см. [пример запроса для прямого геокодирования](/api/search/geocoder/examples/direct#radius).

Чтобы указать радиус поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `lon` — долгота точки поиска, например `lon=37.609484`.
* `lat` — широта точки поиска, например `lat=55.770763`.
* `radius` — радиус поиска в метрах, например `radius=50`.
* `fields=items.adm_div,items.address` — включает в ответ поля с административными единицами и адресом объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?lon=37.609484&lat=55.770763&radius=50&fields=items.adm_div,items.address&key=API_KEY
```

## Поиск входов в здание {#entrance}

Чтобы найти входы в здание (подъезды), ближайшее к указанной точке, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `lon` — долгота точки поиска, например `lon=37.609376`.
* `lat` — широта точки поиска, например `lat=55.772302`.
* `type=building` — поиск объектов с типом «здание».
* `radius` — радиус поиска в метрах, например `radius=10`.
* `fields` — список полей, которые нужно вернуть в ответе:

   * `items.adm_div` — административные единицы.
   * `items.address` — адрес объекта.
   * `items.links.database_entrances` — координаты входов в здание (требуется [дополнительное разрешение ключа](/api/search/geocoder/overview#info-on-demand)).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?lon=37.609376&lat=55.772302&type=building&radius=10&fields=items.adm_div,items.address,items.links.database_entrances&key=API_KEY
```

## Поиск по типу объекта {#type}

С помощью параметра `type` вы можете искать объекты определённого типа: здания, улицы, парковки, остановки, достопримечательности и другие. Полный список типов объектов см. в [справочнике API](/api/search/geocoder/reference/3.0/items/geocode).

Чтобы найти объекты определённого типа, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `lon` — долгота точки поиска, например `lon=37.609484`.
* `lat` — широта точки поиска, например `lat=55.770763`.
* `type` — тип объекта, например `type=building` для поиска зданий.
* `fields=items.adm_div,items.address` — включает в ответ поля с административными единицами и адресом объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?lon=37.609484&lat=55.770763&type=building&fields=items.adm_div,items.address&key=API_KEY
```
