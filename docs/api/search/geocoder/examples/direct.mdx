# Поиск по адресу (прямое геокодирование)

Для поиска объекта по адресу укажите адрес в параметре `q` в GET-запросе к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode): см. подробнее в разделе [Поиск по адресу в текстовом запросе](#text). Чтобы получить в ответе координаты объекта, укажите в запросе параметр `fields=items.point,items.geometry.centroid`.

Также вы можете искать по адресу:

* объекты с указанием [геоограничения](#georestriction) (необходимо, если населённый пункт не указан в параметре `q`);
* координаты [входа в здание](#entrance);
* определённые [типы объектов](#type).

## Поиск по адресу в текстовом запросе {#text}

Вы можете указать в параметре `q` адрес с названием населённого пункта: города, посёлка и т. д. Например, «улица Каретный ряд, 3, Москва», «​Проспект Мира, 26 ст1, Москва» и т. д.

Если вы не указываете населённый пункт, для ограничения области поиска укажите [геоограничение](#georestriction). В противном случае поиск может не дать результатов, даже если объект с указанным адресом существует.

Для небольших населённых пунктов (например, деревень) рекомендуется указывать название вместе с названием области и другими объединениями, к которым он относится (например, сельским или городским поселением).

Чтобы получить координаты объекта, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом, который содержит населённый пункт, например «улица Каретный ряд, 3, Москва».
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=улица Каретный ряд, 3, Москва&fields=items.point,items.geometry.centroid&key=API_KEY
```

## Поиск с геоограничением {#georestriction}

Вы можете указать геоограничение поиска в виде:

* [координат точки поиска](#location);
* [радиуса вокруг точки](#radius);
* [прямоугольной области](#point1-point2);
* [произвольной области](#polygon);
* [области видимости](#viewpoint);
* [региона](#region-id);
* [города](#city-id);
* [территории](#place-id);
* [станции метро](#subway), рядом с которой выполнится поиск.

Одновременно нельзя указывать геоограничения по радиусу, произвольной области и прямоугольной области (параметры `point`, `polygon`, `point1`/`point2`).

### Координаты точки {#location}

С помощью параметра `location` вы можете задать ограничение поиска по координатам точки. В ответе первыми будут выведены наиболее близкие к точке объекты. Населённый пункт в текстовом запросе при этом можно не указывать.

Чтобы указать точку в качестве области поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом, например «улица Каретный ряд, 3».
* `location` — координаты точки поиска в формате `долгота,широта`, например `location=37.623056,55.752344`.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=улица Каретный ряд, 3&location=37.623056,55.752344&fields=items.point,items.geometry.centroid&key=API_KEY
```

### Радиус вокруг точки {#radius}

С помощью параметра `radius` вы можете ограничить результаты поиска радиусом вокруг точки. Точку можно задать с помощью параметра `point` или пары параметров `lon` и `lat`. Населённый пункт в текстовом запросе при этом можно не указывать.

Максимальный радиус — 2 000 м. Если в запросе указан адрес в виде текстового запроса (параметр `q`), максимальный радиус — 50 000 м (см. [пример запроса для обратного геокодирования](/api/search/geocoder/examples/reverse#radius)).

Чтобы указать радиус поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом, например «улица Каретный ряд, 3».
* `point` — координаты центра точки поиска в формате `долгота,широта`, например `point=37.623056,55.752344`.
* `radius` — радиус поиска в метрах, например `radius=10000`.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=улица Каретный ряд, 3&point=37.623056,55.752344&radius=10000&fields=items.point,items.geometry.centroid&key=API_KEY
```

### Прямоугольная область {#point1-point2}

Чтобы указать прямоугольную область поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `point1` — координаты левого верхнего угла прямоугольной области в формате `долгота,широта`, например `37.606789,55.771235`.
* `point2` — координаты правого нижнего угла прямоугольной области в формате `долгота,широта`, например `37.611516,55.769179`.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**


Чтобы указать произвольную область поиска (полигон), отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `viewpoint1` — координаты левого верхнего угла прямоугольной области в формате `долгота,широта`, например `37.606789,55.771235`.
* `viewpoint2` — координаты правого нижнего угла прямоугольной области в формате `долгота,широта`, например `37.611516,55.769179`.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=улица Каретный ряд, 3&viewpoint1=37.606789,55.771235&viewpoint2=37.611516,55.769179&fields=items.point,items.geometry.centroid&key=API_KEY
```

### Территория {#place-id}

Чтобы указать территорию в качестве области поиска, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

### Станция метро {#subway}

С помощью параметра `subway` вы можете задать ограничение поиска по станции метро. Максимальное количество станций в запросе — 50. Населённый пункт в текстовом запросе при этом можно не указывать.

Чтобы указать станцию метро, рядом с которой будет выполняться поиск, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом, например «улица Каретный ряд, 3».
* `subway` — ID станции метро, например `subway=4504385606388578`. Можно использовать несколько ID, разделённых запятыми, например `subway=4504385606388578,4504385606390686`. Подробнее о получении ID см. в разделе [ID станции метро](/api/search/geocoder/examples/obtaining#subway-id).
* `location` — координаты точки поиска в формате `долгота,широта`, например `location=37.623056,55.752344`. Например, вы можете указать координаты любой точки в городе.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=улица Каретный ряд, 3&subway=4504385606388578&location=37.623056,55.752344&fields=items.point,items.geometry.centroid&key=API_KEY
```

## Поиск входа в здание {#entrance}

Чтобы получить координаты входа в здание (подъезда), отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом и подъездом, например «Москва, Садовая-Каретная улица, 10, 2 подъезд».
* `fields` — список полей, которые нужно вернуть в ответе:

   * `items.context` — ID входа в здание (подъезда).
   * `items.point,items.geometry.centroid` — координаты объекта.
   * `items.links.database_entrances` — координаты входа в здание (требуется [дополнительное разрешение ключа](/api/search/geocoder/overview#info-on-demand)).

```bash
https://catalog.api.2gis.com/3.0/items/geocode?q=Москва, Садовая-Каретная улица, 10, 2 подъезд&fields=items.context,items.point,items.geometry.centroid,items.links.database_entrances&key=API_KEY
```

## Поиск по типу объекта {#type}

С помощью параметра `type` вы можете искать объекты определённого типа: здания, улицы, парковки, остановки, достопримечательности и другие. Полный список типов объектов см. в [справочнике API](/api/search/geocoder/reference/3.0/items/geocode).

Чтобы найти объекты определённого типа, отправьте GET-запрос к [/3.0/items/geocode](/api/search/geocoder/reference/3.0/items/geocode) со следующими параметрами:

* `q` — текстовый запрос с адресом, например «Москва, улица Каретный ряд, 3». Вместо населённого пункта в текстовом запросе вы можете указать геоограничение: подробнее см. в разделе [Поиск с геоограничением](#georestriction).
* `type` — тип объекта, например `type=street` для поиска улиц.
* `fields=items.point,items.geometry.centroid` — включает в ответ поля с координатами объекта.

