# Поиск объектов

Вы можете искать объекты (организации, здания, достопримечательности, остановки транспорта, парковки и т. д.):

* [по текстовому запросу](#text),
* [по типу объекта](#type),
* [по ID объекта](#id),
* [по ID категории](#rubric-id),
* [по ID организации](#org-id),
* [по ID бренда](#brand-id).

Для поиска организаций по стандартным параметрам (названию, адресу, категориям и другим) укажите параметр `type=branch` в запросе к endpoint-у [/3.0/items](/api/search/places/reference/3.0/items). Также вы можете использовать endpoint-ы для поиска организаций по уникальным атрибутам. Доступ к ним (кроме `/3.0/items/byservicing`) предоставляется по запросу и за дополнительную плату. Чтобы приобрести доступ, свяжитесь с [отделом продаж <Brand />](https://dev.2gis.ru/api#form):

* [/3.0/items/byservicing](/api/search/places/reference/3.0/items/byservicing) — поиск организаций, обслуживающих здание, [по ID здания](#byservicing);
* [/3.0/items/bysite](/api/search/places/reference/3.0/items/bysite) — поиск организаций [по сайту](#bysite);
* [/3.0/items/byphone](/api/search/places/reference/3.0/items/byphone) — поиск организаций [по номеру телефона](#byphone);
* [/3.0/items/byitin](/api/search/places/reference/3.0/items/byitin) — поиск организаций [по ИНН](#byitin);
* [/3.0/items/bytradelicense](/api/search/places/reference/3.0/items/bytradelicense) — поиск организаций [по торговой лицензии](#bytradelicense);
* [/3.0/items/byfias](/api/search/places/reference/3.0/items/byfias) — поиск организаций [по коду ФИАС](#byfias).

## По текстовому запросу {#text}

Вы можете указать в параметре `q` текстовый запрос для поиска: объект, который нужно найти, например «метро», «кафе», «аптека» и другие. Можно уточнить запрос, указав:

   * определённое место (`Большой театр`) или название организации (`кафе «Шоколадница»`);
   * категорию (`магазины музыкальных инструментов`);
   * критерий (`рестораны с итальянской кухней`);
   * другие параметры.

В параметре `q` можно одновременно указать и объект, и геоограничение, например `кафе в Тверском районе Москвы`. В запросе можно указать только один параметр `q`. Если вы не укажете геоограничение в параметре `q`, для повышения точности поиска передайте его другими способами, например, с помощью параметров `location`, `city_id`, `region_id` и других. Полный список см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).

Чтобы найти объект, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — текстовый запрос, например «новая третьяковка».
* `city_id` — ID города, например `city_id=4504222397630173` для Москвы. Подробнее о получении ID см. в разделе [ID города](/api/search/places/examples/obtaining#city-id). Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=новая третьяковка&city_id=4504222397630173&key=API_KEY
```

## По типу объекта {#type}

С помощью параметра `type` вы можете искать объекты определённого типа: организации, здания, улицы, парковки, остановки, станции метро, достопримечательности и другие.

Параметр `type` можно указать для endpoint-ов:

* [/3.0/items](/api/search/places/reference/3.0/items),
* [/3.0/items/byfias](/api/search/places/reference/3.0/items/byfias).

Полный список типов объектов см. в справочнике API.

Чтобы найти объекты определённого типа, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](#text), например «метро».
* `point` — координаты центра точки поиска в формате `долгота,широта`, например `point=37.630866,55.752256`.
* `radius` — радиус поиска в метрах, например `radius=1000`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `type` — тип объекта, например `type=station.metro` для поиска станций метро.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=метро&point=37.630866,55.752256&radius=1000&type=station.metro&key=API_KEY
```

## По ID объекта {#id}

Вы можете искать объекты по их уникальному идентификатору (ID).

Чтобы найти объект по его ID, отправьте GET-запрос на [/3.0/items/byid](/api/search/places/reference/3.0/items/byid) с параметром `id` — ID объекта, например `id=70000001080081802`. Подробнее о получении ID см. в инструкции [Получение ID объектов](/api/search/places/examples/obtaining).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/byid?id=70000001080081802&key=API_KEY
```

**Пример ответа:**

## По ID категории {#rubric-id}

С помощью параметра `rubric_id` вы можете получить список организаций определённой категории, например, только кафе или только продуктовые магазины.

Чтобы отфильтровать результаты поиска по ID категории организации, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](#text), например «кофе».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`.
```bash
https://catalog.api.2gis.com/3.0/items?q=кофе&location=37.630866,55.752256&rubric_id=161&key=API_KEY
```

## По ID организации {#org-id}

С помощью параметра `org_id` вы можете получить список всех филиалов одной организации, например, только филиалы Почты России. ID организации различаются в зависимости от региона.

Чтобы отфильтровать результаты поиска по ID организации, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `org_id` — ID организации, например `org_id=70000001087490185`. Подробнее о получении ID см. в разделе [ID организации](/api/search/places/examples/obtaining#org-id).
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?org_id=70000001087490185&location=37.630866,55.752256&key=API_KEY
```

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?brand_id=70000001103777439&location=37.630866,55.752256&key=API_KEY
```

## Поиск организаций {#organizations}

### По ID здания {#byservicing}

Вы можете получить список организаций, обслуживающих здание:

* Городских обслуживающих организаций: почта, поликлиника, ЖКХ.
* Интернет-провайдеров.

Чтобы получить список организаций, обслуживающих здание, отправьте GET-запрос на [/3.0/items/byservicing](/api/search/places/reference/3.0/items/byservicing) со следующими параметрами:

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/byservicing?building_id=4504235282736775&servicing_group=internet&key=API_KEY
```
