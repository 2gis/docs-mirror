# Дополнительная информация об объектах

С помощью параметра `fields` вы можете получить дополнительную информацию об объектах в ответе: адрес объекта, его геометрию, контактную информацию и другие данные.

Получение некоторых полей доступно только по запросу и за дополнительную плату. См. список полей в разделе [Дополнительная информация по запросу](/api/search/places/overview#info-on-demand).

Параметр `fields` можно указать для всех актуальных endpoint-ов Places API. Ниже приведены примеры запросов для получения информации об объектах с помощью параметра `fields`. Полный список полей см. в [Справочнике API](/api/search/places/reference/3.0/items).

## Получение информации о здании {#building}

Чтобы получить информацию о здании, отправьте GET-запрос на [/3.0/items/byid](/api/search/places/reference/3.0/items/byid) со следующими параметрами:

* `id` — ID здания, например `id=4504235299048514`. Подробнее о получении ID см. в разделе [ID здания](/api/search/places/examples/obtaining#building-id).
* `fields` — список полей, которые нужно вернуть в ответе. Можно использовать несколько полей, разделённых запятыми, например:

   * `items.address` — адрес здания. 
   * `items.adm_div` — административная территория, к которой относится здание.
   * `items.point` — координаты здания.
   * `items.links` — связанные объекты (ближайшие парковки, остановки, станции метро и другие).
   * `items.floors` — количество этажей здания (требуется [дополнительное разрешение ключа](/api/search/places/overview#info-on-demand)).
   * `items.structure_info.material` — материал здания (требуется [дополнительное разрешение ключа](/api/search/places/overview#info-on-demand)).
   * `items.structure_info.floor_type` — тип перекрытий здания (требуется [дополнительное разрешение ключа](/api/search/places/overview#info-on-demand)).
   * `items.structure_info.year_of_construction` — год постройки здания (требуется [дополнительное разрешение ключа](/api/search/places/overview#info-on-demand)).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/byid?id=4504235299048514&fields=items.address,items.adm_div,items.point,items.links,items.floors,items.structure_info.material,items.structure_info.floor_type,items.structure_info.year_of_construction&key=API_KEY
```

## Получение информации об организации {#organization}

Чтобы получить информацию об организации, отправьте GET-запрос на [/3.0/items/byid](/api/search/places/reference/3.0/items/byid) со следующими параметрами:

* `id` — ID организации, например `id=70000001018276833`. Подробнее о получении ID см. в разделе [ID организации](/api/search/places/examples/obtaining#org-id).
* `fields` — список полей, которые нужно вернуть в ответе. Можно использовать несколько полей, разделённых запятыми, например:

   * `items.rubrics` — категории организации.
   * `items.brand` — бренд, к которому относится организация.
   * `items.contact_groups` — контакты организации (требуется [дополнительное разрешение ключа](/api/search/places/overview#info-on-demand)). 
   * `items.schedule,items.schedule_special` — расписание работы организации.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/byid?id=70000001018276833&fields=items.rubrics,items.brand,items.contact_groups,items.schedule,items.schedule_special&key=API_KEY
```

## Получение информации о парковке {#parking}

Чтобы получить информацию о парковке, отправьте GET-запрос на [/3.0/items/byid](/api/search/places/reference/3.0/items/byid) со следующими параметрами:

* `id` — ID парковки, например `id=4504127908682102`. Подробнее о получении ID см. в разделе [ID парковки](/api/search/places/examples/obtaining#parking-id).
* `fields` — список полей, которые нужно вернуть в ответе. Можно использовать несколько полей, разделённых запятыми, например:

   * `items.is_paid` — является ли парковка платной.
   * `items.paving_type` — тип покрытия парковки.
   * `items.level_count` — количество уровней парковки.
   * `items.capacity` — вместимость парковки.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items/byid?id=4504127908682102&fields=items.is_paid,items.paving_type,items.level_count,items.capacity&key=API_KEY
```
