# Настройки поиска

Вы можете управлять поведением поискового движка и логикой формирования результатов:

* указать [тип поиска](#search-type);
* использовать [поиск рядом с пользователем](#search-nearby);
* указать [область поиска](#search-territory-of-interest);
* выбрать [способ ввода запроса](#search-input-method);
* включить [проверку завершения ввода запроса](#search-is-query-text-complete).

## Тип поиска {#search-type}

С помощью параметра `search_type` вы можете указать тип поискового движка: алгоритм и настройки, оптимизированные под цель поиска, а также логику формирования результатов.

По умолчанию используется поиск с раскрытием (`search_type=discovery`). В результатах поиска категории и организации раскрываются до филиалов организации. Например, при поиске «почта России» в ответе будут все почтовые отделения. Аналогично работает раскрытие категории: при поиске «кафе» в результате будут организации в категории «Кафе / Кондитерские», а не сама категория, которая также является объектом справочника.

Вы можете использовать другие типы поиска, например, [поиск с единственным филиалом](#search-type-one-branch) или [поиск внутри здания](#search-type-indoor). Полный список типов поиска см. в [справочнике API](/api/search/places/reference/3.0/items).

### Поиск с единственным филиалом организации {#search-type-one-branch}

Поиск с единственным филиалом организации в результатах поиска аналогичен поиску с раскрытием, но для каждой организации в результате выводится только один филиал.

Чтобы использовать поиск с единственным филиалом, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `search_type=one_branch` — поиск с единственным филиалом.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&location=37.630866,55.752256&search_type=one_branch&key=API_KEY
```

### Поиск внутри здания {#search-type-indoor}

Поиск внутри здания подходит для поиска организаций в здании, например, в бизнес-центре или торгово-развлекательном центре. Вы также можете использовать этот тип для автодополнения при поиске в здании.

Чтобы использовать поиск внутри здания, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `search_type=indoor` — поиск внутри здания.
* `building_id` — ID здания, например `building_id=4504235299048514`. Можно использовать несколько ID, разделённых запятыми, например `building_id=4504235299048514,4504235282736775`. Подробнее о получении ID см. в разделе [ID здания](/api/search/places/examples/obtaining#building-id).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&search_type=indoor&building_id=4504235299048514&key=API_KEY
```

**Пример ответа:**

## Поиск рядом с пользователем {#search-nearby}

С помощью параметра `search_nearby` вы можете использовать режим поиска рядом с пользователем, чтобы повысить значимость расстояния от пользователя при ранжировании результатов. Поисковый движок учитывает местоположение пользователя и возвращает объекты, которые находятся ближе к нему.

Чтобы использовать поиск рядом с пользователем, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `point` — координаты пользователя в формате `долгота,широта`, например `point=37.630866,55.752256`.
* `search_nearby=true` — поиск рядом с пользователем.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&point=37.630866,55.752256&search_nearby=true&key=API_KEY
```

## Область поиска {#search-territory-of-interest}

С помощью параметра `search_territory_of_interest` вы можете указать предпочтительную область поиска объектов. Объекты внутри области будут ранжироваться в результатах выше, а объекты за её пределами — ниже, но не будут исключены. Этим параметр отличается от геоограничения в виде [произвольной области](/api/search/places/examples/georestriction#polygon), которое полностью исключает объекты за пределами заданного полигона.

Чтобы задать область поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `search_territory_of_interest` — область поиска в формате WKT.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&search_territory_of_interest=MULTIPOLYGON (((37.6146002 55.761322, 37.6175267 55.7628083, 37.6184916 55.7615712, 37.6152171 55.7605209, 37.6146002 55.761322)))&key=API_KEY
```

## Способ ввода запроса {#search-input-method}

С помощью параметра `search_input_method` вы можете указать способ ввода запроса, чтобы поисковый движок учитывал особенности ввода текста. Например, если пользователь вводит запрос голосом, поисковый движок будет учитывать возможные ошибки распознавания речи.

Чтобы указать способ ввода запроса, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафн» (с опечаткой).
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `search_input_method` — способ ввода текста запроса, например `search_input_method=hardware_qwerty_keyboard` для ввода с аппаратной клавиатуры. Полный список способов см. в [справочнике API](/api/search/places/reference/3.0/items).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафн&location=37.630866,55.752256&search_input_method=hardware_qwerty_keyboard&key=API_KEY
```

## Проверка завершения ввода {#search-is-query-text-complete}

С помощью параметра `search_is_query_text_complete=true` вы можете включить проверку завершения ввода запроса и указать поисковому движку, что запрос является законченным (пользователь нажал на кнопку завершения ввода). В этом случае будет отключен поиск по префиксу: например, по запросу «банк» не будет выполняться поиск банкоматов.

Чтобы включить проверку завершения ввода, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «банк».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `search_is_query_text_complete=true` — указание, что запрос является законченным.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=банк&location=37.630866,55.752256&search_is_query_text_complete=true&key=API_KEY
```
