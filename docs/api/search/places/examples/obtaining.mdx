# Получение ID объектов

В зависимости от задачи в некоторые запросы нужно передать ID объекта: здания, организации, города и т. д. Чтобы получить ID объекта, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) и укажите тип объекта в параметре `type`. Полный список типов см. в [Справочнике API](/api/search/places/reference/3.0/items).

Ниже приведены примеры запросов для получения ID различных объектов.

## ID категории {#rubric-id}

ID категорий различаются в регионах. Чтобы найти организации в нужной категории, сначала получите ID региона, затем ID категории и отфильтруйте результаты поиска по категории организации. Для выполнения запроса ключу необходим доступ к [Regions API](/api/search/regions/overview) и [Categories API](/api/search/categories/overview).

Чтобы получить ID категории, отправьте GET-запрос к [Categories API](/api/search/categories/overview) на [/2.0/catalog/rubric/search](/api/search/categories/reference/2.0/catalog/rubric/search) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например `q=кафе`.
* `region_id` — ID региона, например `region_id=32`. Подробнее о получении ID см. в разделе [ID региона](#region-id).

**Пример запроса:**

```bash
https://catalog.api.2gis.com/2.0/catalog/rubric/search?q=кафе&region_id=32&key=API_KEY
```

## ID организации {#org-id}

Чтобы получить ID организации, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «почта россии».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `fields=items.org` — включает в ответ поле с ID организации.
* `type=branch` — поиск объектов с типом «организация».

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=почта россии&location=37.630866,55.752256&fields=items.org&type=branch&key=API_KEY
```

## ID территории {#place-id}

Территории — это площадные объекты: парки, пляжи, территории баз отдыха, озёра и прочие места.

Чтобы получить ID территории, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) одним из способов:

* укажите название территории, например `q=вднх москва`:

   ```bash
   https://catalog.api.2gis.com/3.0/items?q=вднх москва&type=adm_div.place&key=API_KEY
   ```

* укажите долготу и широту точки, например `lon=37.637635&lat=55.826241`:

   ```bash
   https://catalog.api.2gis.com/3.0/items?lon=37.637635&lat=55.826241&type=adm_div.place&key=API_KEY
   ```

В запросе укажите `type=adm_div.place` для поиска объектов с типом «территория».

## ID района {#district-id}

* укажите название города и района, например `q=москва якиманка`:

   ```bash
   https://catalog.api.2gis.com/3.0/items?q=москва якиманка&type=adm_div.district&key=API_KEY
   ```

   ```bash
   https://catalog.api.2gis.com/3.0/items?lon=37.606357&lat=55.735467&type=adm_div.district&key=API_KEY
   ```

## ID региона {#region-id}

Для выполнения запроса ключу необходим доступ к [Regions API](/api/search/regions/overview).

Чтобы получить ID региона (области, края, республики и т. д.), отправьте GET-запрос к [Regions API](/api/search/regions/overview) на [/2.0/region/search](/api/search/regions/reference/2.0/region/search) одним из способов:

* укажите название региона, например `q=Москва`:

   ```bash
   https://catalog.api.2gis.com/2.0/region/search?q=Москва&key=API_KEY
   ```

   ```bash
   https://catalog.api.2gis.com/2.0/region/search?q=37.630866,55.752256&key=API_KEY
   ```
