# Фильтрация по атрибутам

Вы можете фильтровать результаты поиска и получать списки организаций:

* [По времени работы](#work-time).
* [По дате открытия](#opened-after-date).
* По наличию или отсутствию данных: [ИНН](#has-itin), [торговой лицензии](#has-trade-license), [фотографий](#has-photos), [рейтинга](#has-rating), [отзывов](#has-reviews) и [сайта](#has-site).
* [По дополнительным атрибутам](#additional-attributes).

## По времени работы {#work-time}

С помощью параметра `work_time` вы можете получить список организаций, работающих в определённое время, например, только круглосуточно работающие филиалы.

Чтобы отфильтровать результаты поиска по времени работы организации, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `work_time` — фильтр по времени работы, например `work_time=today,09:00` для получения организаций, работающих сегодня в 09:00.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&location=37.630866,55.752256&work_time=today,09:00&key=API_KEY
```

## По дате открытия {#opened-after-date}

С помощью параметра `opened_after_date` вы можете получить список организаций, открытых после определённой даты.

Чтобы отфильтровать результаты поиска по дате открытия организации, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `location` — [координаты точки поиска](/api/search/places/examples/georestriction#location) в формате `долгота,широта`, например `location=37.630866,55.752256`. Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `opened_after_date` — фильтр по дате открытия, например `opened_after_date=2026-06-01` для получения организаций, открытых после 1 июня 2026 года.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&location=37.630866,55.752256&opened_after_date=2026-06-01&key=API_KEY
```
