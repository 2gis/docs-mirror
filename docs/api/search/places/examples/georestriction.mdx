# Геоограничение поиска

Для повышения точности поиска объектов при использовании endpoint-a [/3.0/items](/api/search/places/reference/3.0/items) задайте геоограничение в виде:

* [текстового запроса](#text);
* [координат точки поиска](#location);
* [радиуса вокруг точки](#radius);
* [прямоугольной области](#point1-point2);
* [произвольной области](#polygon);
* [области видимости](#viewpoint);
* [региона](#region-id);
* [города](#city-id);
* [района](#district-id);
* [территории](#place-id);
* [станции метро](#subway), рядом с которой выполнится поиск;
* [здания](#building-id).

Одновременно нельзя указывать геоограничения по радиусу, прямоугольной и произвольной области (параметры `point`, `point1`/`point2` и `polygon`).

При использовании других endpoint-ов геоограничение можно не задавать.

## Текстовый запрос {#text}

Вы можете указать в параметре `q` геоограничение для поиска: название региона, города, района, улицы, станции метро и т. д.

В параметре `q` можно одновременно указать и объект, и геоограничение, например `кафе в Тверском районе Москвы`. В запросе можно указать только один параметр `q`. Подробнее о поиске объектов см. в инструкции [Поиск объектов](/api/search/places/examples/objects#text).

Чтобы указать геоограничение в виде текста, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) с параметром `q` — текстовым запросом, который содержит геоограничение, например «кафе пятницкая улица москва».

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе пятницкая улица москва&key=API_KEY
```

## Координаты точки {#location}

С помощью параметра `location` вы можете задать ограничение поиска по координатам точки. В ответе первыми будут выведены наиболее близкие к точке объекты.

Чтобы указать точку в качестве области поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `location` — координаты точки поиска в формате `долгота,широта`, например `location=37.630866,55.752256`.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&location=37.630866,55.752256&key=API_KEY
```

## Радиус вокруг точки {#radius}

С помощью параметра `radius` вы можете найти все объекты в радиусе вокруг точки. Точку можно задать с помощью параметра `point` или пары параметров `lon` и `lat`.

Максимальный радиус — 50 000 м. Если в запросе не указан объект в виде текстового запроса (параметр `q`) или в другом виде (например, ID организации `org_id`), максимальный радиус — 2 000 м. Рекомендуется указывать объект в запросе, чтобы получить более точные результаты поиска: см. [пример запроса](/api/search/places/overview#request-example).

Чтобы указать радиус поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `point` — координаты центра точки поиска в формате `долгота,широта`, например `point=37.630866,55.752256`.
* `radius` — радиус поиска в метрах, например `radius=500`.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&point=37.630866,55.752256&radius=500&key=API_KEY
```

## Прямоугольная область {#point1-point2}

С помощью параметров `point1` и `point2` вы можете ограничить результаты поиска прямоугольной областью, задав координаты левого верхнего и правого нижнего углов области. Максимальное расстояние между точками — два километра.

Чтобы указать прямоугольную область поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `point1` — координаты левого верхнего угла прямоугольной области в формате `долгота,широта`, например `37.609194,55.773293`.
* `point2` — координаты правого нижнего угла прямоугольной области в формате `долгота,широта`, например `37.621403,55.767303`.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&point1=37.609194,55.773293&point2=37.621403,55.767303&key=API_KEY
```

## Произвольная область {#polygon}

Чтобы указать произвольную область поиска (полигон), отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `polygon` — координаты вершин полигона в формате WKT.

https://catalog.api.2gis.com/3.0/items?q=кафе&polygon=POLYGON((37.6146002 55.761322, 37.6175267 55.7628083, 37.6184916 55.7615712, 37.6152171 55.7605209, 37.6146002 55.761322))&key=API_KEY

## Область видимости {#viewpoint}

С помощью параметров `viewpoint1` и `viewpoint2` вы можете ограничить результаты поиска областью видимости (прямоугольной областью карты). В отличие от геоограничения [прямоугольной областью](#point1-point2), область видимости влияет на ранжирование результатов, но не ограничивает поиск строго заданными границами.

Чтобы указать область видимости, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос](/api/search/places/examples/objects#text), например «кафе».
* `viewpoint1` — координаты левого верхнего угла прямоугольной области в формате `долгота,широта`, например `37.609194,55.773293`.
* `viewpoint2` — координаты правого нижнего угла прямоугольной области в формате `долгота,широта`, например `37.621403,55.767303`.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&viewpoint1=37.609194,55.773293&viewpoint2=37.621403,55.767303&key=API_KEY
```
