# Обработка результатов поиска

Вы можете обрабатывать результаты поиска:

* [сортировать их](#sort) по параметрам;
* [получать определённую страницу результатов поиска](#page);
* [ограничивать количество результатов на странице](#page-size).

## Сортировка результатов {#sort}

С помощью параметра `sort` вы можете сортировать результаты поиска: по удалённости от пользователя, рейтингу объекта и другим параметрам. По умолчанию результаты сортируются по убыванию релевантности. Полный список параметров сортировки см. в [справочнике API](/api/search/places/reference/3.0/items).

Чтобы сортировать результаты поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос с геоограничением](/api/search/places/examples/objects#text), например «кафе пятницкая улица москва». Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `sort` — параметр сортировки, например `sort=name` для сортировки по названию объекта.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе пятницкая улица москва&sort=name&key=API_KEY
```

## Получение результатов по страницам {#page}

В ответе на запрос к API результаты поиска выводятся постранично. По умолчанию каждая страница содержит 20 результатов для основного [ключа в подписке](/platform-manager/subscription/keys#production) и 10 результатов для [демо-ключа](/platform-manager/subscription/keys#demo).

По умолчанию выводится первая страница. С помощью параметра `page` вы можете получить определённую страницу результатов поиска. Параметр `page` можно указать для endpoint-ов:

* [/3.0/items](/api/search/places/reference/3.0/items),
* [/3.0/items/byservicing](/api/search/places/reference/3.0/items/byservicing),
* [/3.0/items/bysite](/api/search/places/reference/3.0/items/bysite),
* [/3.0/items/byphone](/api/search/places/reference/3.0/items/byphone),
* [/3.0/items/byitin](/api/search/places/reference/3.0/items/byitin),
* [/3.0/items/bytradelicense](/api/search/places/reference/3.0/items/bytradelicense),
* [/3.0/items/byfias](/api/search/places/reference/3.0/items/byfias).

Чтобы получить определённую страницу результатов поиска, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос с геоограничением](/api/search/places/examples/objects#text), например «кафе пятницкая улица москва». Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `page` — номер страницы с результатами, например `page=5` для получения пятой страницы. Если вы используете [демо-ключ](/platform-manager/subscription/keys#demo) для доступа к API, максимальное значение — 5.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе пятницкая улица москва&page=5&key=API_KEY
```

## Ограничение количества результатов на странице {#page-size}

В ответе на запрос к API результаты поиска выводятся постранично. По умолчанию каждая страница содержит 20 результатов для основного [ключа в подписке](/platform-manager/subscription/keys#production) и 10 результатов для [демо-ключа](/platform-manager/subscription/keys#demo).

С помощью параметра `page_size` вы можете изменить количество результатов на странице — от 1 до 50. Например, вы можете:

* сократить количество результатов при поиске на карте, чтобы показать ближайшие места без перегрузки интерфейса;
* увеличить количество результатов, чтобы получить больше результатов за один запрос.

Параметр `page_size` можно указать для endpoint-ов:

* [/3.0/items](/api/search/places/reference/3.0/items),
* [/3.0/items/byservicing](/api/search/places/reference/3.0/items/byservicing),
* [/3.0/items/bysite](/api/search/places/reference/3.0/items/bysite),
* [/3.0/items/byphone](/api/search/places/reference/3.0/items/byphone),
* [/3.0/items/byitin](/api/search/places/reference/3.0/items/byitin),
* [/3.0/items/bytradelicense](/api/search/places/reference/3.0/items/bytradelicense),
* [/3.0/items/byfias](/api/search/places/reference/3.0/items/byfias).

Чтобы ограничить количество результатов поиска на странице, отправьте GET-запрос на [/3.0/items](/api/search/places/reference/3.0/items) со следующими параметрами:

* `q` — [текстовый запрос с геоограничением](/api/search/places/examples/objects#text), например «кафе пятницкая улица москва». Вы можете указать геоограничение другим способом: подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
* `page_size` — количество результатов на странице, например `page_size=3` для получения трёх результатов на странице. Если вы используете [демо-ключ](/platform-manager/subscription/keys#demo) для доступа к API, максимальное значение — 10.

**Пример запроса:**

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе пятницкая улица москва&page_size=3&key=API_KEY
```
