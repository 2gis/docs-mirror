# Обзор

Places API позволяет искать различные объекты: организации, здания, достопримечательности, остановки транспорта, парковки и многое другое.

<Video src="/video/Search_ru.mp4" width="900px" />

## Основные возможности {#main-features}

Вы можете искать объекты по:

* названию организации («ИП Иванов»);
* категории или сфере деятельности («рестораны» или «магазины музыкальных инструментов»);
* атрибутам услуг и товаров («кафе с итальянской кухней» или «русская баня на дровах с бассейном»);
* адресу («улица Бауманская, 32»);
* географическому критерию в текстовом запросе («цветы у Бауманской») или в радиусе точки, районе, здании, городе и т. д.;
* координатам («37.630866,55.752256»);
* типу объекта (парковки, остановки, здания, улицы и другие);
* идентификатору объекта («70000001029535674»);
* сайту («2gis.ru»);
* номеру телефона («667-02-99»);
* ИНН («5405276278»);
* торговой лицензии;
* коду ФИАС;
* бренду, времени работы, дате открытия и другим параметрам.

Также вы можете сортировать результаты поиска и работать с настройками поискового движка. Подробнее о каждом параметре см. в [Справочнике API](/api/search/places/reference/3.0/items) и в разделе [Примеры](/api/search/places/examples/objects).

:::tip[Расширенные возможности]

Изучите также [возможности других API поиска](/api-platform?tab=search) и дополните ваши сценарии работы с объектами на карте. Например, чтобы формировать подсказки при поиске объектов, используйте [Suggest API](/api/search/suggest/overview). Если вы хотите создать поисковый виджет на карте, изучите готовый пример [интеграции поисковых API в веб-приложение](./tutorial).

:::

## Дополнительная информация по запросу {#info-on-demand}

Получение некоторой информации об объектах доступно только по запросу и за дополнительную плату. Чтобы приобрести доступ к методам и полям ниже, свяжитесь с [отделом продаж <Brand />](https://dev.2gis.ru/api#form).

* Методы API:

   * [/3.0/items/bysite](/api/search/places/reference/3.0/items/bysite) — поиск организаций по сайту;
   * [/3.0/items/byphone](/api/search/places/reference/3.0/items/byphone) — поиск организаций по номеру телефона;
   * [/3.0/items/byitin](/api/search/places/reference/3.0/items/byitin) — поиск организаций по ИНН;
   * [/3.0/items/bytradelicense](/api/search/places/reference/3.0/items/bytradelicense) — поиск организаций по торговой лицензии;
   * [/3.0/items/byfias](/api/search/places/reference/3.0/items/byfias) — поиск организаций по коду ФИАС.

* Поля (указываются с помощью параметра `fields`):

   * `items.contact_groups` — контакты компании;
   * `items.floors` — количество этажей;
   * `items.floor_plans` — планы этажей;
   * `items.links.database_entrances.apartments_info` — информация о квартирах в доме;
   * `items.employees_org_count` — численность сотрудников организации;
   * `items.itin` — индивидуальный номер налогоплательщика;
   * `items.trade_license` — торговая лицензия филиала;
   * `items.fias_code` — код ФИАС улиц и административных территорий;
   * `items.address.components.fias_code` — код ФИАС зданий;
   * `items.fns_code` — код ФНС административных территорий;
   * `items.okato` — код ОКАТО улиц и административных территорий;
   * `items.address.components.okato` — код ОКАТО зданий;
   * `items.oktmo` — код ОКТМО улиц и административных территорий;
   * `items.address.components.oktmo` — код ОКТМО зданий;
   * `items.structure_info.material` — данные о материале здания;
   * `items.structure_info.apartments_count` — данные о количестве квартир;
   * `items.structure_info.porch_count` — данные о количестве подъездов;
   * `items.structure_info.floor_type` — тип перекрытий в здании;
   * `items.structure_info.gas_type` — тип газоснабжения здания;
   * `items.structure_info.year_of_construction` — год постройки здания;
   * `items.structure_info.elevators_count` — количество лифтов в здании;
   * `items.structure_info.is_in_emergency_state` — факт признания дома аварийным;
   * `items.structure_info.project_type` — серия или проект постройки здания;
   * `items.structure_info.chs_name` — название объекта культурного наследия;
   * `items.structure_info.chs_category` — категория объекта культурного наследия.

### Пример запроса {#request-example}

Запрос к Places API должен содержать:

1. Объект, который нужно найти. Вы можете искать здания, организации, остановки транспорта, парковки, достопримечательности и другие объекты. Подробнее см. в инструкциях [Поиск объектов](/api/search/places/examples/objects) и [Фильтрация по атрибутам](/api/search/places/examples/filtering).
2. Геоограничение поиска: где нужно искать объект. Подробнее см. в инструкции [Геоограничение поиска](/api/search/places/examples/georestriction).
3. Ваш [API-ключ](#get-access-key).

Также вы можете [получать дополнительную информацию об объектах](/api/search/places/examples/additional), [обрабатывать результаты поиска](/api/search/places/examples/results), [настраивать алгоритм поиска](/api/search/places/examples/settings) и т. д.

<br />

Чтобы найти кафе рядом с точкой на карте, отправьте GET-запрос к `/3.0/items`:

```bash
https://catalog.api.2gis.com/3.0/items?q=кафе&location=37.630866,55.752256&key=API_KEY
```

В запросе укажите:

* `q=кафе` — текстовый запрос для поиска объекта: «кафе».
* `location=37.630866,55.752256` — геоограничение: координаты точки, рядом с которой выполняется поиск.
* `key=API_KEY` — значение API-ключа.

### Пример ответа {#response-example}

Ответы на запросы возвращаются в формате JSON.

Краткий пример ответа:

```json
{
    "meta": {
        "api_version": "3.0.20949",
        "code": 200,
        "issue_date": "20260703"
    },
    "result": {
        "items": [
            {
                "address_name": "улица Варварка, 6 ст3",
                "id": "70000001029535674",
                "name": "Зарядье, гастрономический центр",
                "type": "branch"
            },
            ...
        ],
        "total": 1289
    }
}
```

Где:

* `result.items` — массив объектов, соответствующих запросу. Каждый объект содержит:

   * `address_name` — адрес объекта.
   * `id` — ID объекта.
   * `name` — название объекта.
   * `type` — тип объекта.

* `result.total` — общее количество объектов, соответствующих запросу.

Чтобы получить в ответе дополнительные поля, укажите их в параметре `fields` запроса. Подробнее см. в инструкции [Дополнительная информация об объектах](/api/search/places/examples/additional).

Подробнее о каждом параметре см. в [Справочнике API](/api/search/places/reference/3.0/items).

## Тарифы и лимиты {#tariffs}

* Стоимость сервиса рассчитывается исходя из количества успешных запросов в месяц. Успешным запросом к API считается запрос, который возвращает HTTP-код 200 в поле `meta.code` в теле ответа, например:

    ```json
    {
        "meta": {
            "api_version": "3.0.17799",
            "code": 200,
            "issue_date": "20240524"
        },
        ...
    }
    ```

* Для демо-ключей и ключей, созданных в рамках подписки, действуют лимиты на использование сервиса.
* Актуальную стоимость и лимиты см. в инструкции [Тарифы](/platform-manager/subscription/pricing).

## Варианты размещения {#distribution}

* **Облако**: все актуальные методы Places API доступны через публичные endpoint-ы <Brand />.
* **On-Premise**: все актуальные методы Places API доступны при установке API-платформы <Brand /> в закрытом контуре. Подробнее см. в разделе [API-платформа для сервера](/on-premise-api-platform/overview/summary).

Методы, отмеченные как `deprecated`, устарели и не поддерживаются в обоих вариантах размещения.
