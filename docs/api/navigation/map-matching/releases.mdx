# Релизы

## 27 июля 2026 г.

* Ответ с ограничениями скорости стал детальнее: теперь при `need_speed_limits: true` дополнительно возвращается разбивка ограничений по отрезкам маршрута: см. параметр `speed_limits`.

## 23 марта 2026 г.

* Добавлена возможность настраивать обработку некорректных точек в запросе: см. параметр `bad_point_tolerance`.

## 17 марта 2026 г.

* Добавлена возможность регулировать радиус поиска узлов графа для GPS-точки: см. параметр `search_radius`.

## 1 декабря 2025 г.

* Обновлена сетка тарифов на API-сервисы. Подробнее об изменениях см. в [личном кабинете](https://platform.2gis.ru/ru/tariffs?utm_source=docs&utm_medium=referral&utm_campaign=api_mapmatching).

## 25 февраля 2025 г.

* Добавлена возможность получать ограничения скорости, действующие на участках маршрута: см. параметр `need_speed_limits`.

## 12 июля 2021 г.

* Выпущен Map Matching API — алгоритм восстановления маршрута из набора точек, записанных транспортным средством.
