# Релизы

Доступны две версии MapGL JS API:

* (**рекомендуется**) Мажорная версия: https://mapgl.2gis.com/api/js/v1
* Фиксированная версия: https://mapgl.2gis.com/api/js/v1.77.0

Мажорная версия гарантирует стабильный API (критические изменения вводятся в следующей мажорной версии). Она регулярно обновляется: добавляются новые возможности, исправляются ошибки и улучшается производительность.

Фиксированная версия не обновляется, поэтому срок поддержки составляет три месяца после выхода новой версии. В течение срока поддержки гарантируется работоспособность версии. Используйте фиксированную версию только при необходимости проверки [целостности подресурсов (SRI)](https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity) и регулярно её обновляйте.
