# Заливка полигона текстурой

Для кастомизации стилевого слоя с типом `polygon` помимо цвета и параметров обводки вы можете задать текстурный паттерн, который будет бесшовно применён к полигону. Текстура задаётся с помощью SVG-изображения: вы можете добавить собственное изображение или использовать существующую иконку из стиля.

Чтобы растянуть текстуру по ширине и высоте независимо, некоторым браузерам (например, Firefox) требуется наличие атрибута `preserveAspectRatio` со значением `none` у SVG-изображения.

:::warning

Заливка полигона текстурой доступна только в [Редакторе стилей](https://styles.2gis.com/).

:::

## Использование существующей в стиле иконки

Выберите существующий на карте полигон, который нужно залить текстурой (в данном случае, стилевой слой с именем `River`). На вкладке **Стиль** выберите любую существующую иконку.

При необходимости вы можете изменить размер ячейки текстурного паттерна в полях **Ширина** и **Высота** в разделе **Размер текстуры**, и задать её прозрачность в разделе **Прозрачность текстуры**.

![Существующая текстура](/img/mapgl/texturedpolygon/existing_texture.png)

## Добавление собственной текстуры на полигон

Процесс заливки полигона собственной текстурой схож с применением существующей иконки, описанным выше.

1. Добавьте текстуру (иконку) к стилю в меню **Иконки** → **Загрузить иконки** → **Выбрать файлы**:

   ![load\_icons](/img/mapgl/texturedpolygon/load_icons_ru.png)

   ![choose\_files](/img/mapgl/texturedpolygon/choose_files_ru.png)

2. Создайте новый стилевой слой с типом `polygon` и выберите данные **Водные объекты** (Water area) для него: **Создать новый слой** → **Данные** → **Водные объекты** (Water area).

   ![Выбор данных](/img/mapgl/texturedpolygon/select_data.png)

3. Выберите добавленную текстуру и для лучшего визуального эффекта увеличьте размер её ячейки до 256×256 пикселей.

   ![Собственная текстура](/img/mapgl/texturedpolygon/custom_texture.png)
