В программном комплексе <Brand /> используется несколько типов ключей и токенов.

## Лицензия на программный комплекс <Brand /> {#license}

[Сервис лицензий](/on-premise-api-platform/architecture/license) использует лицензию на программный комплекс <Brand /> для контроля доступа к сервисам, а [утилита 2GIS CLI](../overview/2gis-cli/overview) — для получения артефактов установки.

Лицензия выдаётся при покупке программного комплекса <Brand /> и привязана к определённому набору сервисов.

## API-ключи {#api-keys}

![API-ключи](/img/on-premise/keys-types-2.png)

Администратор [сервиса API-ключей](/on-premise-api-platform/architecture/keys) создаёт API-ключи с помощью интерфейса администратора. Конечные приложения затем используют эти ключи для доступа к развёрнутым сервисам программного комплекса <Brand />.

## Сервисные токены {#service-tokens}

Сервисы программного комплекса <Brand /> используют сервисные токены для связи с [сервисом API-ключей](/on-premise-api-platform/architecture/keys) для валидации API-ключей и других операций.

Сервисные токены формируются после установки сервиса API-ключей и уникальны для каждого инстанса сервиса. Администратор сервиса API-ключей не может генерировать сервисные токены, но может получить их для настройки сервисов, работающих с API-ключами.
