# Создание демо-ключа

Демо-ключ позволяет бесплатно протестировать API <Brand /> для работы с картами, навигацией и поиском. Бесплатный демо-ключ создаётся только один раз и действует один месяц со дня создания. Для каждого сервиса действует лимит на количество запросов: см. раздел [Лимиты](/platform-manager/subscription/pricing#limits).

1. Зарегистрируйтесь в личном кабинете Менеджер Платформы.

   <CtaButton href="https://platform.2gis.ru/ru/?utm_source=docs&utm_medium=referral&utm_campaign=account" target="_blank">
      В кабинет
   </CtaButton>

2. На вкладке **Главная** нажмите **Создать демо-ключ**.
3. Введите название ключа и нажмите **Создать**.

После [покупки подписки](/platform-manager/subscription/purchase) демо-ключ можно перевести в «боевой» режим — для него станут доступны все сервисы в подписке. Подробнее см. в разделе [Изменение режима ключа](/platform-manager/subscription/managing-keys#changing-key-mode).
