# Шаблоны

**Шаблоны** — это подготовленные наборы атрибутов для [создания агентов](/geoflow/administrator/managing/agents#creating-agent) и [создания задач](/geoflow/administrator/tasks#importing-tasks). Шаблоны позволяют:

* создавать типовых агентов (например, курьеров) и типовые задачи (например, доставка);
* фильтровать агентов на дашборде [мониторинга](/geoflow/administrator/monitoring) по типу;
* использовать данные при планировании смен.

В роли **Главный администратор** и **Администратор компании** вы можете работать с шаблонами на вкладке **Управление → Шаблоны**:

* [создавать шаблоны агентов](#creating-agent-template),
* [создавать шаблоны задач](#creating-task-template),
* [редактировать шаблоны](#editing-template),
* [дублировать шаблоны](#duplicating-template).

В роли **Диспетчер** и **Руководитель группы агентов** вы можете просматривать список шаблонов и информацию о них.

## Создание шаблона агента {#creating-agent-template}

![Создание шаблона агента](/img/geoflow/creating-agent-template-620.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. Выберите в выпадающем списке **Агент**.
4. Чтобы создать собственный шаблон агента, оставьте поле **Предзаполнить из набора** пустым. Чтобы использовать предзаполненный шаблон, выберите в этом поле один из готовых типов агентов:

   * **Оператор**: сотрудник, выполняющий задачи.
   * **Курьер**: сотрудник, доставляющий документы или посылки.
   * **Спецтехника**: транспортные средства или машины, выполняющие работы. Например, курьерский автомобиль, бензовоз, экскаватор и т. д.

   Параметры из шагов ниже заполнятся автоматически для выбранного типа. При необходимости вы можете отредактировать их.

5. В поле **Название** введите общее название для типа агентов.
6. (Опционально) В блоке **Вид на карте** укажите отображение иконки агентов на карте. Нажмите на превью карты и укажите параметры:

   * **Иконка**: иконка агента.
   * **Цвет**: цвет иконки.

   Нажмите **Сохранить**.

7. В блоке **Атрибуты** укажите список полей для создания агентов этого типа.

   Для каждого шаблона по умолчанию добавляется обязательный атрибут с типом данных `Текстовое поле` для идентификации агента: для предзаполненных шаблонов — `Идентификатор`, для собственных — `Наименование`. В качестве значения атрибута можно указать любой уникальный набор символов (например, табельный номер или ФИО). Вы можете переименовать этот атрибут.

   Каждый атрибут содержит параметры:

   * **Заголовок**: название атрибута.
   * **Тип данных**: тип данных атрибута.
   * **Обязательное поле**: чтобы сделать поле обязательным для заполнения при создании агента, отметьте чекбокс.
   
   Для атрибутов с типом данных `Справочник` доступен дополнительный параметр **Разрешить множественный выбор**. Чтобы разрешить выбирать несколько значений из [справочника](/geoflow/administrator/managing/directories), отметьте чекбокс.

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

8. Нажмите **Сохранить**.

## Создание шаблона задачи {#creating-task-template}

![Создание шаблона задачи](/img/geoflow/creating-task-template-620.png)

1. Перейдите на вкладку **Управление → Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. Выберите в выпадающем списке **Задача**.
4. В поле **Название** введите общее название для типа задач.
5. В блоке **Атрибуты** укажите список полей для создания задач этого типа.

   Для каждого шаблона по умолчанию добавляется обязательный атрибут `Название` для идентификации задачи. В качестве значения атрибута можно указать любой уникальный набор символов (например, номер задачи или название). Вы можете переименовать этот атрибут.
   
   Каждый атрибут содержит параметры:

   * **Заголовок**: название атрибута.
   * **Тип данных**: тип данных атрибута.
   * **Обязательное поле**: чтобы сделать поле обязательным для заполнения при создании задачи, отметьте чекбокс.
   
   Для атрибутов с некоторыми типами данных доступны дополнительные параметры:

   | **Тип данных** | **Дополнительные параметры** |
   | --- | --- |
   | `Справочник` | **Разрешить множественный выбор**: чтобы разрешить выбирать несколько значений из [справочника](/geoflow/administrator/managing/directories), отметьте чекбокс. |
   | `Дата и время` | **Время на задачу в минутах**: чтобы ограничить время на выполнение задачи, отметьте чекбокс. |

   Чтобы добавить дополнительный атрибут, нажмите **Добавить атрибут**. Чтобы удалить атрибут, нажмите значок ![Удалить](/img/pro/trash-icon.svg) рядом с ним. Чтобы изменить порядок атрибутов, зажмите значок ![Перемещение](/img/pro/drag-n-drop-icon.svg) у атрибута и перетащите его.

6. Нажмите **Сохранить**.

## Редактирование шаблона {#editing-template}

:::warning

Редактирование шаблона (например, его атрибутов) изменяет настройки всех агентов или задач, созданных по этому шаблону.

:::

Вы можете редактировать шаблон:

* переименовать шаблон;
* изменить список атрибутов, их названия, тип и обязательность для заполнения;
* дополнительно для шаблонов агентов: изменить вид иконки агента на карте.

<br />

Чтобы отредактировать шаблон:

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Изменить**.
3. Внесите изменения в шаблон.
4. Нажмите **Сохранить**.

## Дублирование шаблона {#duplicating-template}

1. Перейдите на вкладку **Управление → Шаблоны**.
2. В строке шаблона нажмите значок ![Меню шаблона](/img/menu-dots-horizontal.svg) и выберите **Дублировать**.
3. (Опционально) Укажите новые параметры шаблона.
4. Нажмите **Сохранить**.
