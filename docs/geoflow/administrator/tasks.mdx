# Задачи

Вы можете создавать или импортировать **задачи** для [агентов](/geoflow/administrator/managing/agents), например: доставить груз, провести инспекцию и т. д. Задачу можно назначить агенту в [смене](/geoflow/administrator/shifts), если он обладает всеми [навыками](/geoflow/administrator/managing/skills), которые требуются для её выполнения. Агент может просматривать список своих задач в текущей смене в [мобильном приложении](/geoflow/operator/tasks).

Перед созданием или импортом задач [создайте шаблон задачи](/geoflow/administrator/managing/templates#creating-task-template) с набором атрибутов.

В роли **Главный администратор**, **Администратор компании** и **Диспетчер** вы можете работать с задачами на вкладке **Задачи**:

* [создавать задачи](#creating-task),
* [импортировать задачи](#importing-tasks),
* [просматривать информацию о задачах](#viewing-task),
* [редактировать задачи](#editing-task).

В роли **Руководитель группы агентов** вы можете просматривать задачи, назначенные на агентов своей группы.

## Создание задачи {#creating-task}

![Создание задачи](/img/geoflow/creating-task-697.png)

1. Перейдите на вкладку **Задачи**.
2. Нажмите **Добавить задачу**.
3. Укажите дату и время выполнения задачи:

   * **Дата**: дата выполнения задачи.
   * **Временное окно**: время выполнения задачи.
   * **Часовой пояс**: часовой пояс, для которого указывается дата и время выполнения задачи.
   * **Жёсткое окно**: отметьте чекбокс, если задачу нужно выполнить только в указанное время. Если параметр указан, агент не сможет выполнить задачу раньше или позже указанного времени.

4. Укажите другие атрибуты задачи, которые зависят от [шаблона задачи](/geoflow/administrator/managing/templates#creating-task-template).

## Импорт задач {#importing-tasks}

![Импорт задач](/img/geoflow/import-task-697.png)

Чтобы создать несколько задач с похожими атрибутами из одного [шаблона задачи](/geoflow/administrator/managing/templates#creating-task-template), скачайте шаблон, заполните его и импортируйте задачи из файла в формате CSV:

1. Перейдите на вкладку **Задачи**.
2. Нажмите **Импорт из CSV**.
3. Если вы создали несколько шаблонов задачи, выберите один из них.
4. Нажмите **Скачать шаблон**.
5. Заполните шаблон данными о задачах. В шаблоне указано, какие данные нужно добавить, и приведён пример заполнения.

   Один файл может содержать до 150 задач.

6. Вернитесь на вкладку **Задачи**, перетащите файл в область загрузки или нажмите **Выберите файл на компьютере**.

   Ограничение на размер файла — 5 МБ.

7. Если в файле есть ошибки, появится уведомление о строках с ошибками. Чтобы загрузить задачи, исправьте ошибки и загрузите файл заново.

Задачи отобразятся в списке задач после обработки файла.

## Просмотр информации о задаче {#viewing-task}

1. Перейдите на вкладку **Задачи**.
2. Вы можете искать задачи по названию, фильтровать их по типу (шаблону) задачи и по статусу: активным и завершённым.

<br />

В строке каждой задачи отображается:

* **Название**: уникальное название задачи, указанное при создании. Поле может иметь другое название в зависимости от [шаблона задачи](/geoflow/administrator/managing/templates#creating-task-template), например `Идентификатор`.
* **Статус**: статус задачи.
* **Дата**: дата выполнения задачи.
* **Временное окно**: время выполнения задачи.
* **Жёсткое окно**: отметка, что задачу нужно выполнить только в указанное время.
* **Обновлено**: дата и время последнего редактирования задачи.

Также могут отображаться другие столбцы с атрибутами, которые зависят от [шаблона задачи](/geoflow/administrator/managing/templates#creating-task-template).

## Редактирование задачи {#editing-task}

Вы можете изменить дату и время выполнения задачи и другие атрибуты, которые зависят от [шаблона задачи](/geoflow/administrator/managing/templates#creating-task-template).

1. Перейдите на вкладку **Задачи**.
2. Выберите тип (шаблон) задачи.
3. Откройте карточку задачи в списке и нажмите **Изменить задачу**.
4. Внесите изменения в задачу.
5. Нажмите **Сохранить**.
