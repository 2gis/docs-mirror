# Уведомления

В роли **Главный администратор**, **Администратор компании**, **Диспетчер** и **Руководитель группы агентов** вы можете просматривать уведомления на вкладке **Уведомления** в веб-панели администратора. Уведомления отправляются при следующих событиях:

* Агент вошёл в геозону.
* Агент вышел из геозоны.
* Агенту назначена задача.
* На устройстве агента низкий уровень заряда батареи. Только для пользователей с ролью **Руководитель группы агентов**. Также уведомление отправляется в [мобильное приложение](/geoflow/operator/settings).

Агенты (пользователи с ролью **Сотрудник**) могут просматривать уведомления в мобильном приложении: см. список [уведомлений](/geoflow/operator/settings).

Список событий, при которых отправляются уведомления, изменить нельзя.

![Вкладка Уведомления](/img/geoflow/managing-notifications-698.png)

На вкладке **Уведомления** доступно несколько разделов:

* **Непрочитанные**: уведомления, которые вы ещё не прочитали. Чтобы отметить все уведомления как прочитанные, нажмите **Прочитать все**.
* **Все**: все уведомления.
* **Задачи**: уведомления о задачах.
* **Геозоны**: уведомления о геозонах.
