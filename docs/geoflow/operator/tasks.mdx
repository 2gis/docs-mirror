# Задачи

На вкладке **Задачи** мобильного приложения отображается список задач для агента на смене.

В карточках задач отображаются данные, которые указал администратор при создании задачи (например, время выполнения, необходимые навыки и т. д.). Подробнее см. в [Руководстве администратора](/geoflow/administrator/tasks).

<img src="/img/geoflow/operator-tasks-620.png" alt="Вкладка Задачи" width="300"/>

## Начало работы {#getting-started}

Чтобы начать работать с задачей:

1. Перейдите на вкладку **Задачи** и откройте текущую смену.
2. Выберите задачу и нажмите **Взять в работу**.

   <img src="/img/geoflow/operator-tasks-start-620.png" alt="Взять задачу в работу" width="300"/>

3. Чтобы завершить работу над задачей, откройте её карточку и нажмите **Завершить задачу**.
4. Выберите статус результата задачи: **Выполнена** или **Не выполнена**.

   <img src="/img/geoflow/operator-tasks-finish-620.png" alt="Завершить задачу" width="300"/>

Завершённые задачи отобразятся на вкладке **Завершённые**. Оставшиеся активные задачи — на вкладке **Активные**.
