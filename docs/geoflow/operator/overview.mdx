# Обзор мобильного приложения

Мобильное приложение 2ГИС ГеоПоток позволяет сотрудникам просматривать карту и список своих задач.

Мобильное приложение записывает данные о перемещениях агента (сотрудника или транспорта) в течение смены. Эти данные позволяют администраторам отслеживать перемещения агентов в реальном времени и анализировать их историю в веб-панели: см. [Руководство администратора](/geoflow/administrator/overview).

:::tip[2ГИС Логистика]

Если 2ГИС ГеоПоток используется вместе с [2ГИС Логистикой](/logistics/overview), то в мобильном приложении сотрудники могут использовать навигатор для построения маршрута: см. [Руководство сотрудника 2ГИС Логистики](/logistics/operator/overview).

:::

## Интерфейс приложения {#application-interface}

В роли **Сотрудник** вы можете работать со следующими вкладками в мобильном приложении:

* **[Карта](/geoflow/operator/map)**: для просмотра карты и информации об агентах и сменах.
* **[Задачи](/geoflow/operator/tasks)**: для просмотра задач внутри смен и работы с ними. Задачи и смены создают пользователи с ролями **Главный администратор**, **Администратор компании** и **Диспетчер** в веб-панели: подробнее см. в [Руководстве администратора](/geoflow/administrator/tasks).
* **[Профиль](/geoflow/operator/settings)**: для просмотра уведомлений и управления настройками.
