# Сервис лицензий 

## Обновление сервиса лицензий

1. Получите новые артефакты для установки.

   Для этого укажите в конфигурационном файле 2GIS CLI новую версию компонента `core` (см. [Релизы базовых сервисов](/on-premise-api-platform/releases/core)) и [выполните команду загрузки](/on-premise-api-platform/installation#fetch-artifacts).

   См. [справку по командам и аргументам 2GIS CLI](/on-premise-api-platform/overview/2gis-cli/help).

2. Ознакомьтесь со [списком критических изменений](/on-premise-api-platform/releases/core). Если необходимо, обновите настройки в конфигурационном файле `values-license.yaml`. Подробнее см. в [руководстве по установке](/on-premise-api-platform/installation#install-license).

   :::note

   Если вы обновляете базовые сервисы с версии 2.12.0 или ниже до версии 2.13.0 или выше, предварительно обновите утилиту 2GIS CLI до версии 3.8.0 или выше и API-платформу до версии 2.61.0 или выше. Подробнее см. в разделе [Получение лицензии после обновления базовых сервисов до версии 2.13.0](#update-from-2-12).

   :::

3. Выполните команду для обновления сервиса:

   ```bash
   helm upgrade --version=VERSION --atomic --wait-for-jobs --values ./values-license.yaml license 2gis-on-premise/license
   ```

   В параметр `--version` подставьте новую версию компонента `core`, которую вы указывали в конфигурационном файле 2GIS CLI.

   :::warning

   Версии сервисов внутри компонента должны быть одинаковыми и совпадать с версией компонента.

   :::

## Получение лицензии после обновления базовых сервисов до версии 2.13.0 {#update-from-2-12}

Начиная с версии базовых сервисов 2.13.0, лицензия привязана не к сертификату сервера Kubernetes API, а к данным в хранилище состояний сервиса лицензий (параметры `persistence` в `values-license.yaml`). Вернуться к прежнему способу привязки нельзя.

Ваша текущая лицензия после обновления базовых сервисов продолжит работать. Когда вам потребуется новая лицензия (например, при изменении состава сервисов или истечении срока действия), запросите её с учётом нового способа привязки:

1. Убедитесь, что используете утилиту 2GIS CLI версии 3.8.0 или выше.
2. Откройте директорию **license-dir** в S3-хранилище артефактов установки и перейдите в поддиректорию со старшим номером. Убедитесь, что в ней есть файл `trust-anchor.hash`.

   Сервис лицензий создаёт этот файл автоматически при первом запуске после обновления. Файл заменяет `k8s-ca.crt` при запросе лицензии, редактировать его не нужно. Если файла нет, дождитесь его появления.

3. [Получите новую лицензию](/on-premise-api-platform/installation#get-license).

:::warning

Если запросить лицензию с помощью 2GIS CLI версии ниже 3.8.0, будет выдана лицензия старого формата. Сервис лицензий её не примет, и повторно запросить лицензию с тем же порядковым номером не получится. В этом случае обратитесь в службу поддержки On-Premise, чтобы частично аннулировать лицензию на стороне <Brand />, и запросите лицензию повторно с помощью 2GIS CLI версии 3.8.0 или выше.

:::
