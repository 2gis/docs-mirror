# Обновление Менеджера Платформы

1. Получите новые артефакты для установки. Для этого укажите в конфигурационном файле 2GIS CLI новую версию компонента `core` (см. [Релизы базовых сервисов](/on-premise-api-platform/releases/core)) и [выполните команду загрузки](/on-premise-api-platform/installation#fetch-artifacts).

   См. [справку по командам и аргументам 2GIS CLI](/on-premise-api-platform/overview/2gis-cli/help).

2. Ознакомьтесь со [списком критических изменений](/on-premise-api-platform/releases/core). Если необходимо, обновите настройки в конфигурационном файле `values-platform.yaml`. Подробнее см. в [руководстве по установке](/on-premise-api-platform/installation#install-platform).

3. Выполните команду для обновления сервиса:

   ```bash
   helm upgrade --version=VERSION --atomic --values ./values-platform.yaml platform 2gis-on-premise/platform
   ```

   В параметр `--version` подставьте новую версию компонента `core`, которую вы указывали в конфигурационном файле 2GIS CLI.

   :::warning

   Версии сервисов внутри компонента должны быть одинаковыми и совпадать с версией компонента.

   :::

4. [Проверьте работоспособность сервиса](/on-premise-api-platform/installation#test-pm).
