# Platform ID

Platform ID — сервис аутентификации и управления пользователями на базе Keycloak с поддержкой протокола [OpenID Connect (OIDC)](https://openid.net/connect/). С Platform ID можно использовать программный комплекс <Brand /> без настройки внешнего сервиса аутентификации. 

Если у вас уже есть поставщик OIDC, вы можете подключить Менеджер Платформы к нему вместо Platform ID. Подробнее см. в разделе [Настройка аутентификации пользователей](/on-premise-api-platform/installation#authentication).

## Архитектура {#architecture}

<NoInvert>
![Архитектура Platform ID](/img/on-premise/platform-id-architecture.svg)
</NoInvert>

Порядок аутентификации пользователя в Менеджере Платформы с Platform ID:

1. Менеджер Платформы перенаправляет браузер пользователя на форму входа Platform ID.
2. Platform ID проверяет учётные данные пользователя и выдаёт OIDC-токен.
3. Менеджер Платформы обращается к сервису API-ключей от имени пользователя. Сервис API-ключей проверяет токены в Platform ID и привязывает пользователей к компании.
4. Последующие запросы пользователя выполняются в рамках сессии продукта.

Информация о пользователях хранится в [realm-ах](https://www.keycloak.org/docs/latest/server_admin/#_configuring-realms) — изолированных пространствах со своими пользователями, клиентами и настройками аутентификации.
