# Styles API

Сервис предоставляет стили карты по умолчанию и API для подключения пользовательских стилей. Вы можете создать собственный стиль в [Редакторе стилей](https://styles.2gis.com/), загрузить его в контур On-Premise через интерфейс [Менеджера Платформы](/on-premise-api-platform/architecture/platform) и подключить к своей карте в настройках MapGL JS API. Подробнее см. в инструкции [Загрузка и применение стиля карты](/on-premise-api-platform/platform-manager#adding-map-style).

Если Styles API не установлен, к карте применится стиль по умолчанию, поставляемый с MapGL JS API.
