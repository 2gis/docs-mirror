# React Native SDK

React Native SDK позволяет добавить карту <Brand /> в ваше приложение на платформе React Native. С помощью SDK можно отобразить карту на экране, получать информацию об объектах карты, строить маршруты, использовать навигатор и работать с офлайн-данными.

Примеры использования SDK см. в разделе [Примеры](/react-native/sdk/examples/base).

Картографические данные поддерживают [стандарты OGC](https://ru.wikipedia.org/wiki/Open_Geospatial_Consortium).

Вы можете использовать React Native SDK на устройствах с операционными системами iOS и Android.

## Версии SDK {#versions}

Пакет React Native SDK в первом релизе доступен в версии **Map** ([@2gis/dgis-mobile-sdk-map](https://www.npmjs.com/package/@2gis/dgis-mobile-sdk-map)) — облегчённая версия, которая позволяет:

* Добавлять [карту](/react-native/sdk/examples/map) в приложение и управлять ей: добавлять маркеры и геометрические фигуры, управлять движением камеры, отображать слои, работать со стилевыми атрибутами карты и т. д.
* Искать объекты в [справочнике](/react-native/sdk/examples/directory): организации, здания, места и другие.

Версия **Full**, которая позволяет работать с навигацией и оффлайн-данными, появится в будущих релизах.

## API для работы SDK {#api-list}

В зависимости от нужных функциональностей, для работы SDK требуются ключи доступа к API карт, поиска и навигации. Доступные возможности зависят от [версии SDK](#versions): **Full** или **Map**.

При использовании ключа оплачивается только доступ к используемым API, в зависимости от количества отправленных запросов и полученных ответов. Вы можете работать с ключами в личном кабинете [Менеджер Платформы](https://platform.2gis.ru/ru/?utm_source=docs&utm_medium=referral&utm_campaign=sdk_react_native).

## Требования к устройствам {#system-requirements}

iOS 16 и выше / iPadOS 16 и выше.

## Варианты размещения {#distribution}

* **Облако**: React Native SDK доступен для работы в облачной инфраструктуре <Brand />.
* **On-Premise**: доступность React Native SDK при установке API-платформы <Brand /> в закрытом контуре зависит от версии React Native SDK и набора включённых сервисов API-платформы.

Подробнее см. в разделе [API-платформа для сервера](/on-premise-api-platform/overview/summary).
