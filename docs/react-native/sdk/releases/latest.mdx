# Релизы

:::warning

Версии 14.х являются предварительными. API может изменяться без обратной совместимости в последующих минорных релизах.

:::

## 14.2.0 (2026-10-13)

### 🌟 Новые возможности

* В пакете `@2gis/dgis-mobile-sdk-full` добавлен экспериментальный `NavigationView` — готовый React Native UI-элемент навигации поверх карты. Компонент принимает `NavigationManager`, `MapController`, функции обратного вызова для определения геопозиции и завершения маршрута, а также поддерживает настройку поведения UI-элементов карты.
* Добавлен `copyAppAssetToFile()` для копирования React Native asset в файл. Это удобно для сценариев, где SDK ожидает путь к файлу, например при загрузке файлов стиля.

### 🛠 Исправления

* Исправлена загрузка файлов `assets`.

## 14.1.0 (2026-09-25)

### 🌟 Новые возможности

* Теперь пакеты React Native собираются с Native SDK 14.1.0 и получают обновления Android и iOS SDK соответствующего релиза.
* В сгенерированном API Native SDK добавлен публичный источник рельефа `DgisSource.createReliefDgisSource()`. Рельеф автоматически включается только для регионов, где он поддерживается.
* В `PackageInfo` добавлено поле `description` — локализованное развёрнутое описание пакета, в том числе для голосовых пакетов и пакетов территорий в Full-версии SDK.
* Для пакетов `@2gis/dgis-mobile-sdk-map` и `@2gis/dgis-mobile-sdk-full` добавлены README с требованиями, установкой peer dependencies, настройкой `dgissdk.key`, шагами Android/iOS и базовым примером создания карты.
* В файлы `package.json` добавлены `homepage`, `license` и обновлены описания пакетов.
* Добавлена поддержка WebSocket-транспорта на Android и iOS и передача заголовка `X-Session-ID` в HTTP-запросах SDK.
* В автомобильной навигации включён провайдер данных о светофорах на маршруте и обновлена логика подключения к транспортным топикам.

### ❗ Изменения, влияющие на обратную совместимость

* `@2gis/dgis-mobile-sdk-map` теперь явно требует `react-native-svg` как peer dependency. Добавьте пакет в приложение вместе с `react-native-safe-area-context`, чтобы React Native autolinking подключил native-модуль.
* В `PackageInfo` добавлено обязательное поле `description`. Если приложение самостоятельно создаёт объекты `PackageInfo`, передайте в них локализованное описание пакета.

### 🛠 Исправления

* Улучшена потокобезопасность карты: обновление кластеризации при добавлении и удалении объектов, удаление `MapData` и динамических объектов выполняются на render-очереди.
* В iOS-части SDK исправлено поведение поисковых подсказок и закрытие карточки объекта в поисковых демо.
