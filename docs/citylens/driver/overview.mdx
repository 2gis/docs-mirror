# Обзор мобильного приложения

Мобильное приложение <Brand /> Ситискан позволяет водителям записывать данные во время вождения автомобиля. Приложение доступно для устройств на iOS и Android.

## Интерфейс приложения {#application-interface}

В роли **Водитель** вы можете работать со следующими вкладками в мобильном приложении:

* **Статистика**: для просмотра ежедневной статистики по пройденному расстоянию и количеству загруженных и обработанных кадров. Данные обновляются после загрузки треков.
* **Ситискан**: для записи данных в одном из режимов или загрузки записанных треков. Подробнее см. в инструкции [Запись данных](/citylens/driver/record).
* **Настройки**: для настройки параметров съёмки и просмотра информации о приложении и учётной записи. Подробнее см. в инструкции [Настройки](/citylens/driver/settings).

## Обновление приложения {#updating-application}

<Tabs>
<TabItem value="ios" label="iOS" default>

TestFlight присылает уведомление при выходе новой версии приложения. Включите уведомления для TestFlight на устройстве, чтобы не пропускать обязательные обновления.

Чтобы установить обновление:

1. Откройте приложение TestFlight.
2. Выберите приложение **Ситискан** (или **CityLens** в зависимости от сборки).
3. Нажмите **Обновить**.

</TabItem>
<TabItem value="android" label="Android">

Новые версии приложения <Brand /> Ситискан публикуются в репозитории F-Droid. Чтобы установить обновление:

1. Откройте приложение F-Droid.
2. Перейдите в раздел **Настройки** → **Обновления**.
3. Нажмите **Обновить** рядом с приложением **Ситискан** (или **CityLens** в зависимости от сборки).

<br />

Если новая версия, о которой вы получили информацию от менеджера <Brand />, не появилась в F-Droid, обновите кеш F-Droid:

1. Откройте приложение F-Droid.
2. Перейдите в раздел **Настройки** → **Обновления**.
3. Потяните экран вниз, чтобы обновить кеш. Новая версия приложения появится в F-Droid.

<br />

Если после обновления кеша новая версия приложения не появилась в F-Droid:

1. На вашем устройстве перейдите в раздел **Настройки** → **Все приложения**.
2. Нажмите **Очистить кеш** для приложения F-Droid.
3. Повторно добавьте репозиторий приложения <Brand /> Ситискан в F-Droid и повторите процесс установки: см. раздел [Установка мобильного приложения](/citylens/driver/start#install-application).

Если проблема сохраняется, удалите приложение <Brand /> Ситискан и установите его заново.

</TabItem>
</Tabs>
