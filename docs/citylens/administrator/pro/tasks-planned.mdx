# Задачи (План)

В наборе данных **Задачи (План)** представлена информация о задачах, созданных в [Планировщике задач](/citylens/administrator/planner/overview). Набор данных содержит данные только о завершённых задачах.

## Начало работы {#getting-started}

![Задачи (План)](/img/pro/data-tasks-planned-784.png)

1. Перейдите на вкладку **Главная** или **Данные**.
2. Выберите набор данных **Задачи (План)**.
3. В окне **Настройки геофильтров** выберите до 50 территорий, для которых будет создана выборка данных. Вы можете использовать стандартные и собственные территории, а также строить полигоны, зоны доступности и окружности на карте. Подробнее см. в разделе [Геофильтры](/pro/data/overview#geofilters). После выбора территорий нажмите **Готово**.
4. На вкладке **Фильтры** настройте остальные [фильтры](#filters) при необходимости.

<br />

Данные будут отображены на карте в виде линий (запланированных маршрутов) или точек-центроидов: центров геометрий объектов. Результаты фильтрации доступны в двух вкладках:

* **Статистика**: общие статистические данные о выборке:

   * Общее количество задач.
   * Запланированное расстояние для объезда в километрах.
   * Общее планируемое время выполнения задач в часах.
   * Диаграмма с распределением задач по проектам. Отображается, если выбрано несколько проектов.

* **Результаты**: общая информация о задачах и их список. При выборе задачи из списка:

   * Откроется карточка с информацией о задаче.
   * На карте отобразится маршрут. Чтобы приблизить, нажмите **Показать на карте**.

   Вы можете изменить вручную список результатов фильтрации, чтобы оставить в выборке только выбранные задачи. Для этого нажмите **Изменить список**, выберите задачи и нажмите **Применить**.

Чтобы сохранить выборку, нажмите **Создать слой** и настройте [визуализацию данных](/pro/data/visualization/overview).

## Фильтры {#filters}

Для набора данных **Задачи (План)** доступны следующие фильтры:

* **Идентификатор задачи**: [идентификатор задачи](/citylens/administrator/planner/tasks#viewing-task) из Планировщика задач.
* **Название проекта**: [название проекта](/citylens/administrator/planner/projects#viewing-project), к которому относится задача.
* **Email**: email водителя.
* **ФИО водителя**: полное имя водителя.
* **Версия приложения**: версия мобильного приложения на устройстве водителя.
* **Назначена**: дата назначения водителя на задачу. Вы можете указать временной интервал.
* **Завершена**: дата завершения задачи. Вы можете указать временной интервал.
* **Планируемое время, ч**: ожидаемое время выполнения задачи в часах.
* **Планируемое расстояние, км**: ожидаемая длина маршрута в задаче в километрах.
* **Выполнение, %**: процент выполнения задачи.

Чтобы сбросить фильтр по параметру, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с именем фильтра. Чтобы сбросить все фильтры по параметрам, нажмите **Очистить фильтры** внизу вкладки.

Чтобы скрыть фильтр по территории, в окне **Настройки геофильтров** нажмите значок ![Глаз](/img/pro/hide-eye-icon.svg) рядом с именем геофильтра. Чтобы удалить геофильтр, нажмите значок ![Крестик](/img/pro/cross-icon.svg) рядом с его именем. Чтобы удалить все геофильтры, нажмите **Очистить фильтры**.
