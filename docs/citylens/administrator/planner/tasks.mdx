# Задачи

**Задача** — это запланированный маршрут, по которому должен проехать водитель для выполнения съёмки и сбора данных.

Для каждой задачи автоматически рассчитываются общая длина дорог и примерное время движения на автомобиле. Для задач с полигонами также рассчитывается площадь полигона.

Вы можете работать с задачами для покрытия территорий на вкладке **Задачи**:

* [создавать задачи](#creating-task) и маршруты для них [разными способами](#route-options);
* [автоматически разделять полигоны на несколько задач](#splitting-polygons);
* [просматривать информацию о задачах](#viewing-task);
* [отслеживать статус созданных задач](#task-status);
* [редактировать задачи](#editing-task);
* [завершать задачи](#completing-task);
* [отменять задачи](#canceling-task).

![Работа с задачами](/img/citylens/planner-tasks-overview-803.png)

## Создание задачи {#creating-task}

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Нажмите **Новая задача**.
4. Создайте маршрут одним из [способов](#route-options).
5. Укажите параметры задачи:

   * **Название задачи** (обязательный параметр).
   * **Источник съёмки** (обязательный параметр): как водитель будет выполнять съёмку:

      * `Камера смартфона`: съёмка с помощью [мобильного приложения](/citylens/driver/overview).
      * `Камера 360°`: круговая съёмка с помощью камеры 360°.
      * `Другое устройство`: съёмка без водителя и загрузка готовых треков в систему.

   * **Исполнение**:
   
      * **Водитель** (для источников съёмки `Камера смартфона` и `Камера 360°`): водитель, назначенный на задачу. Вы можете использовать поиск по списку водителей и фильтрацию по группам с помощью тегов. В списке отображаются только водители, [добавленные в территорию](/citylens/administrator/planner/drivers#adding-driver-to-territory). Вы можете пропустить выбор водителя и назначить его позже.
      * **Срок исполнения**: дата, до которой водитель должен выполнить задачу.

   * **Параметры съёмки**:

      * **Направление камеры** (для источника съёмки `Камера смартфона`): стекло автомобиля, на которое направлена камера мобильного устройства. Доступные значения: `Вперёд` (по умолчанию используется всегда), `Назад`, `Вправо` и `Влево`.
      * **Анализ вывесок** (для источников съёмки `Камера смартфона` и `Камера 360°`): отметьте чекбокс, чтобы распознавать вывески. При использовании источника `Камера смартфона` выберите для параметра **Направление камеры** значение `Вправо` или `Влево`.
      * **Распознавание разметки** (для источника съёмки `Камера 360°`): отметьте чекбокс, чтобы распознавать дорожную разметку.

   * **Параметры маршрута**:

      * **Проезд в одном направлении** (для источника съёмки `Камера смартфона`): отметьте чекбокс, если водитель должен проехать маршрут только в одном направлении (например, при съёмке вывесок с одной стороны дороги). Время и расстояние будут рассчитаны для проезда в одном направлении. Если чекбокс не отмечен, время и расстояние примерно удвоятся. Для источника съёмки `Камера 360°` по умолчанию рассчитывается проезд в одном направлении.

   * **Исключение дорог**: по умолчанию все отмеченные дороги включаются в маршрут. Чтобы исключить определённые дороги, например, чтобы вынести часть из них в другую задачу, включите опцию и выберите фильтры:

      * **Класс дороги**: магистральные дороги, федеральные трассы и другие.
      * **Дорожный атрибут**: тип покрытия (асфальт, грунт и другие).
      * **Протяженность дорог**: введите максимальную длину дорог в метрах, чтобы исключить из маршрута дороги, длина которых превышает указанное значение.
      * **Исключить платные дороги**: отметьте чекбокс, чтобы исключить платные дороги из маршрута.
      * **Исключить переправы**: отметьте чекбокс, чтобы исключить переправы из маршрута.
      * **Исключить дороги с перекрытиями**: отметьте чекбокс, чтобы исключить дороги с перекрытиями из маршрута.

         Также вы можете [исключить дороги из полигона](#excluding-roads) вручную, кликнув на них на карте.

   * **Закрытые территории**: по умолчанию закрытые территории (области, ограниченные барьерами: воротами, шлагбаумами и т. д.) исключаются из маршрута. Чтобы включить их в маршрут, включите опцию и выберите фильтры:

      * **Тип въезда**: основной, дополнительный или служебный.
      * **Стоимость въезда**: бесплатно, платно или по пропускам.
      * **Тип ограждения**: ворота, шлагбаум, турникет и другие.

   * **Сохранить для следующих задач**: отметьте чекбокс, чтобы при создании следующих задач применялись такие же фильтры исключения дорог и закрытых территорий. Другие параметры задачи (например, название задачи, водитель и срок исполнения) сохраняться не будут.

   ![Параметры задачи](/img/citylens/planner-tasks-parameters-803.png)

6. Нажмите **Создать задачу**.

## Автоматическое разделение полигона {#splitting-polygons}

Вы можете ускорить планирование задач, автоматически разделив полигон на несколько задач. Количество задач зависит от количества водителей и одного из выбранных параметров:

* количества часов, которое водитель может потратить в рамках одной задачи;
* максимальной длины маршрута для каждой задачи.

Каждому водителю назначается одна задача на один рабочий день. Рабочий день длится 8 часов, это значение изменить нельзя.

При разделении для каждого полигона рассчитываются протяжённость дорог и примерное время проезда на автомобиле, а также общее количество рабочих дней, которое потребуется для покрытия всех полигонов.

Чтобы автоматически разделить полигон на несколько задач:

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Нажмите **Планировщик задач**.
4. [Создайте полигон](#polygons).
5. В диалоговом окне в правом нижнем углу нажмите **Использовать**:

   ![Использование полигона](/img/citylens/planner-tasks-auto-803.png)

6. Укажите параметры задач и планирования:

   ![Параметры планирования](/img/citylens/planner-tasks-auto-settings-803.png)

   * **Имя для всех задач** (обязательный параметр): название каждой задачи. К указанному имени будет добавляться порядковый номер (например, `Задача 1`, `Задача 2` и т. д.).
   * **Источник съёмки** (обязательный параметр): как водитель будет выполнять съёмку:

      * `Камера смартфона`: съёмка с помощью [мобильного приложения](/citylens/driver/overview).
      * `Камера 360°`: круговая съёмка с помощью камеры 360°.
      * `Другое устройство`: съёмка без водителя и загрузка готовых треков в систему.

   * **Параметры маршрута**:

      * **Проезд в одном направлении** (для источника съёмки `Камера смартфона`): отметьте чекбокс, если водитель должен проехать маршрут только в одном направлении (например, при съёмке вывесок с одной стороны дороги). Время и расстояние будут рассчитаны для проезда в одном направлении. Если чекбокс не отмечен, время и расстояние примерно удвоятся. Для источника съёмки `Камера 360°` по умолчанию рассчитывается проезд в одном направлении.

   * **Исполнение**:
   
      * **Водитель** (обязательный параметр, для источников съёмки `Камера смартфона` и `Камера 360°`): один или несколько водителей, которым будут назначены задачи. Вы можете использовать поиск по списку водителей и фильтрацию по группам с помощью тегов. В списке отображаются только водители, [добавленные в территорию](/citylens/administrator/planner/drivers#adding-driver-to-territory).
      * **Срок исполнения**: дата, до которой водители должны выполнить задачу.
   
   * **Способ деления полигона**: чтобы разделить полигон на несколько задач, укажите один из параметров:

      * **Часы**: количество часов, за которое можно проехать каждый полигон. При выборе значения вы можете ориентироваться на максимальное количество часов, которое водитель может потратить в рабочий день. Доступные значения: от 1 до 8 часов.
      * **Расстояние**: длина маршрута в километрах для каждого полигона. Доступные значения: от 1 до 250 км.

   * **Параметры съёмки**:

      * **Направление камеры** (для источника съёмки `Камера смартфона`): стекло автомобиля, на которое направлена камера мобильного устройства. Доступные значения: `Вперёд` (по умолчанию используется всегда), `Назад`, `Вправо` и `Влево`.
      * **Анализ вывесок** (для источников съёмки `Камера смартфона` и `Камера 360°`): отметьте чекбокс, чтобы распознавать вывески. При использовании источника `Камера смартфона` выберите для параметра **Направление камеры** значение `Вправо` или `Влево`.
      * **Распознавание разметки** (для источника съёмки `Камера 360°`): отметьте чекбокс, чтобы распознавать дорожную разметку.

   * **Закрытые территории**: по умолчанию закрытые территории (области, ограниченные барьерами: воротами, шлагбаумами и т. д.) исключаются из маршрута. Чтобы включить их в маршрут, включите опцию и выберите фильтры:

      * **Тип въезда**: основной, дополнительный или служебный.
      * **Стоимость въезда**: бесплатно, платно или по пропускам.
      * **Тип ограждения**: ворота, шлагбаум, турникет и другие.

   * **Исключение дорог**: по умолчанию все отмеченные дороги включаются в маршрут. Чтобы исключить определённые дороги, например, чтобы вынести часть из них в другую задачу, включите опцию и выберите фильтры:

      * **Класс дороги**: магистральные дороги, федеральные трассы и другие.
      * **Дорожный атрибут**: тип покрытия (асфальт, грунт и другие).
      * **Протяженность дорог**: введите максимальную длину дорог в метрах, чтобы исключить из маршрута дороги, длина которых превышает указанное значение.
      * **Исключить платные дороги**: отметьте чекбокс, чтобы исключить платные дороги из маршрута.
      * **Исключить переправы**: отметьте чекбокс, чтобы исключить переправы из маршрута.
      * **Исключить дороги с перекрытиями**: отметьте чекбокс, чтобы исключить дороги с перекрытиями из маршрута.

         Также вы можете [исключить дороги из полигона](#excluding-roads) вручную, кликнув на них на карте.

7. Нажмите **Далее**.
8. Проверьте результат планирования задач. Нажмите **Создать задачи**.

## Способы создания маршрута {#route-options}

Для построения маршрута вы можете использовать:

* [Полигоны](#polygons): рисовать полигоны на интерактивной карте <Brand /> или загружать собственные полигоны с уникальными зонами, областями, районами и т. д. Все дороги внутри полигона автоматически включаются в маршрут. При необходимости вы можете [исключить их](#excluding-roads).

  Также вы можете [автоматически разделить полигон](#splitting-polygons) на несколько задач в зависимости от количества водителей, времени на выполнение задачи и длины маршрута.

  Пример задачи с полигоном на карте:

  <img src="/img/citylens/planner-polygon-803.png" alt="Пример полигона на карте" width="700" />

* [Дороги](#roads): выделять дороги маршрута на карте. При необходимости вы можете выбрать только нужные сегменты дорог.

  Пример задачи с выделенными на карте дорогами:

  <img src="/img/citylens/planner-roads-803.png" alt="Пример дорог на карте" width="700" />

* [Точки](#points): отмечать точки на карте, которые нужно посетить в рамках задачи, или загружать точки из файла. Рассчитывается кратчайший по времени маршрут, проходящий через точки.

  Пример задачи с точками маршрута:

  <img src="/img/citylens/planner-points-803.png" alt="Пример точек на карте" width="700" />

### Полигоны {#polygons}

Вы можете [нарисовать полигон на карте](#creating-polygon) или [загрузить собственный полигон из файла](#uploading-polygon). При необходимости из полигонов можно [исключить дороги](#excluding-roads).

#### Создание полигона на карте {#creating-polygon}

Чтобы создать полигон:

1. Нажмите значок ![Рисовать полигон](/img/citylens/planner-draw-polygon.svg).
2. Отметьте не менее трёх точек на карте. Точки соединяются автоматически, линии полигона не должны пересекаться.
3. Чтобы переставить точку, перетащите её в нужное место на карте. Чтобы удалить точку, наведите на неё курсор и нажмите значок ![Крестик](/img/pro/cross-icon.svg).
4. Чтобы замкнуть полигон, соедините начальную и конечную точки или нажмите *Enter*.

![Рисование полигона](/img/citylens/planner-tasks-draw-633.png)

При создании маршрута вы можете использовать поиск по адресам, местам и организациям на карте. Также вы можете использовать в качестве полигонов стандартные территории (области, районы, населённые пункты и другие), выбранные в поиске. Полигон построится на карте автоматически:

![Поиск полигонов на карте](/img/citylens/planner-tasks-search-803.png)

#### Загрузка полигона из файла {#uploading-polygon}

Чтобы загрузить собственный полигон из файла:

1. Нажмите значок ![Рисовать полигон](/img/citylens/planner-draw-polygon.svg).
2. Нажмите ![Загрузить полигон](/img/citylens/planner-upload-polygon.svg).
3. Перетащите файл в область загрузки или нажмите **Выберите файл на компьютере**. Файл должен соответствовать [требованиям](#polygon-requirements).

   <img src="/img/citylens/planner-tasks-file.png" alt="Загрузка полигона из файла" width="370" />

##### Требования к файлу с полигоном {#polygon-requirements}

* Геометрия: Полигон (Polygon).
* Форматы: `.kml`, `.kmz`, `.shp`, `.geojson`.
* Размер: до 100 МБ.
* Кодировка: UTF-8.
* Система координат: [WGS84(4326)](https://epsg.io/4326).

Пример файла:

<details>
<summary><code>example.geojson</code></summary>

```json
{
    "type": "FeatureCollection",
    "features": [
        {
            "type": "Feature",
            "properties": {},
            "geometry": {
                "coordinates": [
                    [
                        [37.60556107462642, 55.76462040952444],
                        [37.614942029534205, 55.75679538816905],
                        [37.62009171457146, 55.75882561530517],
                        [37.61356440678534, 55.76799723318385],
                        [37.60556107462642, 55.76462040952444]
                    ]
                ],
                "type": "Polygon"
            }
        }
    ]
}
```

</details>

#### Исключение дорог из полигона {#excluding-roads}

Все дороги внутри полигона автоматически включаются в маршрут. Вы можете исключить некоторые дороги, например, чтобы вынести часть из них в другую задачу позже.

Чтобы исключить дороги, при создании полигона нажмите значок ![Исключить дороги](/img/citylens/planner-exclude-roads.svg) и кликните на дороги, которые нужно исключить. В режиме редактирования исключённые дороги выделяются красным цветом.

![Исключение дорог](/img/citylens/planner-tasks-exclude-803.png)

### Дороги {#roads}

Чтобы выделить дороги на карте, нажмите значок ![Выделить дороги](/img/citylens/planner-roads.svg) и кликните на дороги. Чтобы удалить дорогу из маршрута, кликните на неё снова.

![Выделение дорог на карте](/img/citylens/planner-tasks-roads-803.png)

Чтобы включить в маршрут только часть дороги, разделите её на сегменты. Для этого нажмите значок ![Выделить сегменты дорог](/img/citylens/planner-segments.svg) и отметьте точки, по которым дорога разделится на сегменты. Чтобы исключить сегмент из маршрута, нажмите значок ![Корзина](/img/pro/trash-icon.svg) в списке сегментов.

![Выделение сегментов дорог на карте](/img/citylens/planner-tasks-segments-803.png)

### Точки {#points}

Вы можете [отметить точки на карте](#selecting-points) или [загрузить точки из файла](#uploading-points).

#### Выбор точек на карте {#selecting-points}

Чтобы выбрать точки маршрута, нажмите значок ![Выбрать точки](/img/citylens/planner-click-points.svg) и отметьте точки на карте.

Чтобы удалить точку из маршрута, наведите на неё курсор и нажмите значок ![Крестик](/img/pro/cross-icon.svg).

![Выбор точек на карте](/img/citylens/planner-tasks-points-803.png)

#### Загрузка точек из файла {#uploading-points}

Чтобы загрузить точки из файла:

1. Нажмите значок ![Менеджер стилей](/img/pro/style-manager-icon.svg) в правом нижнем углу.
2. Нажмите **Добавить приоритетные точки**.
3. Перетащите файл в область загрузки или нажмите **Выберите файл на компьютере**. Файл должен соответствовать [требованиям](#points-requirements).
4. Нажмите на карточку с точками, чтобы отобразить их на карте.

![Загрузка точек из файла](/img/citylens/planner-tasks-points-file-633.png)

Чтобы включить точки в маршрут, используйте один из способов:

* Нажмите значок ![Выбрать точки](/img/citylens/planner-click-points.svg) и отметьте точки на карте.
* Создайте [полигон](#polygons), который покроет точки.
* Выделите [дороги](#roads), которые проходят через точки.

##### Требования к файлу с точками {#points-requirements}

* Геометрия: Точка (Point).

* Размер: до 100 МБ.
* Кодировка: UTF-8.
* Система координат: [WGS84(4326)](https://epsg.io/4326).

## Просмотр информации о задаче {#viewing-task}

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Выберите задачу в списке или кликните на соответствующий полигон или дороги маршрута на карте. Вы можете использовать поиск по задачам в списке, сортировку по параметрам задачи, а также фильтрацию по тегу, водителю, статусу и типу задачи.

### Карточка задачи {#task-card}

В карточке задачи отображается:

* **ID**: уникальный идентификатор задачи.
* **Источник съёмки**: устройство, с помощью которого водитель выполняет съёмку.
* **Исполнение**:

   * **Водитель**: водитель и время его последней активности. Отображается, если вы назначили водителя при создании или редактировании задачи.
   * **Срок исполнения**: запланированная дата выполнения задачи. Отображается, если вы указали срок при создании или редактировании задачи.

* **Параметры съёмки**:

   * **Направление камеры**: стекло автомобиля, на которое направлена камера мобильного устройства.
   * **Анализ вывесок**: распознавание вывесок.
   * **Распознавание разметки**: распознавание дорожной разметки.

* **Параметры маршрута**:

   * **Проезд в одном направлении**: проезд маршрута в одном направлении.
   * **Исключение дорог**: фильтры исключения дорог из маршрута.
   * **Закрытые территории**: фильтры включения закрытых территорий в маршрут.

* **Детали задачи**:

   * **Процент выполнения**: процент выполнения задачи. Отображается только для задач со статусом **В работе** или **Завершена**.
   * **Дата создания**: дата создания задачи.
   * **Площадь**: площадь территории (полигона) в км². Отображается только для задач с полигонами.
   * **Длина дорог**: общая протяжённость дорог.
   * **Время объезда**: расчётное время движения на автомобиле с учётом пробок.

### На карте {#on-map}

В зависимости от [статуса задачи](#task-status) на карте отображается:

* **Новая** и **Назначена**: запланированный маршрут.
* **В работе**:
   * Последняя геопозиция водителя.
   * Пройденная часть запланированного маршрута (жёлтый цвет).
   * Оставшаяся часть запланированного маршрута (синий цвет).
   * Если водитель выполняет задачу в данный момент, отобразится его текущая геопозиция. Вы сможете наблюдать за его перемещением на карте в режиме реального времени.
   * Сообщения о событиях на дороге от водителя.
* **Завершена**: пройденный маршрут и сообщения о событиях на дороге от водителя. Маршруты завершённых задач также доступны в наборах данных <Brand /> Про: [Задачи](/citylens/administrator/pro/tasks-planned) (запланированные маршруты) и [Объезды](/citylens/administrator/pro/tasks-actual) (фактические маршруты).

## Просмотр статуса задачи {#task-status}

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Посмотрите статус задачи в её строке. От статуса задачи зависит цвет соответствующего полигона или дорог маршрута на карте.

<br />

Возможные статусы задачи:

* **Новая** (синий цвет): задача создана, но не назначена водителю. Вы можете [редактировать задачу](#editing-task) или [отменить задачу](#canceling-task) с этим статусом.
* **Назначена** (жёлтый цвет): задача назначена водителю, но водитель пока не взял её в работу. Вы можете [редактировать задачу](#editing-task) или [отменить задачу](#canceling-task) с этим статусом.
* **В работе** (жёлтый цвет): водитель взял задачу в работу в мобильном приложении. В статусе отображается прогресс выполнения задачи в процентах. Вы можете [завершить задачу](#completing-task) или [отменить задачу](#canceling-task) с этим статусом.
* **Завершена** (зелёный цвет): задача помечена как завершённая.
* **Отменена**: задача отменена. Отменённые задачи не отображаются на карте, но по ним сохраняется вся информация в карточке задачи. Отменённые задачи не удаляются из списка.

## Редактирование задачи {#editing-task}

Если задача в статусе **Новая** или **Назначена**, вы можете её отредактировать:

* изменить маршрут: обновить нарисованный полигон, загрузить новый, выделить или исключить дороги, выбрать или удалить точки маршрута;
* назначить другому водителю или удалить водителя из задачи;
* изменить параметры задачи: название, источник съёмки, фильтры исключения дорог и другие.

<br />

Чтобы отредактировать задачу:

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Выберите задачу и в открывшемся окне нажмите **Редактировать задачу**.
4. Внесите изменения в задачу.
5. Нажмите **Сохранить задачу**.

## Завершение задачи {#completing-task}

Вы можете завершать задачи в статусе **В работе** с любым процентом выполнения.

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Выберите задачу.
4. В открывшемся окне нажмите значок ![Меню задачи](/img/menu-dots-horizontal.svg) и выберите **Завершить задачу**.

Статус задачи изменится на **Завершена**.

## Отмена задачи {#canceling-task}

Если задача в статусе **Новая**, **Назначена** или **В работе**, вы можете отменить задачу и перевести её в статус **Отменена**.

1. Перейдите на вкладку **Задачи**.
2. Откройте страницу территории и проекта.
3. Выберите задачу.
4. В открывшемся окне нажмите значок ![Меню задачи](/img/menu-dots-horizontal.svg) и выберите **Отменить задачу**.
5. Подтвердите отмену.
